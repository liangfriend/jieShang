# 成就系统

成就定义以代码常量为准；数据库只记录**已解锁**成就的 `key` 与完成时间。藏品奖励通过 `collection` 表的 `owned` 字段发放。

## 数据模型

### 常量（`src/renderer/src/constant/achievements.ts`）

每条成就包含：

| 字段 | 说明 |
| --- | --- |
| `key` | 唯一标识，与数据库 `achievement_progress.key` 对应（仅作 id，不参与判定） |
| `name` | 展示名称 |
| `description` | 达成条件描述 |
| `reward` | 奖励展示文案（弹窗 / 成就页） |
| `illustrationUrl` | 插图 URL（暂无则留空，页面显示占位图标） |
| `criteria` | 局内判定条件（见下表），**不**从 key 解析阈值 |
| `rewardCollectionId` | 可选；解锁后写入 `collection.owned = true` 的藏品 id，与 main `BUILTIN_COLLECTION_SEED_IDS` 一致 |

#### `criteria` 类型

| `type` | 含义 | 参数字段 |
| --- | --- | --- |
| `note_slice_arcade_score` | 街机本局得分 | `minScore` |
| `note_slice_endless_score` | 无限本局得分 | `minScore` |
| `note_slice_combo` | 本局最高连击（任意模式） | `minCombo` |
| `note_slice_extreme_survival` | 极限本局存活 | `minSurvivalMs` |

无实物奖励（如「无」）或种子尚未入库的奖励（如「曲谱皮肤-虚无」）不设 `rewardCollectionId`。

藏品 id 约定见 `src/renderer/src/constant/collectionSeedIds.ts`（与 `src/main/constant/collectionSeedIds.ts` 保持一致）。

### 数据库（`achievement_progress` 表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| key | TEXT UNIQUE | 成就唯一标识 |
| completed_at | DATETIME | 完成时间 |
| created_at / updated_at / deleted_at | DATETIME | 软删除 |

**规则：** 表中存在的 `key` 即视为已完成；未写入则未完成。

### 历史最高分（`note_slice_high_score` 表）

按 **模式 × 难度 × 谱面模式**（`mode` + `difficulty` + `notation`）记录街机 / 无限 / 极限历史最佳；与曲谱 `score` 表无关。街机 / 无限为分数，极限为存活时间（ms）。**测试难度**不计入排行榜。

`notation` 为 `staff`（线谱）/ `jianpu`（简谱），来自首页设置「游戏曲谱模式」switch（`gameSettings.notationMode`，进入一局时由 `bindNoteSliceGameNotationMode` 绑定）。**线谱与简谱的最高分完全分开记录**；成就本身不区分谱面模式，用哪种谱子达成都算。

## 局内成就流程（音符切切）

实现入口：`noteSliceSessionAchievementManager.ts`，由 `NoteSliceGameView` 每局创建。

```
开局
  └─ createNoteSliceSessionAchievementManager(mode)

局中（仅记录，不判定）
  └─ watch(session.combo) → recordCombo()   // 维护本局 peakCombo

游戏结束（isGameOver）
  ├─ finalizeNoteSliceGameScore(mode, score, difficulty, notation)  // 历史最高分（与成就独立，按谱面模式分记）
  └─ evaluateAndUnlock({ score, survivalMs })
        ├─ 查 achievement:list → 已解锁 key 集合
        ├─ 遍历 ACHIEVEMENT_DEFINITIONS 全部条目
        ├─ 跳过已解锁；对满足 criteria 且未解锁的：
        │     ├─ achievement:unlock
        │     └─ 若有 rewardCollectionId → collection:update(id, { owned: true })
        └─ 返回本局新解锁列表 → gameEnd payload → 结算弹窗展示
```

**批量解锁：** 一局可同时解锁多档（如街机 300 分同时解锁 10 / 50 / 300 三档），每项独立写库并发奖。

**结算弹窗：** `NoteSliceGameOverDialog.vue` 展示「本局获得成就」；固定高度区域可滚轮浏览多条奖励。

## 页面与入口

- 首页 **成就** 按钮 → `/achievements`（`AchievementsView.vue`）
- 进入页面时：`achievement:list` 拉取已解锁记录，与常量按 `key` 合并
- **已达成**：金色高亮 + 「已达成」徽章 + 完成时间
- **未达成**：半透明展示
- 顶部展示历史最高分，先按 **线谱 / 简谱** 分组，每组内为三种模式 × 简单 / 标准 / 困难（无记录显示 0；`buildNoteSliceHighScoreNotationGroups`）

## IPC

| 通道 | 说明 |
| --- | --- |
| `achievement:list` | 返回已解锁列表 |
| `achievement:unlock` | `{ key, completed_at? }`，已存在则幂等返回 |
| `collection:update` | 成就发奖时 `{ owned: true }` |
| `noteSliceHighScore:list` | 各模式 × 难度 × 谱面模式最高分 |
| `noteSliceHighScore:upsertIfHigher` | `(mode, difficulty, score, notation = 'staff')`，仅当更高时更新 |

Renderer 封装：

| 文件 | 职责 |
| --- | --- |
| `utils/achievementHelper.ts` | 列表合并、`unlockAchievement`、`grantCollectionOwnership`、`grantAchievementCollectionReward` |
| `utils/noteSliceHighScoreHelper.ts` | 模式最高分读写（含 `notation` 维度；成就页分组矩阵） |
| `views/noteSlice/noteSliceSessionAchievementManager.ts` | 局内记录 + 结束判定与发奖 |
