# 成就系统

成就定义以代码常量为准；数据库只记录**已解锁**成就的 `key` 与完成时间。

## 数据模型

### 常量（`src/renderer/src/constant/achievements.ts`）

每条成就包含：

| 字段 | 说明 |
| --- | --- |
| `key` | 唯一标识，与数据库 `achievement_progress.key` 对应 |
| `name` | 展示名称 |
| `description` | 简短描述 |
| `howToGet` | 获取方式说明 |
| `illustrationUrl` | 插图 URL（暂无则留空，页面显示占位图标） |

### 数据库（`achievement_progress` 表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| key | TEXT UNIQUE | 成就唯一标识 |
| completed_at | DATETIME | 完成时间 |
| created_at / updated_at / deleted_at | DATETIME | 软删除 |

**规则：** 表中存在的 `key` 即视为已完成；未写入则未完成。

### 历史最高分（`note_slice_high_score` 表）

记录音符切切三种模式的历史最高分（与曲谱 `score` 表无关）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| mode | TEXT UNIQUE | `arcade` / `endless` / `extreme` |
| high_score | INTEGER | 该模式历史最高分 |
| created_at / updated_at / deleted_at | DATETIME | 软删除 |

街机 / 无限模式一局结束时，若本局分数更高则自动更新。极限模式接入后再写入。

## 页面与入口

- 首页 **成就** 按钮 → `/achievements`（`AchievementsView.vue`）
- 进入页面时：`achievement:list` 拉取已解锁记录，与常量按 `key` 合并
- **已达成**：金色高亮 + 「已达成」徽章 + 完成时间
- **未达成**：半透明展示
- 顶部展示三种模式历史最高分（无记录显示 0）

## IPC

| 通道 | 说明 |
| --- | --- |
| `achievement:list` | 返回已解锁列表 |
| `achievement:unlock` | `{ key, completed_at? }`，已存在则幂等返回 |
| `noteSliceHighScore:list` | 三种模式最高分 |
| `noteSliceHighScore:upsertIfHigher` | `(mode, score)`，仅当更高时更新 |

Renderer 封装：`utils/achievementHelper.ts`、`utils/noteSliceHighScoreHelper.ts`。

## 当前预置成就（示例）

| key | 名称 | 获取条件（设计） |
| --- | --- | --- |
| `note_slice_first_game` | 初来乍到 | 完成任意一局街机或无限 |
| `note_slice_arcade_500` | 街机新星 | 街机单局 ≥ 500 分 |
| `note_slice_combo_10` | 连击十段 | 连击达到 10 |
| `note_slice_endless_survive` | 久战不退 | 无限模式累计清除 50 个普通块 |
| `note_slice_no_wrong_press` | 指下无误 | 整局未乱按触发惩罚炸弹 |

**待办：** 游戏中成就埋点（调用 `achievement:unlock`）尚未全部接入。
