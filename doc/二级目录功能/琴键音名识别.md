页面进入后展示

标题：琴键音名识别

说明：看键选音名（选择题）。不播放声音，考查琴键位置与音名对应；与「音感测试」互为对照（后者听音点琴键）。

状态0
可设置：
+ 音名范围：五音（宫商角徵羽 → C D E G A）、七音（C D E F G A B）、十二音（完整半音）
+ 选项文本类型：音名（C / C#）、唱名（do / di）、数字（1 / #1）、混合（每项随机一种文本），默认音名
+ 轮次，默认 6
+ 答题倒计时，默认 3s
按钮：开始测试

开始测试后，进入多轮测试，
状态1 上方圆环显示倒计时；下方八度钢琴组件高亮一枚目标琴键（不显示琴键文本）。更下方是若干选择题按钮（从当前音名范围中抽取，含 1 个正确答案 + 若干干扰项，建议共 4 项）。倒计时结束或点选任一选项后进入结果。圆环下方（或钢琴下方）提供「中止」按钮，直接回到状态0。
状态2 圆环文本变为正确 / 错误 / 超时。八度钢琴：正确答案琴键绿色边框；若点错，错误项对应琴键红色边框，同时仍显示绿色正确答案。选择题区同步标出对错。展示约 2s 后进入下一轮状态1；若已是最后一轮则进入状态3。
状态3 显示结果：正确率、正确/错误/超时次数、平均作答 ms、最长连对。按钮：再来一次（同设置重开）、重新设置（回状态0）。

出题规则
+ 每轮从所选音名范围中随机一个音级（0–11），在八度钢琴上高亮对应键
+ 干扰项从同范围内其它音级抽取，不够时允许从十二音补足
+ 连续两轮尽量避免同一目标音级

复用
+ 八度钢琴组件：同音感测试（num 0–11，color / border，文本类型，宽高）
