标题：和弦识别

说明：听和弦选名称（选择题）。考查常见和弦听辨；与「音感测试」同属音高体系，本页聚焦多音同时发声后的和弦类型判断。

状态0
可设置：
+ 和弦范围（可多选，至少选一类；默认勾选三和弦）：
  + 大三和弦（如 C、G）
  + 小三和弦（如 Am、Em）
  + 属七（如 G7）
  + 大七 / 小七（如 Cmaj7、Am7）——可作进阶项，默认不勾选
+ 声音范围：标准音（中央 C 附近八度内排布和弦）、全音（21–108 内随机根音八度）
+ 是否显示钢琴（switch，默认开）
+ 轮次，默认 6
+ 答题倒计时，默认 8s
按钮：开始测试

开始测试后，进入多轮测试，
状态1 自动播放当前和弦（全局 nplayer，和弦内各音几乎同时 trigger；需先 ensure 藏品音色）。上方圆环显示倒计时，点击圆环可重播该和弦。下方八度钢琴可只读展示本轮和弦音级（答题中可不标答案色，或仅用中性高亮提示“有音”，避免直接泄露和弦名）。更下方是选择题按钮（和弦名称，如「C 大三」「A 小三」「G7」等；1 个正确 + 若干干扰，建议共 4 项）。倒计时结束或点选选项后进入结果。提供「中止」回到状态0。
状态2 圆环文本变为正确 / 错误 / 超时。八度钢琴用绿色边框标出和弦内所有音级；若点错，不额外标红其它和弦名对应键（因选项是名称不是单键），选择题区标出正确项与错误项即可。约 2s 后下一轮状态1；最后一轮进入状态3。
状态3 显示结果：正确率、正确/错误/超时、平均作答 ms、最长连对；可选展示「各和弦类型正确率」细分。按钮：再来一次、重新设置。

出题规则
+ 在已选和弦范围内随机类型 + 随机根音（音级）
+ 标准音：根音落在中央 C 八度附近，和弦音用常见密集排列（尽量落在可弹八度展示范围内；超出八度钢琴的音只参与发声，钢琴上按音级 0–11 点亮）
+ 全音：根音 MIDI 在 21–108 内随机，仍按音级点亮八度钢琴
+ 选项干扰：优先同组其它和弦（如同是三和弦的大/小互换、根音相近），再从其它已启用类型补充
+ 连续两轮尽量避免完全相同的「根音+类型」

发声
+ 使用全局 nplayer.trigger，注意藏品音色 key 需 ensureCollectionToneColorInitialized（与音感测试一致）
+ 和弦各音可用相同短 duration，略微分开 0–30ms 也可，默认齐奏

复用
+ 八度钢琴组件：同音感测试 / 琴键音名识别
+ 结果页信息结构：对齐音感测试（正确率、次数、平均作答、连对）
