进入模拟乐器列表页，会判断各种模拟乐器的音色是否拥有，如果未拥有对应音色，对应模拟乐器卡片是禁用状态无法点击进入

页面分三部分

上下两大块，下边分割成左右两块
上边横向是一个口琴正视图(吹口朝向用户)
下边左侧是曲谱，下边右侧是功能区

功能区
+ 选择器选择曲谱展示到曲谱展示区
+ 播放暂停停止 这个页面锁死音色为口琴音色
+ 口琴种类选择器，默认是24孔C调复音，全部种类有10孔c调布鲁斯和24孔C调复音
+ 嘴部大小，控制嘴部宽度，数字输入框

口琴展示区
鼠标只要落在口琴展示区，就会触发口琴跟随。口琴中心点横坐标会跟随鼠标光标。此时左键是吹气，右键是吸气
鼠标离开口琴展示区，口琴回归居中位置
展示区中心处有一个红色矩形框。表示嘴的范围。在这个范围内的孔，才会响应吹气呼气来发声

口琴组件

做一个能模拟所有种类（包括未来半音阶口琴等）口琴的组件

口琴每个孔，有吹还是吸触发，对应音高，半音阶触发后音高等等信息，具象化为一个对象。口琴就变成了一个对象数组能渲染出来。应该是这样的，内置各种口琴的数据。一键切换

实现要点
+ 通用组件：`HarmonicaPanel.vue`，数据：`constant/harmonica.ts`（`HarmonicaHoleDef[]`）
+ 机体 SVG：`harmonica-blues10.svg` / `harmonica-tremolo24.svg`
+ 孔位响应吹/吸时高亮并发声；种类 / 嘴宽偏好存 localStorage（`jieShang.harmonicaSimPrefs`）
