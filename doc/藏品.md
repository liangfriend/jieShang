# 藏品

## 概念

| 概念 | 说明 |
| --- | --- |
| 藏品类型 | 音色、曲谱皮肤、钢琴皮肤、演奏皮肤（见 `CollectionTypeEnum`） |
| 藏品表 `collection` | 本地已下载/入库的藏品记录，**不等于已拥有** |
| `owned` | 是否已拥有；**列表页只展示 `owned = true` 的记录** |
| `level` | 藏品级别 **1（最低）~ 6（最高）**；列表卡片背景按级别着色 |
| `is_built_in` | 是否软件内置藏品；内置藏品不可删除，靠任务等方式解锁 `owned` |
| 社区藏品（二期） | 用户从网上下载的藏品，`is_built_in = false`，可删除；不含演奏皮肤（需 Vue 页面，暂不支持社区开发） |

## 数据分工

### 数据库 `collection` 表

存本地下载好的藏品实体与状态，字段见 [数据库.md](./数据库.md#collection藏品)。

| 字段 | 列表/详情用途 |
| --- | --- |
| `type` | 藏品类型 |
| `name` | 藏品名称 |
| `content` | 藏品本体：音色/曲谱皮肤/钢琴皮肤 JSON、演奏皮肤内置 key |
| `description` | 描述（社区藏品主要来源；内置可为空，走常量兜底） |
| `thumbnail` | 缩略图；无图时 UI 用 `?` 占位 |
| `is_built_in` | 是否内置；`true` 时禁止删除，并读取内置元数据 |
| `owned` | 是否拥有；未拥有不进入藏品列表 |
| `level` | 级别 1~5；内置种子见 `BUILTIN_COLLECTION_LEVELS` |
| `option` | 可调参数 JSON 字符串；金色及以上带参数的皮肤有默认值，其余为 `'{}'`。详见下文「可调参数（option）」 |

### 级别与列表配色

级别定义在 `src/main/constant/collectionSeedIds.ts` 与 renderer 同名文件中的 `BUILTIN_COLLECTION_LEVELS`（按类型 + 名称）。**1 为最低档**，当前内置藏品最高为 5 级（空洞演奏皮肤）；6 级预留给后续内容。

| 级别 | 列表卡片背景 |
| --- | --- |
| 1 | 灰白 |
| 2 | 绿色 |
| 3 | 蓝色 |
| 4 | 紫色 |
| 5 | 金色 |
| 6 | 红色（预留） |

实现：`CollectionView.vue` + `utils/collection/collectionLevel.ts`（`collectionLevelCardClass` / `collectionLevelLabel`）。

| 钢琴皮肤 | 经典纯色 | 重金属、黑白、木板 | — | — | — |

#### 演奏皮肤品质标准

演奏皮肤的级别按画面的动态程度判定，逐级累加（高一级必须满足低一级的全部要求）：

| 级别 | 颜色 | 标准 |
| --- | --- | --- |
| 1 | 白 | 什么动效都没有：静态背景，水柱 / 方块就是从背景图里抠出来的形状，基准线静态 |
| 2 | 绿 | 有按键动效（overlay `createRuntime`：粒子、迸发等），但背景是静态的 |
| 3 | 蓝 | 在绿色基础上背景是动态的（第一层 `drawBackground` 随 `time` 变化），但基准线仍是静态的 |
| 4 | 紫 | 在蓝色基础上基准线也动起来、炫酷起来（`drawBaseline` 随时间变化），且整体更美观、更细致 |
| 5 | 金 | 在紫色基础上水柱 / 方块脱离背景遮罩、用 `drawColumns` 自绘（如向外发光的线框），且按住琴键期间动效持续不断（不只按下瞬间）。背景可以是纯色，由自绘水柱与持续按键动效顶替「动态背景」 |

判定依据：

- **按键动效**：只有静态的琴键高亮条（`drawKeyActiveBar`）不算动效。
- **动态背景**：第一层背景随时间变化。水柱层自身的流光不算动态背景。
- **动态基准线**：`drawBaseline` 每帧画出的内容不同（流光、波动、放电等）。

新增或修改演奏皮肤时，先按此表确定级别，再写入两份 `collectionSeedIds.ts` 的 `BUILTIN_COLLECTION_LEVELS.performSkin`。

### 内置元数据 `src/renderer/src/constant/collection.ts`

仅存 **内置** 藏品的展示与解锁信息，不重复存 content 本体：

- `PerformSkinNameList`：演奏皮肤，`content` 存此处的 key（如 `default`、`RainBow`）
- `BUILTIN_COLLECTION_META`：按 `type → contentKey` 索引，可扩展音色/曲谱皮肤/钢琴皮肤

每条内置元数据：

```ts
{
  name: string       // 展示名称
  howToGet: string   // 获取条件（详情区「获取条件」）
  description?: string // 描述兜底
}
```

## 列表页逻辑（`CollectionView.vue`）

1. 调用 `window.api.collection.query({ owned: true })` 拉取已拥有藏品。
2. 顶栏：名称模糊搜索（`includes`，不区分大小写）。
3. 左侧主区域：类型筛选（`全部` + 遍历 `CollectionTypeEnum`）+ **按级别着色的**卡片网格列表。
4. 右侧窄栏详情：缩略图（无则 `?`）、名称、类型 **· 级别**、描述、获取条件。
5. **名称**：优先数据库 `name`；内置兜底 `BUILTIN_COLLECTION_META` → `description` 首行 → 类型 + id。
6. **描述**：优先数据库 `description`；内置可为空时读常量 `description`。
7. **获取条件**：仅 `is_built_in === true` 时，从 `getBuiltinMeta(type, content).howToGet` 读取，展示在描述下方。
8. **删除**：仅 `is_built_in === false` 显示删除按钮，调用 `collection:delete`。

## 内置种子数据

每次启动在 `setupContainer` 中执行 `syncBuiltinCollections`（`src/main/database/collectionBuiltinSeed.ts`）：缺失的内置藏品新建，已有的按 `owned = existing || seed` 合并；新增内置藏品无需写迁移。

**初始 `owned`：** `DEFAULT_BUILTIN_COLLECTION_OWNED_IDS` 为 `true`：全部音色、默认曲谱皮 id=7、默认演奏皮 id=10、经典纯色钢琴皮 id=12；其余皮肤类 `false`，由成就等方式解锁。

**级别：** 写入时按 `BUILTIN_COLLECTION_LEVELS` 设置 `level` 字段。

**音色**（`src/main/resources/toneColors/*.json`）

名单统一维护在 `src/shared/toneColorCatalog.json`（主进程种子与渲染层 i18n 共用）：每项 `{ id, file, family, name: { zh, en, ja }, description? }`，`families` 给出乐器族的三语名称。全部 level=1、初始 owned=true。

- 名单见 `src/shared/toneColorCatalog.json`（钢琴三角/亮音；有音高打击乐八音盒/马林巴；风琴口琴/手风琴；吉他尼龙/钢弦；原声贝斯；吹管短笛/排箫；民族卡林巴/班卓/唢呐；打击乐全保留）
- 音色 JSON 较大，不打进主进程 bundle：开发读 `src/main/resources/toneColors`，打包经 `package.json` 中 `build.extraResources` 复制到 `resources/toneColors`，运行时由 `readBuiltinToneColorContent` 读取（gzip 文件自动解压）
- 启动同步时只在库内 content 为空、长度与文件不一致或文件更新时间晚于 `updated_at` 时重写 content
- `collection:query` 列表不返回音色 content，使用音色时按 id 单独读取
- 新增音色：放入 JSON 文件 → 在 catalog 中追加一项 → `node scripts/generateCollectionThumbnails.mjs` 生成缩略图

## 演奏皮肤本地结构（performSkin）

一套皮肤 = 7 部分，目录 `src/renderer/src/components/performSkin/{name}/`：

| 部分 | 文件 |
| --- | --- |
| midi 块普通态 | `midiBox/normal.ts` |
| midi 块激活态 | `midiBox/active.ts` |
| 瀑布流普通水柱 | `waterfall/normal.ts` |
| 瀑布流激活水柱 | `waterfall/active.ts` |
| 背景 | `svg.ts` → `bg` |
| 基准线 | `svg.ts` → `baseline` |
| 基准线 midi 按下高亮 | `svg.ts` → `baselineMidiActive` |

**基准线 midi 按下高亮**：`svg.ts` 提供 `baselineMidiActive`；`pianoWaterfall` / `pianoMidiBox` 内按 `activeKeys` 合并 `keyActiveBar` 布局与 SVG 背景（宽度传 `getMidiWidth(midi)` 数值，单位 px）。

注册表：`performSkin/registry.ts`（`content` 与文件夹对应）

| content | 文件夹 | 说明 |
| --- | --- | --- |
| `default` | `default/` | 普通黄、激活蓝、白底、红基准线 |
| `RainBow` | `rainbow/` | 原彩色糖果风（自 pianoMidiBox / pianoWaterfall 抽出） |
| `PixelArcade` | `pixelArcade/` | CRT 像素星空，像素柱，像素碎片迸发 |
| `MintSoda` | `mintSoda/` | 薄荷汽水气泡，柠檬黄高亮，按键冒泡 |
| `Sakura` | `sakura/` | 远山樱枝落樱，樱枝基准线，花瓣绽放 |
| `Firefly` | `firefly/` | 月下森林萤火，草叶基准线，放飞萤火虫 |
| `Synthwave` | `synthwave/` | 条纹落日 + 透视网格，霓虹灯管基准线，火花喷射 |
| `Aurora` | `aurora/` | 飘动极光 + 雪山，冰线基准线，极光光柱与冰晶 |
| `ImperialDragon` | `imperialDragon/` | 宫灯祥云 + 游龙戏珠，回纹金条基准线，金色烟花 |
| `Thunder` | `thunder/` | 暴雨云 + 周期雷击，放电导线基准线，电弧与连锁闪电 |
| `Hollow` | `hollow/` | 纯黑底，未弹水柱是渐变流动的发光线框（略圆角矩形），已弹水柱是填满线框内侧的不透明实心渐变块（无边框），上下扩散光晕的基准线，按住时细光线从水柱左右两侧边缘向外上方斜着缓缓上飘；渐变色等参数存 `option`，可在藏品页修改 |

以上 9 款第四层动效都走 overlay `createRuntime()`（`canvas/*Effect.ts`）；背景里的静态部分（山、树、樱枝等）按尺寸缓存为离屏 canvas，尺寸变化时重建。

**水柱绘制的两种结构**（`utils/performLayerBackground.ts` 的 `drawLayerWithUnifiedColumnClip`）：

- 默认（遮罩）：整层画 `drawBackground`，再以所有水柱 / 方块的圆角矩形并集为 clip 抠出来。内容只能在水柱内部，画不出外发光。
- 自绘：normal / active 命令提供可选的 `drawColumns(ctx, columns, input)` 时跳过遮罩，直接拿到每根水柱的 `{x, y, width, height, borderRadius, opacity}` 自行绘制，可以描边、外发光、画到水柱外面。`Hollow` 用这种方式画发光线框（同透明度的水柱合并 path，描边色是随时间流动的渐变，大 / 中 / 小三层 `shadowBlur` 叠出光晕，再描一次亮芯）。

### 可调参数（option）

`collection.option` 存藏品的可调参数（JSON 字符串），默认 `'{}'`。

- 默认值写在内置种子里（`collectionBuiltinSeed.ts`），启动同步时只在记录的 option 为空或 `'{}'` 时写入，**用户保存过的参数不会被覆盖**。
- 用户在藏品页详情里修改并点「保存参数」后，通过 `collection:update` 写回 `option`；「恢复默认」把编辑框重置为默认值，需再保存。
- 演奏页加载皮肤时读取 `content` + `option`：`registry.ts` 的 `PERFORM_SKIN_FACTORIES` 里有工厂的皮肤按 option 生成皮肤包，其余皮肤忽略 option。

空洞演奏皮肤（`Hollow`）的参数（`performSkin/hollow/option.ts`，非法或缺失字段回退默认值）：

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| `gradientStops` | 渐变色标数组 `{ color: '#RRGGBB', offset: 0~100 }`，2~6 个 | `#FF8A00 0`、`#FFD45C 40`、`#FFF6D6 55`、`#C86A00 100` |
| `flowSpeed` | 渐变流动速度 0~100：0 静止，50 约 2.3 秒一个周期，100 约 0.8 秒 | 50 |
| `glowStrength` | 光晕强度 0~100：0 无光晕，60 为基准倍率 1，100 约 2 倍 | 60 |

演奏皮肤 **不** 把样式 JSON 存数据库，只存 `content` 名称；样式在代码库维护。社区功能不支持用户自制演奏皮肤。

## 二期规划（社区）

- 允许用户下载除 **演奏皮肤** 外的藏品（演奏皮肤依赖内置 Vue 组件）。
- 下载入库：`is_built_in = false`，`owned` 由购买/下载流程置 `true`。
- 用户可在列表删除自己下载的藏品；内置藏品始终不可删。
