# 本地数据库（SQLite）

单机模式，无用户表。JSON 字段均以 **TEXT 字符串** 存储。

## score（曲谱）

仅存打谱数据，供曲谱编辑器读写。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 曲谱名称 |
| data | TEXT | 曲谱 JSON 字符串（渲染插件格式） |
| thumbnail | TEXT | 曲谱缩略图（预留，可为空） |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

## work（作品）

作品内容为 `.sjw` 文件（zip），落盘在 `userData/resources/sjw`；库中只存元数据与绝对路径。可选 `score_id` 关联独立曲谱表（便于提取曲谱；嵌入谱仍在 sjw 内）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 作品名称 |
| score_id | INTEGER FK score(id) | 关联曲谱，可为空 |
| url | TEXT | `.sjw` 文件绝对路径（磁盘唯一文件名 = `basename(url)`，创建时自动生成） |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

创建 / 更新（带 file）会写入或覆盖对应路径下的 `.sjw`；删除会软删库记录并删除该文件。

## guitar_chord（吉他和弦符号）

模拟吉他用的和弦图，`data` 存完整 `tabChord` JSON（与 `@deciphony/renderer` / `ChordBuilder` 一致）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 和弦名（与 tabChord.name 同步，便于搜索） |
| data | TEXT | tabChord JSON 字符串 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

空表时会写入内置常用和弦种子。创建 / 编辑走 `ChordBuilder`，列表展示走 `Chord` 组件。

## audio（音频）

用户上传到软件目录的音频文件（目录：`userData/resources/audio`）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 用户起的展示名称 |
| url | TEXT | 文件绝对路径（磁盘唯一文件名 = `basename(url)`，创建时自动生成） |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

## image（图片）

用户上传到软件目录的图片文件（目录：`userData/resources/image`）。字段同 `audio`。

## video（视频）

用户上传到软件目录的视频文件（目录：`userData/resources/video`）。字段同 `audio`。

业务说明见 [藏品.md](./藏品.md)。

## collection（藏品）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| type | TEXT | 藏品类型：`tone_color` / `score_skin` / `piano_skin` / `perform_skin` |
| name | TEXT | 藏品名称 |
| content | TEXT | 藏品内容。音色、曲谱皮肤、钢琴皮肤为 JSON；演奏皮肤为内置名称 |
| description | TEXT | 藏品说明，可为空 |
| is_built_in | BOOLEAN | 是否内置（软件自带），默认 false |
| owned | BOOLEAN | 是否拥有，默认 false |
| level | INTEGER | 藏品级别 1（最低）~ 6（最高），默认 1 |
| thumbnail | TEXT | 藏品缩略图，可为空 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

### content 按类型

| type | content 含义 |
| --- | --- |
| tone_color | 音色 JSON，传入 NPlayer |
| score_skin | deciphony-renderer 皮肤 JSON |
| piano_skin | 钢琴皮肤 JSON：`Record<midi, { normal, press, active }>`（21~108），值为 `data:image/svg+xml;charset=utf-8,` + `encodeURIComponent(svg)` |
| perform_skin | 内置演奏皮肤名称（PerformSkinNameList） |

## 迁移

| id | 说明 |
| --- | --- |
| 001-init | 创建全部表（含 `work.url`、`audio` / `image` / `video`、`achievement_progress`、`note_slice_high_score`、`collection` 等），写入内置藏品种子 |

## achievement_progress（已解锁成就）

仅存解锁记录；完整成就列表与 `criteria` / `rewardCollectionId` 见 `src/renderer/src/constant/achievements.ts`。解锁成就时同步将对应 `collection.id` 的 `owned` 设为 `true`（见 [成就.md](./成就.md)）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| key | TEXT UNIQUE | 成就唯一标识 |
| completed_at | DATETIME | 完成时间 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

## note_slice_high_score（音符切切模式最高分）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| mode | TEXT | `arcade` / `endless` / `extreme` |
| difficulty | TEXT | `easy` / `standard` / `hard`（不含测试难度） |
| high_score | INTEGER | 该模式+难度下的历史最高分，默认 0 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

**唯一约束：** `(mode, difficulty)`。旧数据迁移时默认归入 `standard`。

业务说明见 [成就.md](./成就.md)。
