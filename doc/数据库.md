# 本地数据库（SQLite）

单机模式，无用户表。JSON 字段均以 **TEXT 字符串** 存储。

## score（曲谱）

仅存打谱数据，供曲谱编辑器读写。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 曲谱名称 |
| data | TEXT | 曲谱 JSON 字符串（渲染插件格式） |
| thumbnail | TEXT | 曲谱缩略图（预留，可为空） |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

## work（作品）

作品内容为 `.sjw` 文件（zip），落盘在 `userData/resources/sjw`；库中只存元数据与绝对路径。可选 `score_id` 关联独立曲谱表（便于提取曲谱；嵌入谱仍在 sjw 内）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 作品名称 |
| score_id | INTEGER FK score(id) | 关联曲谱，可为空 |
| url | TEXT | `.sjw` 文件绝对路径（磁盘唯一文件名 = `basename(url)`，创建时自动生成） |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

创建 / 更新（带 file）会写入或覆盖对应路径下的 `.sjw`；删除会软删库记录并删除该文件。

## guitar_chord（吉他 / 尤克里里和弦符号）

模拟吉他用的和弦图，`data` 存完整 `tabChord` JSON（与 `@deciphony/renderer` / `ChordBuilder` 一致）；`hand_pose` 存按弦手型；`tab_type` 区分四弦 / 六弦。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 和弦名（与 tabChord.name 同步，便于搜索） |
| data | TEXT | tabChord JSON 字符串 |
| hand_pose | TEXT | FingerPoseMap JSON（可空，未编辑时为 null） |
| tab_type | TEXT | `tab4`（尤克里里四弦）或 `tab6`（吉他六弦）；创建后不可改 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

`001-init` 会写入内置吉他九和弦（C/G/Am/Em/D/F/E/A/Dm，固定 id 1~9，含手型，均为 tab6）与同名尤克里里九和弦（id 101~109，GCEA 开放把位，无手型，tab4）。已有同 id 或同名同类型不覆盖。首次打开模拟吉他时，主键盘 1~9 会绑定吉他九和弦。

创建时须指定 tab4/tab6，`ChordBuilder` 禁用修改 `stringCount`；列表可按类型筛选。编辑走 `ChordBuilder`，列表展示走 `Chord` 组件；手型在「和弦手」弹窗中编辑。

## drum_machine（电子鼓机谱）

模拟乐器 → 电子鼓机保存的鼓机谱。音色为藏品「打击乐」（id 26，`da-ji-yue.json`，进入鼓机时从数据库读取），键含义见 `constant/drumMachine.ts` 的 `DRUM_SOUND_LIST`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 鼓机名称（1~100 字） |
| data | TEXT | `DrumMachineData` JSON 字符串 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

`data` 结构（时值单位 Unit256：全音符 256、四分 64）：

```json
{
  "version": 1,
  "bpm": 110,
  "volume": 0.5,
  "swing": 0,
  "swingUnit": 32,
  "pattern": {
    "totalUnits": 512,
    "tracks": [
      {
        "id": "t1",
        "sound": 12,
        "volume": 0.8,
        "muted": false,
        "solo": false,
        "blocks": [{ "duration": 16, "active": true }, { "duration": 16, "active": false }]
      }
    ]
  }
}
```

鼓机谱本体只放在 `pattern`；`bpm` / `volume` / `swing` / `swingUnit`（摇摆单位，Unit256 取 128/64/32/16/8：推迟起点满足 `start % (2 × unit) === unit` 的块；缺省或非法值为 32）为播放配置。每轨 `blocks` 时值之和恒等于 `pattern.totalUnits`。

# 藏品 / 作品关系

### 数据关系

```
score (曲谱 JSON)
  ↑ score_id（可选）
work.url → userData/resources/sjw/*.sjw
```

业务说明见 [藏品.md](./藏品.md)。

## collection（藏品）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| type | TEXT | 藏品类型：`tone_color` / `score_skin` / `piano_skin` / `perform_skin` |
| name | TEXT | 藏品名称 |
| content | TEXT | 藏品内容。音色、曲谱皮肤、钢琴皮肤为 JSON；演奏皮肤为内置名称 |
| description | TEXT | 藏品说明，可为空 |
| is_built_in | BOOLEAN | 是否内置（软件自带），默认 false |
| owned | BOOLEAN | 是否拥有，默认 false |
| level | INTEGER | 藏品级别 1（最低）~ 6（最高），默认 1 |
| thumbnail | TEXT | 藏品缩略图，可为空 |
| option | TEXT | 可调参数 JSON 字符串，非空，默认 `'{}'`。金色及以上带参数的皮肤（如空洞演奏皮肤）在种子里有默认值，用户修改后写回；启动同步不覆盖用户保存的值 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

### content 按类型

| type | content 含义 |
| --- | --- |
| tone_color | 音色 JSON，传入 NPlayer |
| score_skin | deciphony-renderer 皮肤 JSON |
| piano_skin | 钢琴皮肤 JSON：`Record<midi, { normal, press, active }>`（21~108），值为 `data:image/svg+xml;charset=utf-8,` + `encodeURIComponent(svg)` |
| perform_skin | 内置演奏皮肤名称（PerformSkinNameList） |

## 迁移

| id | 说明 |
| --- | --- |
| 001-init | 创建全部表（含 `work.url`、`audio` / `image` / `video`、`achievement_progress`、`note_slice_high_score`（含 `notation` 列与 `(mode, difficulty, notation)` 唯一索引）、`collection`（含 `option` 列）、`drum_machine` 等），写入内置吉他 / 尤克里里 / 五弦贝斯和弦种子 |

只有这一条迁移，旧库不做升级：表结构变更后需删除用户数据目录下的 `database/app.db` 重新建库。

内置藏品初始 `owned`：`DEFAULT_BUILTIN_COLLECTION_OWNED_IDS`（**全部音色**、默认曲谱皮 id=7、默认演奏皮 id=10、经典纯色钢琴皮 id=12），其余皮肤类为 `false`；成就解锁后通过 `collection:update` 置 `true`。级别见 `BUILTIN_COLLECTION_LEVELS`（`collectionSeedIds.ts`）。

## note_slice_high_score（音符切切模式最高分）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| mode | TEXT | `arcade` / `endless` / `extreme` |
| difficulty | TEXT | `easy` / `standard` / `hard`（不含测试难度） |
| notation | TEXT | 谱面模式 `staff`（线谱）/ `jianpu`（简谱），默认 `staff` |
| high_score | INTEGER | 该模式+难度+谱面模式下的历史最高分，默认 0 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

**唯一约束：** `(mode, difficulty, notation)`（索引名 `note_slice_high_score_mode_difficulty_notation`）。极限模式固定 `difficulty = 'standard'`，但同样区分 `notation`。

业务说明见 [成就.md](./成就.md)。
