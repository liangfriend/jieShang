# 本地数据库（SQLite）

单机模式，无用户表。JSON 字段均以 **TEXT 字符串** 存储。

## score（曲谱）

仅存打谱数据，供曲谱编辑器读写。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 曲谱名称 |
| data | TEXT | 曲谱 JSON 字符串（渲染插件格式） |
| thumbnail | TEXT | 曲谱缩略图（预留，可为空） |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

## work（作品）

在曲谱之上叠加画笔、媒体、音频等。曲谱本体在 `score` 表，通过 `score_id` 关联，便于从作品 **单独提取曲谱**。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 作品名称 |
| score_id | INTEGER FK score(id) | 关联曲谱，可为空（草稿） |
| data | TEXT | 作品扩展 JSON，例：`{ brushStrokes, mediaResourceIds, audioResourceIds, layers }` |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

### 数据关系

```
score (曲谱 JSON)
  ↑ score_id
work (画笔 / 媒体 / 音频等 JSON)
```

业务说明见 [藏品.md](./藏品.md)。

## collection（藏品）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| type | TEXT | 藏品类型：`tone_color` / `score_skin` / `piano_skin` / `perform_skin` |
| name | TEXT | 藏品名称 |
| content | TEXT | 藏品内容。音色、曲谱皮肤、钢琴皮肤为 JSON；演奏皮肤为内置名称 |
| description | TEXT | 藏品说明，可为空 |
| is_built_in | BOOLEAN | 是否内置（软件自带），默认 false |
| owned | BOOLEAN | 是否拥有，默认 false |
| level | INTEGER | 藏品级别 1（最低）~ 6（最高），默认 1 |
| thumbnail | TEXT | 藏品缩略图，可为空 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

### content 按类型

| type | content 含义 |
| --- | --- |
| tone_color | 音色 JSON，传入 NPlayer |
| score_skin | deciphony-renderer 皮肤 JSON |
| piano_skin | 钢琴皮肤 JSON：`Record<midi, { normal, press, active }>`（21~108），值为 `data:image/svg+xml;charset=utf-8,` + `encodeURIComponent(svg)` |
| perform_skin | 内置演奏皮肤名称（PerformSkinNameList） |

## 迁移

| id | 说明 |
| --- | --- |
| 001-init | 创建全部表（含 `achievement_progress`、`note_slice_high_score`、`collection` 等），写入内置藏品种子；`note_slice_high_score` 含 `mode`+`difficulty` 唯一 |

内置藏品初始 `owned`：仅 `DEFAULT_BUILTIN_COLLECTION_OWNED_IDS`（三角钢琴 id=1、默认曲谱皮 id=7、默认演奏皮 id=10、经典纯色钢琴皮 id=12），其余为 `false`；成就解锁后通过 `collection:update` 置 `true`。级别见 `BUILTIN_COLLECTION_LEVELS`（`collectionSeedIds.ts`）。

## achievement_progress（已解锁成就）

仅存解锁记录；完整成就列表与 `criteria` / `rewardCollectionId` 见 `src/renderer/src/constant/achievements.ts`。解锁成就时同步将对应 `collection.id` 的 `owned` 设为 `true`（见 [成就.md](./成就.md)）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| key | TEXT UNIQUE | 成就唯一标识 |
| completed_at | DATETIME | 完成时间 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

## note_slice_high_score（音符切切模式最高分）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| mode | TEXT | `arcade` / `endless` / `extreme` |
| difficulty | TEXT | `easy` / `standard` / `hard`（不含测试难度） |
| high_score | INTEGER | 该模式+难度下的历史最高分，默认 0 |
| created_at | DATETIME | |
| updated_at | DATETIME | |
| deleted_at | DATETIME | 软删除 |

**唯一约束：** `(mode, difficulty)`。旧数据迁移时默认归入 `standard`。

业务说明见 [成就.md](./成就.md)。
