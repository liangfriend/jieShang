# 作品页架构

## 布局

# 编辑页（`/work-edit`）

- 左：缩略图栏（加页 / 插入 / 删页）
- 中：`@deciphony/work` 的 `SJWPDF`
- 右：工具栏
  - **绘制**：开始/取消绘制；画笔 / 橡皮；笔触大小（画笔默认 3，橡皮默认 20）；可清空本页笔迹
  - **素材库**：弹窗分类图片 / 音频 / 视频（视频元素包内未就绪，仅提示）
  - **文本**：内容、字号（默认 16）、颜色 → 放到 (100,100)
  - **曲谱**：从我的曲谱选择，缩放默认 0.5，放到 (100,100)

## 设置按钮
作品编辑页上方加一个设置按钮，点击打开设置弹窗：
新页大小 两个数字input, 默认值， 然后右侧有个全页应用，这个按钮点击后所有页都会改成这个大小
+ 已实现：顶栏「设置」→ 新页宽高（默认 794×1123）+「全页应用」；加页/插入页使用该尺寸

## 右键菜单

选中element
+ 删除


# 展示页（`/work-show`）

无右侧工具栏；顶栏可切回编辑。

## 顶栏

- 展示 / 编辑：对齐曲谱 `edit` ↔ `play`，query 走 `workId` / `tempId`
- 保存：弹窗填名称、作者；新建入库，已有则更新；`.sjw` 写入 `userData/resources/sjw`，`work.url` 存绝对路径
- 导入 / 导出：`.sjw`（加载用 `app-image://sjw/{basename}`）

## 临时缓存（对齐 tempScoreMap）

- `tempWorkMap`：当前编辑中的 `SJW` 引用
- `tempWorkBlobMap`：含资源的 sjw 快照，切页/重进时 `loadSjw` 恢复 AssetMap
- 常量：`editNewWork` / `curShowWork`

新建未保存进展示再离开 ≈ 未保存丢弃（与曲谱一致）。

## 入口

- 首页「我的作品」→ 列表
- 列表「新建」→ `/work-edit?tempId=editNewWork`
- 列表卡片 → `/work-show?workId=…`
