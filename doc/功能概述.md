是一个工具软件同时也是一个社交软件，一个游戏
游戏是靠独立的剧本故事支撑的。

### 首页
+ 剧情，点击弹出弹窗，展示所有正方形剧本卡片
  + hover剧本，句本卡片被遮罩，中间浮出文字“开始游戏”
  + 如果没有开始过任意游戏，点击进入
  + 如果已经处于某个剧本的进度，点击先显示提示框，“开始新游戏会覆盖当前游玩游戏进度，确认继续吗？”
+ 继续游戏，继续当前游戏进度
+ 藏品，这个内容后续在写，先加个按钮
  + 音色
  + 曲谱皮肤
  + 琴键皮肤
  + 播放特效
+ 曲谱制作，点击弹出弹窗，选择模版
  + 模版：空， 单声部，双声部
  + 点击模版后，直接进入曲谱编辑模式
+ 我的曲谱，点击进入曲谱列表页，上方筛选框，下方曲谱卡片
  + 筛选框，暂时只有个名称模糊搜索
  + 曲谱卡片，展示曲谱缩略图卡片，下面有名称, 点击进入曲谱播放模式
+ 教学白板
  + 谱子区，默认展示一个全屏的复谱表，不可以鼠标添加音符，但是点击下面的钢琴可以添加音符
  + 虚拟钢琴区， 展示虚拟钢琴
  + 功能区
+ 素养训练营，里边各种素养训练游戏

### 曲谱编辑器play.vue
播放模式
+ 播放暂停停止，因为播放是一个按钮，三个按钮都要显示，不过不同播放状态要禁用
+ 单行模式/普通模式切换
+ 练习模式，进入practice.vue页面
+ 新手模式，进入forBeginner.vue页面

### 练习模式 practice.vue
展示单行模式的曲谱
页面分成四部分，上边是曲谱，中间是瀑布流，下边是虚拟钢琴，最底部是功能区
底部功能区，有播放,暂停,停止，，不过不同播放状态要禁用。设置

+ 开始播放， 点击开始播放会响一小节预备拍节拍器，然后播放
+ 设置，点击显示遮罩，打开设置弹窗
  + 是否实时显示音符结果， 弹对弹晚弹早弹错漏弹的音符以不同的颜色显示出来
  + 是否显示虚拟钢琴
  + 是否显示瀑布流
  + 曲谱音量
  + 节拍器音量
  + bpm
  + 是否播放过程开启节拍器
  + 禁用单谱表，使用一个组件列出曲谱的所有单谱表，取单谱表最多的复谱表的单谱表数量，列出switch,默认都都开着的
    + 关闭某一单谱表后，那个单谱表会变透明，并且瀑布流相关的水流也会变透明
  + 是否虚拟钢琴按键提示， 这个开启后，下批音符的琴键会出现红色高亮，下下批音符会出现蓝色高亮，如果下下批和下批音符有重合的键，显示绿色
  + 附录：显示琴键颜色含义，音符颜色含义

### 新手模式 forBeginner.vue
页面：上边是曲谱下边是虚拟钢琴，中间的瀑布流替换成了彩色midi块。大小均匀，颜色不相邻。只要弹对了就会下落且没有动画

+ 开始练习，没有预备拍，高亮当前待弹奏琴键
+ 设置，点击显示遮罩，打开设置弹窗
  + 是否显示虚拟钢琴
  + 是否显示midi块
  + 节拍器音量
  + 是否播放过程开启节拍器
  + + 禁用单谱表，使用一个组件列出曲谱的所有单谱表，取单谱表最多的复谱表的单谱表数量，列出switch,默认都都开着的
  + 关闭某一单谱表后，那个单谱表会变透明，并且瀑布流相关的水流也会变透明
  + 是否虚拟钢琴按键提示， 这个开启后，下批音符会出现红色高亮，下下批音符会出现蓝色高亮，如果下下批和下批音符有重合的键，显示绿色
  + 附录：显示琴键颜色含义，音符颜色含义
