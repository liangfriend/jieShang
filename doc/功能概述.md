## 虚拟钢琴（VirtualPiano）

各页面共用 `virtualPiano.vue` 组件，通过是否监听 `@key-down` / `@key-up` 决定是否发声。

| 页面 | 点击琴键是否发声 | 说明 |
| --- | --- | --- |
| 练习模式 `practice.vue` | **否** | 未绑定 key 事件；仅琴键按下视觉反馈 + `midiStore` 同步（供瀑布流等使用） |
| 新手模式 `forBeginner.vue` | **音量 > 0 时** | 底部工具栏调音量与音色；`volume=0` 等效静音，仅琴键按下视觉反馈 |
| 教学白板 `TeachingWhiteboardView.vue` | **是** | 绑定 `@key-down` → `playStore.triggerNote`，`@key-up` → `releaseNote`；音色使用当前藏品 id（与播放/练习页共用 `playStore.collectionToneColorId`） |

钢琴皮肤：各页面 VirtualPiano 均读取 localStorage 中当前使用的 `virtualPianoSkin` 藏品 id，从数据库加载皮肤包渲染。

  + 内置皮肤在 `builtinSkins.ts` 定义白键/黑键各一套，migration 时循环展开；也可换线上 svg 路径
+ 演奏皮肤(pianoWaterfall和pianoMidiBox的瀑布流加基准线加背景算是一套)
  + `svg.ts`：`bg` 背景、`baseline` 基准线、`baselineMidiActive` midi 按下时基准线琴键位高亮
  + 这个太过复杂，只能内置几个vue组件了
