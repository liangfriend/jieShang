### 练习模式 practice.vue
展示单行模式的曲谱
页面分成五部分，上边是曲谱紧接着是实时详情信息，中间是瀑布流，下边是虚拟钢琴，最底部是功能区
练习模式开始播放前要打一小节节拍
音符要判定perfect good early late miss
首先是highlightPolicy

实时详情信息
展示：音符总数：漏弹数：谈早数：弹晚数：及格数：优秀数：完美数：实时分：总分
音符总数会去掉休止符，延音线会保留第一个音符
评分逻辑：
漏弹*0+弹早&弹晚*50+及格*60+优秀*80+完美*100 / 音符总数*100
实时分就是除以当前已弹奏音符数*100

+ 设置，播放过程禁用，点击显示遮罩，打开设置弹窗
  + 是否实时显示音符结果， 弹对弹晚弹早弹错漏弹的音符以不同的颜色显示出来
  + 是否遮盖瀑布流，用一个可爱背景图挡住瀑布流
  + 曲谱音量
  + 节拍器音量
  + bpm
  + 是否播放过程开启节拍器
  + 禁用单谱表，使用一个组件列出曲谱的所有单谱表，取单谱表最多的复谱表的单谱表数量，列出switch,默认都都开着的
    + 关闭某一单谱表后，那个单谱表会变透明，并且瀑布流相关的水流也会变透明
  + 是否虚拟钢琴按键提示， 这个开启后，下批音符的琴键会出现红色高亮，下下批音符会出现蓝色高亮，如果下下批和下批音符有重合的键，显示绿色
  + 难度，定义新手 老手 大师 三个预先定义好的pianoWaterfall HighlightPolicy参数，默认是新手
  + 附录：显示琴键颜色含义，音符颜色含义
+ 播放
+ 暂停
+ 停止
+ 清空弹奏数据
