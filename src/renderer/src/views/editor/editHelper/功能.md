## 高频几何预览：`updateVDom(targetId, patch)` + `scoreWriteGate.patch`

凡是指针/滑块会频繁改 Frame 或附属 `data`、从而触发整谱 `musicScoreToVDom` 的操作，一律走门禁（不限 slur）：

| 场景 | preview API | patch 来源 |
|------|-------------|------------|
| 连音线拖拽 | `previewSlurDrag` | `slurVDomPatch` |
| volta 拖拽 | `previewVoltaDrag` | 相对 base 的 x/y/w/h |
| 五线谱音符头 region | `updateNoteHeadDragFromPointer` | 直接写 `region`（与 test 一致，整谱刷新） |
| 简谱音符头唱名 | `updateNumberHeadDragFromPointer` | 直接写 `syllable`/`octaveDot`（与 test 一致，整谱刷新） |
| Tab 弦位 | `previewTabHeadRegionDrag` | `shiftVDomPatch`（相对 baseRegion） |
| relativeX 滑块 | `previewRelativeX` | `frameShiftVDomPatch` |

约定（实现见 `scoreWriteGate.ts`）：

1. **立刻改视图**：`musicScoreRef.updateVDom(targetId, patch)` —— 按 id 找到现有节点，**原地 assign**（不换数组、不换节点引用）。
2. **改源数据**：`scoreWriteGateFor(musicScore, getUpdateVDom?, getVDomList?).patch({ key, mirror?: { targetId, patch }, commit, delay? })`。默认 `delay = 100ms`，同一 `key` 只保留最后一次 `commit`。
3. **结构变更**（增删音符/小节等）用 `delay: 0`，立刻 `commit`。
4. **补丁基准**：整谱渲染后调用 `captureScoreVDomBaseline`；`findScoreVDom` 读冻结基准（不是被 `updateVDom` 改过的 live）。绝对补丁 = 基准几何 + (preview − 已落盘 relative*)，禁止对 live 节点叠增量。**音符头拖 region / 八度时跳过克隆**（renderEditTest 本来就不做），松手再补一帧，避免大谱每步深拷贝整表卡顿。
5. **把手叠层**：拖拽中把手用独立 override（`slurHandleOverride` / `voltaHandleOverride`），不要为了跟手去改编辑器的 `vDomList`。
6. 卸载或 pointerup 时 `flushScoreWrites(musicScore)`，避免未落盘的 commit 丢失。
