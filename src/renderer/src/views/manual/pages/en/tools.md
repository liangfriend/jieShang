Tools is a set of small utilities that come in handy while you practice. Click "Tools" on the home screen to open it.

| Tool | Purpose | Required device |
| --- | --- | --- |
| [Tuner](#tool-tune) | Tune a guitar, bass, or ukulele | Microphone |
| [Metronome](#tool-metronome) | Click a beat at a set tempo and time signature | None |
| [Pitch detection](#tool-pitch) | Show the note name and frequency you sing or play in real time | Microphone |
| [Microphone check](#tool-mic) | Make sure your microphone picks up sound | Microphone |
| [MIDI device check](#tool-midi) | Make sure your MIDI keyboard is connected and sends correct signals | MIDI keyboard |

If you run into problems such as "Singing mode doesn't respond" or "keys don't respond in the game", start by checking your devices with Microphone check and MIDI device check.
