Beginner mode has **no tempo limit**: you move on to the next step only after you hold down every key that needs to be pressed at the same time. It's ideal when you've just started learning a piece and can't keep up with the tempo yet.

## Layout

It's similar to [Practice mode](#play-practice): the score is at the top and an on-screen piano is at the bottom. The difference is that the waterfall is replaced by a stack of **colored blocks**, where each layer is the set of keys to press next.

## How to play

1. Click "Start practice". One measure of metronome clicks plays first as a count-in.
2. Look at the bottom layer of blocks and press the matching keys. Notes that start together (such as a chord) form one layer and must be **held down at the same time**.
3. Once every key is correct, the blocks drop and you move to the next step. On the score, the notes you need to play now are shown in red and finished notes turn green; the score also scrolls automatically to the current position.
4. After the last step, practice ends automatically and the colors are cleared.

- There's no time limit and no early/late judgment. Wrong keys don't cost points; you just won't advance.
- Beginner mode has no score and no pause button, and results aren't saved.

## Input methods and sound

| Input method | Advances? | Makes sound? |
| --- | --- | --- |
| MIDI keyboard | Yes | Yes, using the tone selected in the toolbar |
| Clicking the on-screen piano | Yes | Yes |
| Computer keyboard | Yes | Yes, same as a MIDI keyboard |

For the computer keyboard layout and usage, see "Playing with the computer keyboard" in [Practice mode](#play-practice). Beginner mode **doesn't play the score**: the only sound you hear is what you play yourself.

## Toolbar

| Button | Description |
| --- | --- |
| Back | Return to Play mode |
| Settings | Open "Beginner mode settings"; only available while stopped |
| Start practice / Stop | Start or end |
| Volume | 0–100%, default 100%; controls the sound of your playing |
| Tone | The tone used for your playing; can only be changed while stopped |
| Score type / Transpose / Up ½ / Down ½ | Same as in [Play mode](#play-features), but the change is only temporary |
| Shortcuts | Shows the computer keyboard key map; see [Practice mode](#play-practice) |
| Hide score / Show score | Hide the score and watch only the colored blocks |

If the score has no playable notes, you'll see "No notes to practice in this score".

## Beginner mode settings

| Group | Setting | Description |
| --- | --- | --- |
| Display | Cover MIDI blocks | Off by default. When on, the colored blocks are covered, so you can only follow the score or play by ear |
| Sound | Virtual piano volume | 0–100, default 100; controls the sound of your playing. This is the same setting as "Volume" in the toolbar, so changing either one changes both |
| Metronome | Metronome volume | 0–100, default 80 |
| Metronome | BPM | 40–240; defaults to the score's tempo. Affects only the count-in and the metronome, not your playing |
| Metronome | Metronome during practice | Off by default |
| Staff selection | Staff 1, 2… | All on by default. When you turn a line off, it becomes transparent and you no longer need to play it |

You can use "Staff selection" to practice only the right hand or only the left hand.
