Staff notation is the most widely used way of writing music. In staff notation, pitch is determined by a note's **position** on the five lines, so the note you add depends on where you click.

## Add toolbar

When editing staff notation, the toolbar in the top-left corner has two items:

| Item | Options | Default |
| --- | --- | --- |
| Add | Note / Rest | Note |
| Duration | Whole, half, quarter, eighth, 16th, 32nd, 64th, 128th | Quarter note |

The toolbar settings stay as they are until you change them. Dots, accidentals, and so on are changed in the property panel on the right after adding a note.

## Shortcuts

Like number notation, **the main-row digits and three letter rows enter notes by solfège**, and the numpad digits switch the duration. Solfège follows the measure's key signature (movable do: 1 = C in C major, 1 = G in G major); the middle octave is C4–B4 in treble clef and one octave lower in bass clef.

| Key | Function |
| --- | --- |
| Main row `1`–`7` | Append middle-octave do, re, mi, fa, sol, la, si to the end of the selected measure, using the toolbar duration |
| `Q` `W` `E` `R` `T` `Y` `U` | Append 1–7 one octave higher |
| `A` `S` `D` `F` `G` `H` `J` | Append middle 1–7 |
| `Z` `X` `C` `V` `B` `N` `M` | Append 1–7 one octave lower |
| Main row `0` / `~` / `I` / `K` | Append a rest to the end of the selected measure |
| Numpad `1`–`8` | Switch duration: 1 whole, 2 half, 3 quarter, 4 eighth, 5 16th, 6 32nd, 7 64th, 8 128th |
| Numpad `0` | Toggle between "Note" and "Rest" (used when adding with the mouse) |
| MIDI keyboard | With a measure selected, press a key to add a note of that pitch at the end of the measure, using the toolbar duration |

For common shortcuts, see [Edit mode](#score-edit).

## Staff-only features

- **Piano input**: play a MIDI keyboard to record a piano score in real time. See [Staff input by recording](#edit-piano-record).
- **Box selection**: raise or lower pitch and change durations in batch. See [Box-selecting notes](#edit-box-select).
- **Convert to number notation**: "Score type" in the top-right corner. See [Top toolbar](#edit-top).
- Measures can have a clef, key signature, and time signature. See [Measures](#edit-measure).
