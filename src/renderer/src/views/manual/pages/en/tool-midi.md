MIDI device check (the page is titled "MIDI device check") lets you confirm that your MIDI keyboard is connected and sending correct signals.

## Device list

The list has two columns, "Inputs" and "Outputs", showing each device's name, manufacturer, and connection status (Connected / Disconnected).

- Your MIDI keyboard should appear under "Inputs" and show "Connected".
- When there are no devices, "No MIDI inputs" is shown.
- When you plug in or unplug a device, a "MIDI device connected" or "MIDI device disconnected" notification pops up on any page of the app.

## Signal monitor

When you press keys, step on pedals, or turn wheels, the signals received are shown here in real time:

| Item | Description |
| --- | --- |
| Lamps | Activity (flashes whenever any signal arrives), Notes held, Sustain, Soft, Sostenuto |
| Meters | Pitch bend, Mod wheel, Expression, Volume CC7, Channel pressure, Poly aftertouch |
| Values | Channel, Program, Last note, Velocity, Held notes, Aftertouch note, Last CC, Source, Raw bytes |

"Reset signals" clears all readings.

## 88-key piano

The piano at the bottom of the page lights up along with your MIDI keyboard, so you can check that every key is recognized and maps to the right pitch. You can also click keys with the mouse to hear them.

## Troubleshooting

- **Your keyboard is not in the device list**: check the cable and power, try a different USB port, or unplug and replug it and wait for the notification.
- **You see "MIDI access not granted — allow and retry"**: allow access, then open this page again.
- **The key lamps light up but other features don't respond**: make sure no other software is using the MIDI device exclusively.

You can also check whether a MIDI keyboard is connected at a glance with the round icon in the lower-right corner of the home screen. See [Decipher](#jieshang).
