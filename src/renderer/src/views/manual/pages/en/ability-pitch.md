The Pitch sense test plays a note, and you find its note name on the piano. It tests your absolute pitch.

## Test settings

| Setting | Options | Default |
| --- | --- | --- |
| Pitch set | Pentatonic (the Chinese five tones, i.e. C D E G A) / Diatonic (7 notes) / Chromatic (12 notes) | Chromatic (12 notes) |
| Sound range | Standard (the octave containing middle C) / Full (all 88 piano keys) | Standard |
| Key labels | Text shown on the keys: Note names (C, C#…) / Solfege (do, di, re…) / Numbers (1, #1, 2…) | Note names |
| Rounds | 1–12 | 6 |
| Answer time (sec) | 3–20 | 8 |

## How the test works

1. Click "Start test", and a random note plays (the same note never comes up two rounds in a row).
2. To hear it again, click "Tap to replay" on the ring, as many times as you like.
3. On the one-octave piano below, click the note you think it is.
4. The correct key turns green, a wrong pick turns red, and the ring shows "Correct", "Wrong", or "Time out".

- Only the note name is judged, not the octave. For example, if a low C is played, clicking the middle C still counts as correct.
- If you haven't answered when the countdown ends, the round counts as "Time out".
- "Abort" takes you back to the settings page at any time.

## Results

- Accuracy (timeouts count as wrong).
- How many rounds were correct, wrong, and timed out.
- Average response time (excluding timeouts).
- Longest streak of correct answers.
