All Play mode features are in the bottom toolbar. During playback the score scrolls automatically to keep the note being played in the middle of the screen; when you stop, it returns to the beginning.

## Toolbar

From left to right:

| Button | Description |
| --- | --- |
| Back | Returns to the previous page |
| Edit mode | Stops playback and opens this score in Edit mode |
| Score / Vocal / Accompaniment | Chooses what to play; the default is "Score". "Vocal" and "Accompaniment" stay grayed out until you bind audio in [Score-audio sync](#edit-sync). You cannot switch while playing or paused; click "Stop" first |
| Play / Pause / Stop | After pausing, click "Play" again to continue from where you paused |
| Range | Plays only one section; see below. Available only with "Score" |
| Volume | 0–100%, default 100%. It also controls the volume of the vocal and accompaniment |
| BPM | Playback tempo, 40–240. The default is the score's tempo (converted so that a quarter note is one beat), or 120 if the score has no tempo. Hidden when playing the vocal or accompaniment |
| Tone | "Score setting" or any tone in your collection. You cannot switch while playing or paused; click "Stop" first. Tab and drum kit scores do not have this button |
| Score type | Temporarily switches the display between staff and number notation |
| Transpose | Choose a "Target key" and click "Transpose" to temporarily transpose the whole score to another key |
| Up ½ / Down ½ | Temporarily raises or lowers the whole score by a semitone |
| Marks | Shows xiao or dizi fingerings on number notation; see below |
| Practice mode / Beginner mode / Singing mode | Enters the corresponding sub-mode; see [Play mode](#score-play) |

"Score type", "Transpose", and "Up ½ / Down ½" cannot be used during playback, and tab and drum kit scores do not have them.

> "Score type", "Transpose", and "Up ½ / Down ½" only change the score you are currently viewing and are **not saved** to "My scores". If you click "Edit mode" at this point, these changes are carried into the editor and only take effect after you save there.

### Default tone

Each time you enter Play mode, the tone defaults to "Score setting", which uses the tone set for each single staff. Single staves without a tone use Grand piano.

## Playing a range

When you only want to listen to one section over and over:

1. Click "Range". A range bar appears above the score.
2. Click a note to set the **start** (shown in green). The prompt reads "Click another note to set the end".
3. Click another note to set the **end** (shown in blue).
4. Click "Play" to play only that section.

- Clicking a note again resets the start.
- On the range bar, "Clear range" clears the selected start and end, and "Exit range" leaves range selection.
- If you click Play before finishing your selection, you see "Pick the start and end notes first".
- Switching "Score / Vocal / Accompaniment" or "Score type" automatically exits range selection.

## Playing the vocal and accompaniment

After you bind a vocal or accompaniment in [Score-audio sync](#edit-sync), you can choose it in the drop-down:

- Real audio is played, and the score highlight moves according to the aligned times.
- If the audio is bound but not yet aligned, it still plays, but the score is not highlighted and you see "No vocal sync times on this score…".
- If the bound audio has been deleted from "My audio", you see "Bound audio not found".

## Xiao and dizi fingering marks

"Marks" shows the fingering below each note to make playing easier:

- **8-hole xiao**: xiao in C, ♭D, D, ♭E, E, F, ♭G, G, ♭A, A, ♭B, or B.
- **6-hole dizi**: dizi in low G, A, ♭B, C, D, E, F, or high G.
- Choose "None" to remove the marks. You can switch even during playback.

Choose the option in the same key as the instrument you are playing.

## Keyboard shortcuts

Play mode has no keyboard shortcuts; everything is done from the toolbar.
