On the home screen, click "My works" to open the list of works.

## List

- Works are sorted by **last modified time**, newest first.
- Each card shows the work's name; if it has no name, "?" is shown.
- **Click a card** to open that work in [Presentation mode](#work-show).
- If you have no works yet, you'll see "No works yet — create one".

## Creating a work

Click "New work" in the top-right corner to go straight to [Edit mode](#work-edit) with one blank page.

- A new work is only actually saved the first time you click "Save", and you'll be asked to enter a name for it.
- **If you click "Back" after creating a work without saving it, the work is lost immediately, with no warning.**

## Search

Type part of a work's name in the search box and the list filters automatically; if nothing matches, you'll see "No matching works". Click the clear button on the right of the box to show everything again.

## Deleting

Hover over a card and a red delete button appears in its top-right corner. Click it, confirm "Delete this work? This cannot be undone.", and click "Delete".

> Deleting also removes the work file, and it **cannot be recovered**. If you're not sure, first "Export" a .sjw file as a backup in Presentation mode.

## Import and export

The list page has no import or export buttons. Import and export are in the top toolbar inside a work; see [Presentation mode features](#work-show-features).

## Renaming

You enter a work's name the first time you save a new work. To change the name or author later:

1. Open the work in [Edit mode](#work-edit) and click "Settings" at the top.
2. Change "Name" and "Author", then click "Apply".
3. Click "Save" at the top; only then is the new name written to the list of works.
