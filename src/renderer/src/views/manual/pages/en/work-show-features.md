## Top toolbar

| Button | Description |
| --- | --- |
| Back | Return to the list of works |
| Edit | Switch to [Edit mode](#work-edit) |
| Import | Choose a .sjw file and **replace** the current work with its contents; see below |
| Export | Export as "Decipher work (.sjw)", "Images" or "PDF"; see below |
| Volume | 0–100%, default 100%; controls the volume of score playback and of the vocal and accompaniment. Video and audio elements have their own volume and aren't affected by it |
| Temporary marks | "Annotate", "Pen", "Eraser", color, width, "Clear marks"; see below |

## Turning pages

Click a thumbnail on the left to switch pages. Presentation mode has no full screen, zoom or keyboard page turning.

## Temporary marks

While explaining in class, you can circle and draw directly on the page:

1. Click "Annotate" to start annotating.
2. Choose "Pen" or "Eraser".
3. You can pick a pen color (black by default); width ranges from 1 to 80, with a default of 3 for the pen and 20 for the eraser.
4. Drag the mouse on the page to draw; you can draw beyond the page edges.
5. Click "Annotate" again to stop annotating and get back to interacting with scores, videos and other elements.

- "Clear marks" clears marks on the **current page** only, and you can click it even when you're not annotating.
- Marks **aren't saved to the work**. They stay when you turn pages, and all disappear when you leave the work.
- For strokes you want to keep permanently, use "Start drawing" in Edit mode; see [Edit mode features](#work-edit-features).

> Strokes drawn in Edit mode are saved in the work and also show up in Presentation mode, but neither "Clear marks" nor the eraser can remove them. To delete them, go back to Edit mode, click "Start drawing" and erase them with the eraser, or click "Clear page strokes", then "Save".

## Export

| Format | Description |
| --- | --- |
| Decipher work (.sjw) | The complete work file, including all media; can be imported on another computer |
| Images | One PNG per page, exported at 2× resolution. A single-page work gives you one image; a multi-page work gives you a zip archive containing 01.png, 02.png… |
| PDF | One image per page, combined into a single PDF |

When exporting images and PDF:

- Audio elements don't appear in the images.
- Videos appear as their first frame; if that can't be read, they appear as a play icon on a black background.
- Temporary marks aren't exported.

While exporting, you'll see "Exporting… page X / Y".

## Import

Click "Import" and choose a .sjw file:

- The file's contents **replace the contents of the currently open work**, and you're taken back to page 1.
- Importing only changes what you currently see. To keep it, switch to Edit mode and click "Save"; **saving overwrites the current work**.

> To import a .sjw someone sent you as a new work, first click "New work" in the list of works, import into the new work, and then save.
