Welcome to Decipher! Decipher is a music app that combines a music game, score creation, piano practice and singing assessment, and teaching presentations in one place. Each item in the table of contents on the left is a page — click it to view it. Use the search box at the top to find pages by title or body text.

## Home page overview

From top to bottom, the home page is divided into several sections:

- **Game modes**: three cards — "Arcade mode", "Endless mode", and "Extreme mode". Click one to start playing right away. See [Main game](#game).
- **Main entries**: "My scores" and "My works". See [My scores](#scores) and [My works](#works).
- **More entries**: "Whiteboard", "Chord manager", "Ability tests", "Instruments", "My audio", "My images", "My videos", "Tools", "Collection", and "Achievements".
- **Footer**: the Decipher community QQ group number. If you run into any problems, you're welcome to ask in the group.

> When the window is short, the logo and app name at the top are hidden automatically to make room for the entries below.

## Settings

Click the gear button in the **bottom-left corner** of the home page to open the "Settings" dialog. All changes take effect immediately and are saved automatically; just click "Done" to close it.

| Setting | Description |
| --- | --- |
| Language | 中文 / English / 日本語. The whole interface switches to the selected language immediately |
| Arcade / Endless difficulty | Easy / Standard / Hard; Easy by default. Only affects Arcade mode and Endless mode; Extreme mode is not affected |
| Game notation | When the switch is on, "Number notation" is used; when it is off, "Staff" is used. Staff is the default. Applies to all three game modes |
| Note block sound | 0–100. The volume of the cue sound played when a note block appears in the game |
| User Manual | Opens this manual |

Game-related settings are read when you start a round. Changing them during a round does not affect the current round.

## MIDI keyboard

The round icon in the **bottom-right corner** of the home page shows the connection status of your MIDI keyboard:

- **Green**: connected. Hovering over it shows "MIDI keyboard connected".
- **Red**: not connected. Hovering over it shows "MIDI keyboard not connected".

When you plug in or unplug a MIDI device, the app shows a "MIDI device connected" or "MIDI device disconnected" message. The icon only shows status and cannot be clicked.

How much each feature needs a MIDI keyboard:

| Feature | MIDI keyboard needed? |
| --- | --- |
| Main game | **Required**. The game only accepts MIDI keyboard input |
| Staff input by recording ("Piano input") | **Required** |
| Practice mode, Beginner mode | Recommended. You can also click the on-screen piano with the mouse or play with your computer keyboard |
| Entering notes in Edit mode | Optional; supported for staff and number notation |
| Teaching whiteboard | Optional; you can also click the keys with the mouse or play with the computer keyboard |

To check whether your device is recognized and its signal is working, see [MIDI device check](#tool-midi).

## Microphone

[Singing mode](#play-singing), [Tuner](#tool-tune), [Pitch detection](#tool-pitch), [Microphone check](#tool-mic), and the microphone breath mode of the piccolo simulator need a microphone. Allow microphone access the first time you use them. You can first confirm that your microphone works in [Microphone check](#tool-mic).
