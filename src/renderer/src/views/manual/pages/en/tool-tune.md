The tuner listens to the open string you pluck through the microphone and tells you whether it is sharp or flat.

## Supported instruments

| Instrument | String pitches |
| --- | --- |
| Guitar: Standard (default) | Strings 6 to 1: E2 A2 D3 G3 B3 E4 |
| 4-string bass | E1 A1 D2 G2 |
| Ukulele | G4 C4 E4 A4 |

The reference pitch is fixed at A4 = 440 Hz.

## How to use

1. Detection starts automatically when you open the page (the first time, you need to allow microphone access). Use the button at the top to "Stop" or "Start" detection again.
2. Click the round note-name buttons next to the headstock to **choose the string to tune** (string 1 by default). The app does not detect which string you plucked.
3. Pluck that open string and let it ring out. "Calculating…" appears while the string sounds; once the sound stops, the needle moves to the result.
4. Turn the tuning peg as prompted, then pluck again to check:

| Prompt | Meaning |
| --- | --- |
| In tune! (green) | Within ±8 cents; this string is tuned |
| Tune up! | The pitch is flat; tighten the string a little |
| Tune down! | The pitch is sharp; loosen the string a little |
| Listening… | Waiting for you to pluck |

The left side of the dial is "Flat" and the right side is "Sharp", with a range of ±50 cents (100 cents is one semitone).

> Only the note name is checked, not the octave. A string that is off by a whole octave will still show "In tune!", so get the pitch roughly right before fine-tuning.
