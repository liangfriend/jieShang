The Key note name quiz is a series of multiple-choice questions: a key is highlighted on the piano, and you choose its note name from four options. It helps you learn your way around the keyboard. This test has **no sound**.

## Test settings

| Setting | Options | Default |
| --- | --- | --- |
| Pitch set | Pentatonic (C D E G A) / Diatonic (white keys) / Chromatic (including black keys) | Diatonic |
| Option labels | Note names / Solfege / Numbers / Mixed (each option randomly uses one of the styles) | Note names |
| Rounds | 1–12 | 6 |
| Answer time (sec) | 3–20 | 3 |

## How the test works

1. Click "Start test". One key on the one-octave piano is highlighted in blue, with the prompt "Name the highlighted key".
2. Click the correct note name among the 4 options below.
3. After showing whether you were right, the test moves on to the next round automatically.

- The highlighted key is chosen from the "Pitch set" and is never the same two rounds in a row. Wrong options can be any of the twelve notes, including black keys.
- If you haven't answered when the countdown ends, the round counts as "Time out". The default is only 3 seconds; if that feels too fast, make it longer.

## Results

Same as the [Pitch sense test](#ability-pitch): accuracy, number of correct / wrong / timed-out rounds, average response time, and longest streak.
