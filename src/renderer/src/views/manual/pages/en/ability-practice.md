Practice mode is like an [Extreme mode](#game-extreme) whose difficulty you set yourself: only one big note block is shown in the middle of the screen. It never disappears, and the next one appears only after you play it correctly. There are no lives, no time-outs, and no special blocks, so you can drill note reading at your own pace.

## Practice settings

"Practice settings" appear first. Your settings are remembered for next time.

| Setting | Description | Default |
| --- | --- | --- |
| Notation | Staff / Number notation | Staff |
| Clefs | Treble / Alto / Bass; choose any combination (staff only) | Treble, Bass |
| Key signatures | Any of the 15 key signatures, with "All" and "C only" shortcuts | C only |
| Accidentals | None / Sharps and flats / Including double sharps and flats (number notation has no doubles) | None |
| Range | Drag the slider to set the lowest and highest notes | D2–B5 (MIDI 38–83) |
| Number of notes | 1–10000, or tick "Unlimited" | 50 |
| Play each new note | Plays the pitch when a new block appears | On |
| Play sound when you press a key | The app plays a piano sound for your key presses; turn it off if your digital piano makes its own sound | On |
| Show virtual piano | Shows a piano at the bottom so you can answer with the mouse without a MIDI keyboard | On |

- On the staff, each clef has a fixed range: treble B3–B5, alto C3–C5, bass D2–D4. Parts of the range slider outside the chosen clefs never appear.
- Below the settings, "N notes can appear with these settings" tells you how many notes are possible. If it is 0 you can't start; widen the range, clefs, or key signatures.

## How it works

1. Click "Start practice". A note block appears in the middle; above it you see the "Done" and "Wrong" counts and the time, and the header shows "current note / total" (∞ when unlimited).
2. Play the note on your MIDI keyboard or the virtual piano. The pitch must match exactly, including the octave.
3. When you're right, the next block appears immediately. When you're wrong, it flashes red and shakes; the block stays so you can try again.
4. Practice ends automatically after the set number of notes. You can also click "Finish" at any time to see your results, or "Stop" to go straight back to the settings. With "Unlimited", practice continues until you finish or stop it.

- The same note never appears twice in a row (unless only one note is possible).

## Results

- **First-try accuracy**: the share of completed notes you played correctly on the first press.
- Notes completed, wrong presses, average time per note, longest first-try streak, and total time.
- "Practice again" restarts with the same settings; "Change settings" goes back to the settings page.

Practice results are not saved and don't count toward achievements or high scores.
