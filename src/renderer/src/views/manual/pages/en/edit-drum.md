A drum kit score is written on a five-line staff, but each line and space stands for **a drum or cymbal** rather than a pitch. Different **note head shapes** (normal, cross, triangle, and so on) also stand for different instruments or playing techniques.

A drum kit score has two voices: drums and cymbals played by hand usually go in **voice 1** (stems up), while the bass drum and hi-hat played with the feet go in **voice 2** (stems down).

## Add toolbar

| Item | Options | Default |
| --- | --- | --- |
| Voice | Voice 1 (up) / Voice 2 (down) | Voice 1 |
| Add | Note / Rest | Note |
| Note head | Normal, Cross, Circled cross, Circled slash, Triangle, Diamond | Normal |
| Duration | Quarter note to 128th note (drum kit scores go no longer than a quarter note) | Eighth note |
| Dot | None / Single dot / Double dot | None |

When you select one voice, the notes in the other voice turn gray so you can focus on the voice you are editing. Picking a note head automatically switches back to "Note".

## Shortcuts

| Key | Action |
| --- | --- |
| `A`–`T` (skipping `P`) | With a measure selected, adds the matching drum note at the end of the measure, using the voice, duration, and dot set in the toolbar (see the table below) |
| `3`–`8` | Changes the duration: 3 quarter … 8 128th. `1` and `2` do nothing |
| `0` | Toggles between "Note" and "Rest" |

Letter keys also work while your input method is in Chinese mode. Drum kit scores do not support MIDI keyboard input. For general shortcuts, see [Edit mode](#score-edit).

## Legal notes and letter keys

Only the "position + note head" combinations in the table below produce sound. Under "Legal notes" at the top right, you can see what each notation looks like and preview its sound.

| Key | Instrument | Position | Note head |
| --- | --- | --- | --- |
| `A` | Crash 2 | Space above the first ledger line above the staff | Cross |
| `B` | Chinese cymbal | Space above the first ledger line above the staff | Circled cross |
| `C` | Crash 1 | First ledger line above the staff | Cross |
| `D` | Hi-hat (open) | Space above line 5 | Circled cross |
| `E` | Hi-hat (half-open) | Space above line 5 | Circled slash |
| `F` | Hi-hat (closed) | Space above line 5 | Cross |
| `G` | High tom | Space above line 5 | Normal |
| `H` | Cowbell | Space above line 5 | Triangle |
| `I` | Ride cymbal | Line 5 | Cross |
| `J` | Ride bell | Line 5 | Diamond |
| `K` | Tom 1 (hi-mid) | Space 4 | Normal |
| `L` | Tom 2 (mid) | Line 4 | Normal |
| `M` | Snare | Space 3 | Normal |
| `N` | Side stick | Space 3 | Cross |
| `O` | Rim shot | Space 3 | Circled slash |
| `Q` | Tom 3 (floor) | Space 2 | Normal |
| `R` | Bass drum | Space 1 | Normal |

> There is no `P`: `P` is "copy to next measure"; see [Edit mode](#score-edit).

> Letter keys only set the position and note head; **the voice still comes from the toolbar**. For example, to enter a bass drum, remember to switch the voice to "Voice 2" first.

## Drum kit score limitations

- Drum kit score measures have no key signature. You can set the clef and time signature; see [Measures](#edit-measure).
- The tone of a drum kit score is fixed to percussion and cannot be changed.
- Drum kit scores cannot be converted to other score types.
