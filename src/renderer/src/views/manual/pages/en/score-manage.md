Score management is the "My scores" list page. Click "My scores" on the home page to open it.

## Browsing and searching

- Each score is shown as a card with the score's name on it; if the name is empty, "？" is shown.
- The list is sorted by last update time, with the most recently modified scores first.
- Type a keyword in the search box at the top; after a short pause, the list is fuzzy-searched by name automatically. Click the × on the right of the box to clear it.
- **Click a card** to enter that score's [Play mode](#score-play).
- Cards with a "Chords" badge in the top-left are [chord & lyric sheets](#cl-sheet); clicking one opens the chord sheet page.

## Creating a score

Click "New score" in the top-right corner and pick a template in the "Choose a template" dialog. You go straight to [Edit mode](#score-edit).

| Group | Templates |
| --- | --- |
| Staff | Empty / Single staff / Double staff |
| Number notation | Empty / Single staff / Double staff |
| TAB | Guitar tab / Ukulele tab / 4-string bass tab / 5-string bass tab / 6-string bass tab |
| Drum | Drum kit score |
| Chord & lyric sheet | Empty (opens the [chord & lyric sheet](#cl-sheet) page) |

A new score only appears in the list after you click "Save" in Edit mode.

> The score type is fixed when you create the score. Staff and number notation can still be converted to each other later; tab and drum scores cannot be converted to any other type after they are created.

## Importing existing score files

There's no import button on the list page; importing is done in Edit mode:

1. Click "New score" and pick any template to enter Edit mode.
2. Click "Import" in the top-right corner and choose the file format and the file. The imported content **overwrites** the current score.
3. Check that everything looks right, then click "Save".

See [Import and export](#edit-import-export) for supported formats and notes.

## Renaming

A score's name is its **title**. To rename a score, enter Edit mode, change the title at the very top of the score, and click "Save". If the title is empty, the score is saved as "Untitled score".

## Deleting

Hover over a card and a red trash-can button appears in its top-right corner. Click it, then click "Delete" in the "Delete score" dialog to confirm.

> Deleted scores **cannot be recovered**. For important scores, we recommend exporting an `.sj` file in Edit mode as a backup first.
