展示模式中，不同元素支持的操作不同。曲谱、图片、视频的功能都在**右键菜单**里。

## 曲谱

在曲谱上点右键，菜单中有：

| 菜单项 | 说明 |
| --- | --- |
| 播放 | 播放曲谱，正在播放的音符会高亮。速度取曲谱的速度。暂停后再点「播放」从暂停处继续 |
| 选段 | 只播放其中一段，见下文 |
| 播放范唱 | 播放这首曲谱绑定的范唱，曲谱按对齐时间高亮。没有范唱时是灰色的 |
| 播放伴奏 | 播放绑定的伴奏。没有伴奏时是灰色的 |
| 暂停 / 停止 | |
| 进入演唱模式 | 带着这首曲谱和它的范唱、伴奏进入 [演唱模式](#play-singing)。范唱和伴奏都没有时是灰色的 |

- 播放的音色：吉他、尤克里里谱用尼龙弦吉他，贝斯谱用原声贝斯，鼓谱用打击乐，其它用钢琴；曲谱中单谱表设置了音色时以设置为准。
- 曲谱播放和范唱 / 伴奏不能同时进行，开始一个会停止另一个。
- 曲谱的范唱、伴奏来自它在「我的曲谱」中通过 [谱音同步](#edit-sync) 绑定的音频，添加到作品时自动带上。

### 选段

1. 右键选择「选段」，页面上出现选段提示条。
2. 点击一个音符作为起点（绿色），再点击一个音符作为终点（蓝色）。
3. 点提示条上的「播放选段」，只播放这一段。

- 再点音符会重新设置起点。
- 提示条上还有「停止」「清空选段」「结束选段」。右键菜单中也有「清空选段」「结束选段」。
- 翻页、切换模式或开始标注时，选段会自动结束。

## 图片

右键选择「放大」，在弹窗中查看大图。

## 视频

- 直接在页面上播放：点击画面中间的播放按钮，或点击画面切换播放 / 暂停。鼠标移上去时，底部显示进度条、时间、音量和静音按钮。
- 右键选择「播放」或「放大」，会在弹窗中放大播放。

## 音频

音频元素是一个小播放器：播放 / 暂停、进度条、时间；鼠标移到音量图标上可以调节音量或静音。音频没有右键菜单。

## 文本

文本只用于显示，没有可操作的功能。
