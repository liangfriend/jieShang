五线谱（线谱）是最通用的记谱方式。在五线谱中，音高由音符在五线上的**位置**决定，所以鼠标点在哪里，就添加哪个音。

## 添加工具栏

编辑五线谱时，左上角的工具栏有两项：

| 项目 | 选项 | 默认 |
| --- | --- | --- |
| 添加 | 音符 / 休止符 | 音符 |
| 时值 | 全音符、二分、四分、八分、十六分、三十二分、六十四分、一百二十八分 | 四分音符 |

工具栏的设置会一直保留，直到你手动修改。附点、变音记号等在添加后到右侧属性栏中修改。

## 快捷键

五线谱和简谱一样：**主键盘的数字和三排字母直接按唱名输入音符**，小键盘的数字才是切换时值。唱名按小节的调号首调换算（C 大调 1 = C，G 大调 1 = G），高音谱号的中音是 C4–B4 一组，低音谱号低一个八度。

| 按键 | 作用 |
| --- | --- |
| 主键盘 `1`–`7` | 在选中小节的末尾添加中音 do、re、mi、fa、sol、la、si，时值取工具栏设置 |
| `Q` `W` `E` `R` `T` `Y` `U` | 添加高八度的 1–7 |
| `A` `S` `D` `F` `G` `H` `J` | 添加中音 1–7 |
| `Z` `X` `C` `V` `B` `N` `M` | 添加低八度的 1–7 |
| 主键盘 `0` / `~` / `I` / `K` | 在选中小节的末尾添加一个休止符 |
| 小键盘 `1`–`8` | 切换时值：1 全音符、2 二分、3 四分、4 八分、5 十六分、6 三十二分、7 六十四分、8 一百二十八分 |
| 小键盘 `0` | 在「音符」和「休止符」之间切换（影响鼠标点击添加） |
| MIDI 键盘 | 选中小节后按琴键，在小节末尾添加对应音高的音符，时值取工具栏设置 |

通用快捷键见 [编辑模式](#score-edit)。

## 五线谱特有的功能

- **钢琴录入**：用 MIDI 键盘弹奏，实时录成钢琴谱，见 [线谱录制录入](#edit-piano-record)。
- **框选**：批量升降音、改时值，见 [框选音符](#edit-box-select)。
- **转换为简谱**：右上角「曲谱类型」，见 [顶部功能](#edit-top)。
- 小节可以设置谱号、调号、拍号，见 [小节](#edit-measure)。
