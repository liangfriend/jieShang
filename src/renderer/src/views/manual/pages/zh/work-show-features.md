## 顶部工具栏

| 按钮 | 说明 |
| --- | --- |
| 返回 | 回到作品列表 |
| 编辑 | 切换到 [编辑模式](#work-edit) |
| 导入 | 选择一个 .sjw 文件，用它的内容**替换**当前作品，见下文 |
| 导出 | 导出为「解熵作品 (.sjw)」「图片」或「PDF」，见下文 |
| 音量 | 0–100%，默认 100%，控制曲谱播放和范唱、伴奏的音量。视频和音频元素有各自的音量，不受它影响 |
| 临时标注 | 「标注」「画笔」「橡皮」、颜色、粗细、「清空标注」，见下文 |

## 翻页

点击左侧的缩略图切换页面。展示模式没有全屏、缩放和键盘翻页。

## 临时标注

上课讲解时，可以直接在页面上圈画：

1. 点「标注」进入标注状态。
2. 选择「画笔」或「橡皮」。
3. 画笔可以选颜色（默认黑色）；粗细 1–80，画笔默认 3，橡皮默认 20。
4. 在页面上拖动鼠标绘制，可以画到页面外面。
5. 再点「标注」退出标注状态，恢复对曲谱、视频等元素的操作。

- 「清空标注」只清除**当前页**的标注，不进入标注状态也能点。
- 标注**不会保存到作品中**，翻页时保留，离开作品后全部消失。
- 想要永久保存的笔迹，请在编辑模式中使用「开始绘制」，见 [编辑模式的功能](#work-edit-features)。

> 编辑模式里画的笔迹会存进作品，在展示模式中也会显示，但「清空标注」和橡皮都清不掉它们。要删除，回到编辑模式，点「开始绘制」后用橡皮擦掉，或点「清空本页笔迹」，再「保存」。

## 导出

| 格式 | 说明 |
| --- | --- |
| 解熵作品 (.sjw) | 完整的作品文件，包含所有素材，可以在其它电脑上导入 |
| 图片 | 每页一张 PNG，按 2 倍清晰度导出。只有一页时直接得到一张图片，多页时得到一个压缩包，里面是 01.png、02.png…… |
| PDF | 每页一张图片，合成一个 PDF |

导出图片和 PDF 时：

- 音频元素不会出现在图片中。
- 视频显示为它的第一帧画面；读取不到时显示为黑底的播放图标。
- 临时标注不会导出。

导出过程中会显示「导出中… 第几页 / 共几页」。

## 导入

点「导入」选择一个 .sjw 文件：

- 文件中的内容会**替换当前打开的作品的内容**，并回到第 1 页。
- 导入只改变当前看到的内容，要保存需切换到编辑模式点「保存」，**保存后会覆盖当前作品**。

> 想把别人发来的 .sjw 导入成一个新作品，请先在作品列表点「新建作品」，在新作品中导入，再保存。
