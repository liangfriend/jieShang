和弦识别播放一个和弦，你从四个选项中选出它的名称。

## 测试设置

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 和弦范围（可多选） | 大三 / 小三 / 属七 / 大七 / 小七，至少选一种 | 大三、小三 |
| 声音范围 | 标准音（根音在中央 C 所在的八度）/ 全音（根音范围更广） | 标准音 |
| 显示钢琴 | 是否在答题区显示钢琴 | 开 |
| 纯听感 | 打开后作答时钢琴上不标出和弦，出结果后才显示。关闭「显示钢琴」时不可用 | 关 |
| 轮次 | 1–12 | 6 |
| 答题倒计时（秒） | 3–20 | 8 |

## 测试流程

1. 点「开始测试」，所有音同时响起，播放一个随机和弦（12 个根音 × 选中的和弦类型，不会连续两轮相同）。
2. 点圆环可以重播。
3. 在 4 个选项中选出和弦名称，例如「C 大三」「Cm」「C7」「Cmaj7」「Cm7」。根音一律用升号表示。
4. 显示对错后自动进入下一轮。

> 「显示钢琴」打开、「纯听感」关闭时，作答过程中钢琴上会用蓝色标出和弦的组成音，相当于给了提示。想只靠耳朵分辨，打开「纯听感」：作答时钢琴不标音，出结果后再用绿色标出正确的和弦，方便对照。

## 结果

除了正确率、正确 / 错误 / 超时轮数、平均作答时间、最长连对外，还会分别列出每种和弦类型的正确率，方便找出自己容易混淆的类型。
