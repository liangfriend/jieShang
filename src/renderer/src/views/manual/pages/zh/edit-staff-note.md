本页介绍五线谱中音符和休止符的添加、修改与删除。

## 用鼠标添加

1. 点击一个小节将它选中。
2. 把鼠标移到小节里（上下各 50 像素以内也可以，方便添加加线上的音），会出现一个半透明的**预览音符**，它的高低就是将要添加的音高。
3. 点击即可添加，时值取左上角工具栏的设置。

添加的位置取决于你点在哪里：

- 点在**两个音符之间**：插入一个新音符。
- 点在**已有音符上**、但高度不同：在这个音符上叠加一个音，组成**和弦**，时值和符杠沿用原来的音符。
- 点在已有音符上、高度相同：改为选中这个音符。
- 休止符只能插在音符之间，不能叠加。

新添加的音符不带变音记号；符干方向自动决定（在中线以上时朝下，否则朝上）。

## 用键盘 / MIDI 键盘添加

- 选中小节后按 MIDI 键盘上的琴键，在小节末尾添加对应音高的音符，会按小节的谱号和调号自动换算，需要变音时写成升号。
- 选中小节后按主键盘 `1`–`7` 或 `Q`–`U` / `A`–`J` / `Z`–`M` 三排字母，按唱名在小节末尾添加音符，`0` / `~` 添加休止符；小键盘数字切换时值。详见 [五线谱](#edit-staff) 的快捷键说明。

## 修改音高：拖动

选中音符后，按住符头**上下拖动**即可改变音高。如果同一个和弦里已经有符头在目标位置，拖动无效。

## 音符属性栏

点击一个音符将它选中，右侧显示「音符属性」，分为「属性」「记号」「连线」三个标签页。上次停留的标签页会被记住。

### 属性

**节奏**

- **时值**：全 / 二分 / 四分 / 八分 / 16分 / 32分 / 64分 / 128分。
- **附点**：无 / · / ·· / ···。
- **符杠**：全连 / 右连 / 无，控制八分及更短的音符与相邻音符如何用横杠连接。
- **符干方向**：向上 / 向下。

**音高**

- **变音符号**：无 / 升号 ♯ / 降号 ♭ / 重升 𝄪 / 重降 𝄫 / 还原 ♮。设置后会出现「横向偏移」滑块，用来微调变音记号的左右位置。
- **音符前谱号**：无 / 高音谱号 / 低音谱号 / 中音谱号 / 次中音谱号，在这个音符前临时换谱号，同样可以调横向偏移。

**横向偏移**：滑块 -40 到 40，微调整个音符的左右位置。

**倚音**

- 点「添加前倚音」或「添加后倚音」。新倚音默认是八分音符，音高和符干方向跟随主音。
- 下方列表显示已有的倚音，可以逐个删除。
- 在谱面上点击倚音可以单独选中它，属性栏变为「倚音属性」，可修改时值、符杠、符干方向、附点。

### 记号

添加重音、断奏、颤音、力度等单音符记号，见 [其它符号](#edit-symbols)。

### 连线

添加琶音、连音线、踏板、8va / 8vb、颤音线、渐强渐弱等跨音符记号，见 [其它符号](#edit-symbols)。

## 休止符属性栏

选中休止符时显示「属性」和「记号」两个标签页，可以修改时值、附点、横向偏移，也可以添加记号。

## 删除

- 选中后按 `Delete` 或 `Backspace`。
- 和弦中有多个音时，只删除选中的那一个；删到最后一个时，整个音符位置一起删掉。
- 挂在被删音符上的连音线等记号会一起清理。

## 多声部

五线谱目前没有声部切换功能，同一位置的多个音用和弦的方式叠加。
