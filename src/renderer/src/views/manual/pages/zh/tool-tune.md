调弦工具通过麦克风听你拨的空弦，告诉你音高是偏高还是偏低。

## 支持的乐器

| 乐器 | 各弦音高 |
| --- | --- |
| 吉他：标准（默认） | 6 弦到 1 弦：E2 A2 D3 G3 B3 E4 |
| 四弦贝斯 | E1 A1 D2 G2 |
| 尤克里里 | G4 C4 E4 A4 |

标准音固定为 A4 = 440 Hz。

## 使用步骤

1. 进入页面后会自动开始检测（第一次需要允许麦克风权限）。顶部按钮可以「停止」或重新「开始检测」。
2. 点击琴头旁边的圆形音名按钮，**选择要调的弦**（默认 1 弦）。软件不会自动识别你拨的是哪根弦。
3. 拨响这根空弦，等声音自然停下。拨弦时显示「计算中…」，声音停下后指针移动到结果位置。
4. 按提示拧弦轴，再拨一次确认：

| 提示 | 意思 |
| --- | --- |
| 准确！（绿色） | 误差在 ±8 音分以内，这根弦调好了 |
| 调高！ | 音偏低，把弦拧紧一些 |
| 调低！ | 音偏高，把弦放松一些 |
| 聆听中… | 等待拨弦 |

表盘左边是「偏低」，右边是「偏高」，范围 ±50 音分（100 音分为一个半音）。

> 判断时只看音名，不看八度。如果弦的音高差了一整个八度，也会显示「准确！」，所以请先大致确认音高再精调。
