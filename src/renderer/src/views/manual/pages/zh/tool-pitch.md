音高检测通过麦克风实时识别你唱或弹奏的音高，并显示在钢琴和人声音域上。可以用来练习唱准音，或者看看自己的音域。

## 使用步骤

1. 点「开始检测」，允许麦克风权限。
2. 对着麦克风唱或弹奏一个**稳定**的音。
3. 左侧「实时结果」显示音名、频率（Hz）和 MIDI 编号；右侧的竖向钢琴高亮对应的键。
4. 点「停止」结束。

没有检测到音高时显示「聆听中…发出稳定音高试试」。

## 静音门限

声音小于这个值时不识别，范围 0.005–0.1，默认 0.020。环境吵、经常误检时调高一些；声音小、识别不到时调低一些。

## 人声音域参考

右侧标出六种常见的人声音域，可以对照自己唱到的最高音和最低音：

| 音域 | 范围 |
| --- | --- |
| 男低音 | E2–E4 |
| 普通男性 | A2–A4 |
| 男高音 | C3–C5 |
| 女低音 | F3–F5 |
| 普通女性 | A3–A5 |
| 女高音 | C4–C6 |
