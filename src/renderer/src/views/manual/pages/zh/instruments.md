模拟乐器用电脑键盘和鼠标来演奏各种乐器。在首页点「模拟乐器」，选择一种乐器进入。

| 乐器 | 怎么演奏 |
| --- | --- |
| 吉他 | 数字键按和弦，小键盘拨弦 |
| 口琴 | 鼠标跟随，左键吹 / 右键吸 |
| 排箫 | 嘴位跟随鼠标，左键吹气 |
| 短笛 | 键盘按孔，麦克风吹气或空格发声 |
| 卡林巴 | 字母键弹奏，左右手对应左右琴键 |
| 电子鼓机 | 多轨步进编排，可保存与载入 |

- 模拟乐器**不支持 MIDI 键盘**。
- 每个乐器页面右上角都有「使用指南」。
- 「箫」还在开发中，暂时不能进入。
- 吉他、口琴、排箫、短笛、卡林巴需要拥有对应的音色藏品，默认全部已拥有。

## 跟着曲谱演奏

吉他、口琴、排箫、短笛、卡林巴的页面下方都有曲谱面板：在「选择曲谱」中选一首「我的曲谱」，点「播放」「暂停」「停止」，可以边听边跟着演奏。

## 吉他

标准调弦（E A D G B E）的六弦吉他，20 个品。上方左边是吉他，右边是当前和弦的和弦图；下方左边是曲谱区，右下角面板放着曲谱播放和下面这些吉他设置。

- **横向 / 竖向**：顶部「使用指南」左边的切换按钮。默认「横向」，吉他横放在上方；切到「竖向」后吉他立在左侧，和弦图移到吉他上方，右边整块留给曲谱区。选择会被记住。
- **选择弹唱谱**：面板里在「选择曲谱」下方，可以再选一份 [和弦弹唱谱](#cl-sheet)，显示在曲谱区。同时选了曲谱时，单行曲谱在上、弹唱谱在下；只选弹唱谱时弹唱谱占满曲谱区。内容放不下时可以上下、左右滚动查看。

- **按和弦**：按住主键盘的数字键 `1`–`9`，左手就按住对应的和弦；松开回到空弦。默认依次是 C、G、Am、Em、D、F、E、A、Dm。按住的弦会变成橙色，所按的品格发光，琴颈下方的橙色圆标出品号；拨到这根弦时高亮更亮。
- **拨弦**：小键盘 `1`–`6`（1 是最细的 1 弦），或用鼠标点击琴弦。闷音（×）的弦不发声。
- **快捷和弦设置**：修改 `1`–`9` 绑定的和弦，和弦来自 [和弦管理](#chords) 中的六弦和弦。
- **和弦符号管理**：打开和弦管理页面。
- 右下角面板显示「当前和弦」的名称，吉他右边显示对应的和弦图。
- **平缓**：让声音更柔和，默认关闭。

## 口琴

- 口琴跟随鼠标左右移动，只有红色嘴框内的孔会发声。
- 按住**左键吹气**，按住**右键吸气**。
- **口琴种类**：「10 孔 C 调布鲁斯」或「24 孔 C 调复音」（默认）。
- **嘴部大小**：嘴框覆盖几个孔，0.5–8。
- **平缓**：默认关闭。

## 排箫

- 移动鼠标，红色箭头对准一根竹管，按住**左键吹气**。按住左键滑动可以连续换音。同一时间只有一根管发声。
- **排箫种类**：「16 管 C 调」（默认，G4–A6）或「18 管 C 调」（G4–C7）。
- **平缓**：默认打开。

## 短笛

六孔 G 调短笛。

- **按孔**：笛头朝左时，按住 `Q` `W` `E` `P` `O` `I` 按住六个孔，`A` `S` `D` `L` `K` `J` 按半孔；笛头朝右时，`O` `I` `U` `Q` `W` `E` 按孔，`L` `K` `J` `A` `S` `D` 按半孔。也可以用鼠标：左键按孔，右键按半孔。
- **吹气方式**：
  - 「麦克风」（默认）：进入页面后打开麦克风，对着麦克风吹气发声。吹得越用力声音越大；同一个指法能吹出不同八度时，气越急音越高。旁边的「气压」条显示当前气压。
  - 「空格」：按住空格键发声，只吹最低的八度。
- 右侧显示当前音名和音区；指法不对应任何音时提示「该指法没有对应的音」。
- 麦克风打不开时，请检查权限，或切换为「空格」模式。

## 卡林巴

- **卡林巴种类**：「17 音 C 调」（默认，C4–E6）或「21 音 C 调」（F3–E6）。
- 最低音在正中间，对应 `G` 键，向两边交替升高：左边依次是 `F` `D` `S` `A` `T` `R` `E` `W` `Q` `B`，右边依次是 `H` `J` `K` `L` `Y` `U` `I` `O` `P` `N`。
- 也可以用鼠标左键按住音片。
- **平缓**：默认打开。

## 电子鼓机

用网格编排鼓点节奏，可以保存下来反复使用。

- 每一行是一个音轨（一种鼓声），每一格是一个时间点。**左键点亮，右键熄灭，按住拖动可以连续绘制。**
- 默认 9 个音轨，最多 24 个，底部「添加音轨」。每个音轨可以「试听」、「独奏」(S)、「静音」(M)，「更多」中有整轨网格、反选、清空本轨、删除音轨。
- 设置：

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| BPM | 40–240 | 110 |
| 总音量 | 0–100% | 50% |
| 摇摆 | 0–60%，让节奏带一点「晃」的感觉，可选作用的音符单位 | 0 |
| 总时值（拍） | 1–64 拍 | 8 拍 |

- 顶部可以「新建」「打开」「保存」「另存为」，并给鼓机命名。有未保存的改动时会显示「未保存」，离开前会提醒。
- 快捷键：`空格` 播放 / 停止，`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。
