本页介绍鼓谱中音符和休止符的添加、修改与删除。

## 用鼠标添加

1. 点击一个小节将它选中。
2. 在左上角工具栏选好声部、音符头、时值和附点。
3. 把鼠标移到小节里，会出现一个半透明的**预览音符**，上下移动选择位置（线或间）。
4. 点击即可添加。

添加的位置取决于你点在哪里：

- 点在**两个音符之间**：插入一个新音符。
- 点在**已有音符上**、但位置不同：在同一时刻叠加一个音符头，例如军鼓和踩镲同时敲。
- 点在已有音符上、位置相同：改为选中这个音符头。
- 休止符只能插在音符之间。

只会在当前选择的声部中插入或叠加。

## 用键盘添加

选中小节后按 `A`–`T` 字母键（跳过 `P`），在当前声部的末尾添加对应的鼓音符，见 [架子鼓谱](#edit-drum) 中的对照表。

## 修改位置：拖动

选中音符头或休止符后，按住它**上下拖动**即可改变所在的线或间。

## 音符属性栏

选中音符头后，右侧显示「音符属性」，和五线谱一样分为「属性」「记号」「连线」三个标签页。

### 属性

| 项目 | 说明 |
| --- | --- |
| 音符头 | 普通、叉号、叉号加圆、斜线加圆、三角形、菱形 |
| 线位 | 用数字表示位置：0 是第一线（最下面的线），每升高一个线或间加 1，8 是第五线（最上面的线）。范围 -6 到 14 |
| 时值 | 四分音符到一百二十八分音符，修改的是整个音符（同一时刻的所有音符头） |
| 附点 | 无 / 单附点 / 双附点 |
| 符杠 | 全连 / 右连 / 无 |
| 倚音 | 添加前倚音 / 后倚音，音符头和线位与主音相同 |

修改「音符头」和「线位」时，请对照 [架子鼓谱](#edit-drum) 中的合法音符表，不在表中的组合播放时没有声音。

### 记号

给选中的音符头添加重音、断奏、力度等单音符记号，见 [其它符号](#edit-symbols)。

### 连线

添加琶音、前奏括号、连音线、踏板、8va / 8vb、颤音线、渐强渐弱等跨音符记号，见 [其它符号](#edit-symbols)。只在同一声部中向右数音符。

## 休止符属性栏

选中休止符时显示「属性」和「记号」两个标签页。

| 项目 | 说明 |
| --- | --- |
| 时值 | 四分音符到一百二十八分音符 |
| 附点 | 无 / 单附点 / 双附点 |
| 线位 | -6 到 14，点「居中」放回第三线 |

## 删除

- 选中后按 `Delete` 或 `Backspace`。
- 同一时刻有多个音符头时，只删除选中的那一个。
