「我的音频」「我的图片」「我的视频」是你的素材库。在首页点击对应的入口进入，三者的用法相同。

## 素材用在哪里

| 素材 | 用途 |
| --- | --- |
| 音频 | 在 [谱音同步](#edit-sync) 中绑定为曲谱的范唱或伴奏；在 [作品](#work-edit-features) 中添加为音频元素 |
| 图片 | 在作品中添加为图片元素，或设置为页面背景 |
| 视频 | 在作品中添加为视频元素 |

## 添加

点右上角「添加音频」「添加图片」或「添加视频」，在弹出的窗口中选择文件，可以一次选择多个。暂不支持拖入文件。

支持的格式：

| 类型 | 格式 |
| --- | --- |
| 音频 | mp3、wav、ogg、flac、m4a、aac、webm、aiff |
| 图片 | png、jpg、gif、webp、bmp、svg |
| 视频 | mp4、webm、mov、mkv、avi、m4v |

素材名称取自文件名（不含扩展名），目前添加后不能改名。

## 查找和预览

- 搜索框可以按名称查找，列表按最近修改时间排列。
- **音频**：卡片上可以直接播放、停止、拖动进度，同一时间只播放一条。点击卡片查看详情：时长、采样率、声道、文件大小、格式、添加时间。
- **图片**：点击卡片查看详情：尺寸、文件大小、格式、添加时间。
- **视频**：卡片显示第一帧画面和时长，点击卡片可以播放，并查看时长、分辨率、文件大小、格式、添加时间。

## 删除

点卡片上的删除按钮，确认后删除。删除会同时删掉文件，**无法恢复**。

> 如果删除的音频已经绑定为某首曲谱的范唱或伴奏，播放时会提示「未找到绑定音频」，需要重新绑定。

## 备份

素材文件保存在软件的数据文件夹中。Steam 云存档只同步数据库，**不包含**这些素材文件，换电脑时请自行备份原文件。
