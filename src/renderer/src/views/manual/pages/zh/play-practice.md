练习模式像音乐游戏一样：音符从上方落下，落到琴键上时按下对应的键，软件会判定你按得准不准。

## 界面

从上到下依次是：

- **曲谱**：整首曲谱拼成一长行，播放时自动滚动。
- **统计栏**：音符总数、漏弹、弹早、弹晚、及格、优秀、完美、实时分、进度。
- **瀑布流**：覆盖 88 个琴键，音符块落到底部时就是该按下的时刻。
- **屏幕钢琴**。
- **工具栏**。

## 工具栏

| 按钮 | 说明 |
| --- | --- |
| 返回 | 回到播放模式 |
| 设置 | 打开「练习设置」，见下文。只能在停止时打开 |
| 播放 | 开始练习。从停止状态开始时，会先响一小节节拍器作为预备拍 |
| 演示播放 | 先倒数 3 秒，然后自动演奏一遍，所有音符都判为完美，琴键也会亮起，可以先看一遍怎么弹。演示时变为「停止演示」 |
| 暂停 / 停止 | 暂停后再点「播放」直接继续，不再响预备拍 |
| 音色 | 曲谱播放使用的音色，只能在停止时修改 |
| 曲谱类型 / 转调 / 升半音 / 降半音 | 与 [播放模式](#play-features) 相同，只是临时改变 |
| 清空弹奏数据 | 清空统计和曲谱上的颜色 |
| 快捷键 | 打开电脑键盘键位图，见下文「电脑键盘弹琴」 |
| 隐藏曲谱 / 显示曲谱 | 隐藏后只看瀑布流练习 |

## 怎么弹

可以用以下三种方式输入：

- **MIDI 键盘**（推荐）。
- **鼠标**点击屏幕钢琴。
- **电脑键盘**，见下文「电脑键盘弹琴」。

> 三种方式按下的键都会发出钢琴声，音量由「练习设置」中的「虚拟钢琴音量」控制，调到 0 就只听曲谱的播放。演示播放时自动弹奏的键不会额外发声。

### 电脑键盘弹琴

电脑键盘按简谱排列（1 = C），按下的效果和 MIDI 键盘完全一样：发声、点亮琴键、参与判定。不用打开任何东西就能弹。

点工具栏的「快捷键」会弹出键位图：每个键帽上标着对应的简谱音和高低八度点，按下的键会亮起。按住弹窗标题栏可以拖动，再点一次「快捷键」或点右上角 × 关闭。

默认音高（C4 是中央 C）：

| 按键 | 音高 |
| --- | --- |
| 数字行 `1`–`7`，`8`–`=` | C5–B5，C6–G6 |
| `Q`–`U`，`I`–`\` | C4–B4，C5–A5 |
| `A`–`J`，`K`–`'` | C3–B3，C4–F4 |
| `Z`–`M`，`,`–`/` | C2–B2，C3–E3 |
| 小键盘 `0` `.` | A3、B3 |
| 小键盘 `1`–`7` | C4–B4 |
| 小键盘 `8` `9` `/` `*` `-` `+` `Enter` | C5–B5 |

- 按住 **Shift** 再按，升高半音（弹黑键）。
- 键位图下方有两个八度设置：「字母侧八度」整体升降主键盘区，「小键盘八度」整体升降小键盘区，范围 −3 到 +3，旁边显示 `Q` 键和小键盘 `1` 当前对应的音。设置会自动保存，练习模式、新手模式和教学白板共用。
- 超出 88 键范围的键不发声，键帽上的数字变淡。
- 按住 Ctrl、Alt、Win，或光标在输入框里时，按键不会弹琴。

## 判定规则

- 只判定**按下的时刻**和音符开始时刻之间的差距，松开的时间和按住多久不判定。
- 按错的键如果不在任何音符的判定范围内，直接忽略，不扣分。
- 音符过了判定范围还没按，记为「漏弹」。
- 瀑布流始终按速度往下走，**不会等你**。想按自己的节奏练，请用 [新手模式](#play-beginner)。

判定范围（毫秒，正负表示早或晚）：

| 难度 | 完美 | 优秀 | 及格 | 弹早 / 弹晚 |
| --- | --- | --- | --- | --- |
| 新手（默认） | ±90 | ±140 | ±200 | ±260 |
| 老手 | ±35 | ±60 | ±100 | ±150 |
| 大师 | ±20 | ±35 | ±60 | ±100 |

**实时分**是已判定音符的平均分：完美 100、优秀 80、及格 60、弹早 / 弹晚 50、漏弹 0。**进度**是已判定的音符占全部音符的比例。

统计在曲子结束后保留在屏幕上，下次从头「播放」或点「清空弹奏数据」时清零。练习结果不会保存，也不计入成就。

## 曲谱上的颜色

打开「实时显示音符结果」后，曲谱上的音符会按判定结果变色：

| 结果 | 颜色 |
| --- | --- |
| 完美 | 彩虹渐变 |
| 优秀 | 绿色 |
| 及格 | 橙色 |
| 弹早 | 浅蓝色 |
| 弹晚 | 浅粉色 |
| 漏弹 | 红色 |

停止时可以按住 `Shift` 滚动鼠标滚轮，左右查看曲谱。

## 练习设置

| 分组 | 设置 | 说明 |
| --- | --- | --- |
| 显示 | 实时显示音符结果 | 默认打开 |
| 显示 | 遮盖瀑布流 | 默认关闭。打开后用一张背景图挡住瀑布流，只能凭耳朵和曲谱练习 |
| 音量与速度 | 曲谱音量 | 0–100，默认 100 |
| 音量与速度 | 虚拟钢琴音量 | 0–100，默认 100。你按键发出的声音，和曲谱音量分开调。曲谱音量为 0 时按键也会静音 |
| 音量与速度 | 节拍器音量 | 0–100，默认 80，预备拍也用这个音量 |
| 音量与速度 | BPM | 40–240，默认取曲谱的速度 |
| 音量与速度 | 播放过程开启节拍器 | 默认关闭。打开后整个练习过程中节拍器一直响 |
| 声部选择 | 单谱表 1、2…… | 默认全部打开。关闭某一行后，这一行变淡，**既不判定也不播放** |
| 难度 | 新手 / 老手 / 大师 | 默认新手，判定范围见上表 |

练习模式没有「左手 / 右手」选项。钢琴谱通常第一行是右手、第二行是左手，可以用「声部选择」只练其中一只手。

设置在软件关闭前一直保留，重新打开软件后恢复默认。
