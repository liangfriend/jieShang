编辑模式用来制作作品：管理页面、添加元素、摆放位置、裁剪曲谱和图片。

进入方式：

- 在作品列表点「新建作品」。
- 在展示模式点顶部的「编辑」。

## 界面

- **左侧**：页面缩略图，下方有「加页」「插入」「删页」「复制」按钮。
- **中间**：当前页面，点击元素将它选中。
- **右侧**：「工具」面板，用来绘制、设置背景、添加素材、文本和曲谱。
- **右上角**：选中曲谱、图片或文本后出现的「属性」面板。
- **顶部**：「撤销」「恢复」「设置」「展示」「保存」以及导入、导出、音量。

## 基本流程

1. 在右侧「工具」中添加曲谱、素材或文本。新添加的元素都放在页面左上方 (100, 100) 的位置。
2. 拖动元素调整位置，拖动四角调整大小。
3. 需要更多页面时，在左侧点「加页」或「插入」。
4. 点「保存」。

> **编辑模式没有自动保存，离开时也不会提示保存。** 记得经常点「保存」。
