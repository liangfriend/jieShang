编辑模式右上角的「导入」「导出」用来和其他软件交换曲谱，也可以用来备份。

## 导入

> 导入会**覆盖当前曲谱**的全部内容。导入后请检查一遍，再点「保存」。

| 选项 | 文件类型 | 说明 |
| --- | --- | --- |
| 解熵曲谱 (.sj) | `.sj` | 解熵自己的曲谱格式，原样还原 |
| MusicXML | `.xml`、`.musicxml` | 通用的乐谱交换格式，不支持压缩格式 `.mxl` |
| MIDI | `.mid`、`.midi` | 导入后**一定是五线谱** |
| 图片转谱(简谱) | PNG、JPG、WebP、BMP 图片 | 识别图片中的简谱 |

导入成功会提示「已导入 文件名」。

### MIDI 导入规则

- 按十六分音符量化，太细碎的节奏会被对齐到十六分音符。
- 每个音轨的每个通道生成一个单谱表；音域很宽的钢琴音轨会在中央 C 处自动拆成高低两行。
- 第 10 通道（打击乐）会被忽略。
- 不支持的拍号会改为 4/4；有多个速度时只保留第一个。
- 每行排 4 个小节，跨小节的音用连音线连接；有多个谱表时自动加花括号。
- 有内容没能保留时，会提示「MIDI 部分内容未能保留」，并列出原因。

### 图片转谱（简谱）

1. 选择「图片转谱(简谱)」，打开转谱窗口。**只能识别简谱。**
2. 点击或拖入图片，可以一次添加多张（例如一首歌的好几页）。可以上移、下移、按文件名排序、移除；点缩略图可以放大查看。
3. 点「开始生成」，软件逐张识别并显示进度，每张图片会显示识别出的行数、小节数、调号、拍号和提示。识别过程中可以停止。
4. 识别失败的图片会标红。可以替换图片后重试，也可以跳过失败的图片，用其余图片生成。
5. 多张图片按列表顺序拼成一份曲谱。全曲的调号、拍号取第一个识别到的；某一页的调号或拍号有变化时，会写到该页的第一个小节上。
6. 生成结果会覆盖当前曲谱，可以用 `Ctrl+Z` 撤销。

> 识别结果难免有误差，生成后请对照原图检查一遍，再保存。

## 导出

| 选项 | 说明 |
| --- | --- |
| 解熵曲谱 (.sj) | 完整保存曲谱，可以在解熵中原样导入，适合备份和分享 |
| MusicXML(ms4) | MusicXML 4.0，适用于较新的打谱软件 |
| MusicXML(ms3) | MusicXML 3.1，兼容 MuseScore 3 等较旧的软件 |
| MIDI | 每个单谱表导出为一条音轨 |
| 作品 | 把曲谱排进一个新作品，按页面大小自动分页，见下文 |

简谱导出 MusicXML 时，会先自动转成按 C 调拼写的五线谱再导出。

### 导出为作品

1. 选择「导出」→「作品」，弹出设置窗口。
2. 选一个页面模板（A4、A5、B5、Letter、16:9 等，纸张分纵向和横向），或直接填页面宽高。
3. 设置**曲谱宽度**：曲谱按这个宽度等比缩放。
4. 设置**曲谱上边距**：曲谱从页面顶部往下多少开始排。
5. 点「确定」，软件新建一个作品并进入作品编辑：
   - 每页的曲谱横向居中，从上边距开始排；
   - 一页放不下时，放不下的复谱表整行移到下一页，页面底部也留出同样的边距；
   - 标题放在第一页。

作品在保存前不会出现在「我的作品」里，检查无误后记得保存。上次填写的设置会被记住。
