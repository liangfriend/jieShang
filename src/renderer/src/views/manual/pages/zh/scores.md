「我的曲谱」是解熵的核心：你可以在这里新建、编辑、播放曲谱，再用这些曲谱练琴、唱歌、做作品。

从首页点「我的曲谱」进入曲谱列表。每首曲谱有两个主要模式：

- **播放模式**：在列表中点击曲谱卡片进入。可以试听、转调、选段播放，并从这里进入练习、新手和演唱模式。
- **编辑模式**：新建曲谱时，或在播放模式中点「编辑模式」进入，用来写谱、改谱。

## 支持的曲谱类型

| 类型 | 能做什么 |
| --- | --- |
| 线谱（五线谱） | 编辑、播放、练习、演唱；可以和简谱互相转换 |
| 简谱 | 同上 |
| TAB 谱 | 吉他谱、尤克里里谱、四 / 五 / 六弦贝斯谱。可以编辑、播放；不能转换类型，不能进入练习、新手、演唱模式 |
| 鼓谱 | 架子鼓谱。可以编辑、播放；限制同 TAB 谱 |

## 常见流程

1. 在 [曲谱管理](#score-manage) 中新建曲谱。已有 MusicXML、MIDI、简谱图片等文件，可以在编辑模式中 [导入](#edit-import-export)。
2. 在 [编辑模式](#score-edit) 中写谱、改谱，完成后点「保存」。
3. 回到列表点击曲谱，进入 [播放模式](#score-play) 试听。
4. 用 [练习模式](#play-practice)、[新手模式](#play-beginner) 练琴，或用 [演唱模式](#play-singing) 测评演唱。
5. 想把曲谱和图片、视频、文字组合成课件，可以在 [我的作品](#works) 中把曲谱添加进作品。
