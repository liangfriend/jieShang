「谱音同步」用来把一段真实的音频（范唱或伴奏）和曲谱对齐：告诉软件每个音符在音频的第几秒出现。对齐之后，播放模式和演唱模式就能**播放这段音频，同时让曲谱高亮跟着走**，演唱模式还会按这个时间来判定你唱得准不准。

入口：编辑模式底部工具栏的「谱音同步」，会从底部弹出谱音同步面板。

> 使用前需要先把音频文件添加到 [我的音频](#media)。

## 名词解释

- **范唱**：带人声的示范演唱音频。
- **伴奏**：不带人声的伴奏音频。
- 一首曲谱可以同时绑定一个范唱和一个伴奏，两者分别对齐，各有一套时间。

## 面板布局

**第一行设置：**

| 设置 | 说明 |
| --- | --- |
| 时间属性 | 「范唱」或「伴奏」，表示你现在正在对齐哪一个，默认「伴奏」 |
| px/s | 每秒对应的像素宽度，20–400，默认 80。数值越大，波形和音符拉得越开，越方便精细调整 |
| 采样率 | 默认 44100，一般不需要修改 |
| 选择音频 | 从「我的音频」中选择一个音频，用来显示波形和播放 |

**第二行：**「绑定范唱」「绑定伴奏」，分别指定这首曲谱的范唱音频和伴奏音频，都从「我的音频」中选择。切换「时间属性」时，「选择音频」会自动换成对应绑定的音频。

**主体区域（从上到下）：**

1. **音频波形**。
2. **展平谱**：把曲谱的反复展开，多个复谱表按单谱表行接成一长条。同一个音符如果因为反复会播放多遍，就会对应多个可以拖动的框。
3. **红色播放指针**：竖贯波形和展平谱，上方显示当前秒数。停止时可以拖动指针改变播放位置；播放时画面自动滚动，让指针保持在中间。

**底部按钮：**

| 按钮 | 作用 |
| --- | --- |
| 前奏时间 | 填写音频开头到第一个音符之间的秒数 |
| 重置对齐 | 按曲谱的速度、时值、反复和前奏时间，重新计算所有音符的理论时间 |
| 播放 | 从指针位置开始播放音频 |
| 停止 | 暂停播放，指针停在原位 |
| 重置 | 指针回到 0 秒，不改动音符时间 |

## 对齐步骤

1. 在「绑定范唱」或「绑定伴奏」中选好音频。
2. 「时间属性」选择要对齐的那一个（范唱或伴奏）。
3. 听一下音频，量出第一个音符出现的秒数，填入「前奏时间」，点「重置对齐」，得到一个大致对齐的结果。
4. 点「播放」，边听边看指针和音符框。哪里对不上，就在展平谱上**左右拖动音符框**，把它对准音频中实际出现的位置。
5. 对齐完成后关闭面板，回到编辑器点「保存」。

> 面板中**没有单独的保存按钮**。绑定和对齐结果直接写进当前曲谱，必须回到编辑器点「保存」才会真正保存。

## 限制

- 各复谱表的单谱表行数必须一致，否则无法展平，面板会显示错误提示。
- 曲谱中有空的复谱表时也无法展平。
- 时间轴最长 10 分钟。

## 对齐之后

- **播放模式**：底部「曲谱 / 范唱 / 伴奏」下拉框选择「范唱」或「伴奏」，播放音频时曲谱按对齐时间高亮，见 [功能](#play-features)。
- **演唱模式**：可以选择范唱或伴奏作为音源，判定按对齐时间进行，见 [演唱模式](#play-singing)。
- 如果绑定了音频但没有对齐，播放时会提示「当前曲谱还没有范唱的谱音同步时间」（伴奏同理）。
