除了音符和休止符，曲谱上还可以添加各种记号。它们分为三类：挂在**单个音符**上的记号、跨越**多个音符**的记号，以及挂在**小节**上的反复记号。

## 单音符记号

选中一个音符（或休止符），在右侧属性栏切换到「记号」标签页（标签上的数字表示已有记号的数量）。点击图标添加，再点一次取消。

| 分组 | 记号 | 说明 |
| --- | --- | --- |
| 奏法 | 重音、断奏（跳音）、短断奏、保持音、次断奏、强重音、重音 + 断奏、强重音 + 断奏、强重音 + 保持音、短断奏（竖线）、短断奏（楔形）、强调、保持音 + 重音、弱化 | 可以同时添加多个 |
| 技巧 / 弓法 | 开放音、闷音、泛音、上弓、下弓、换气 | 可以同时添加多个 |
| 装饰音 | 回音、逆回音、颤音 tr、短颤音（顺波音）、波音（逆波音） | 组内只能选一个 |
| 力度 | ppp、pp、p、mp、mf、f、ff、fff、fp、pf、sf、sfz、sffz、sfp、rfz、rf、fz | 组内只能选一个 |
| 古筝指法（仅简谱） | 托、劈、抹、挑、勾、剔、打、摘、提、拨、小撮、大撮 | 组内只能选一个 |
| 古筝技法（仅简谱） | 扫、摇指 | 可以和指法同时添加 |

图标的样子取决于当前使用的曲谱皮肤。

### 调整与删除记号

在谱面上点击某个记号即可选中它，记号周围出现虚线框，右侧有绿色的移动按钮，拖动它可以微调位置。属性栏会显示「记号属性」：

- **X / Y**：精确输入位置偏移。
- **重置位置**：恢复默认位置。
- **删除**：删除这个记号，也可以直接按 `Delete`。
- **替换为**：换成同组的其它记号，并保留位置偏移。

> 有些记号在谱面上不容易点中，可以在音符的「记号」页中再点一次图标取消。

## 跨音符记号

选中一个音符，在属性栏切换到「连线」标签页。

### 列级符号

- 「添加琶音」「添加前奏括号（」「添加前奏括号）」。
- 琶音只作用于当前音符所在的这一列，每列最多一个。已经添加过的符号不再显示对应按钮。

### 添加跨音符记号

1. 先选择「跨度」：从当前音符起向右覆盖 1 / 2 / 3 / 4 个音符。
2. 再点要添加的记号：连音线、踏板、高八度 8va、低八度 8vb、颤音线、渐强、渐弱。简谱还有古筝连续指法：连托、连劈、连抹、连挑、连勾、连剔、连打、连摘。
3. 连音线至少要跨 2 个音符。如果终点那一列有多个音（和弦），可以选择连到哪个音。

后续音符只在当前小节和下一小节内查找，音符不够时会提示。

### 从此音符开始

「连线」页下方列出从这个音符开始的所有跨音符记号，可以直接删除；连音线还可以调线宽（2–12）。没有时显示「暂无」。

## 选中跨音符记号后

在谱面上点击这些记号可以选中它们（需要精准点到符号本身），右侧显示对应的属性：

| 记号 | 可调整的内容 |
| --- | --- |
| 连音线 | 线宽；覆盖范围（左扩、右扩、左缩、右缩、重置对齐）；和弦时的起止音；起止点位置；居中控制点（简谱没有）。可以在谱面上拖动手柄调整形状。「应用当前位置到」可以把当前形状批量应用到本小节 / 单谱表 / 复谱表 / 全谱的其它连音线 |
| 八度记号 | 高八度 / 低八度 |
| 颤音线 | 起始符号：tr / 上行颤音 / 下行颤音 / 长颤音；两端和中间有把手可以拖动 |
| 渐强 / 渐弱 | 样式（楔形或 cresc. / dim. 文字线），楔形可以调开口高度；两端和中间有把手可以拖动 |
| 古筝连续指法 | 指法（连托 / 连劈 / 连抹 …）、覆盖范围、起止点位置；两端和中间有把手可以拖动 |
| 踏板 | 没有专门的属性 |
| 琶音 | 样式（波浪线 / 直线）、箭头、重置位置 |
| 连谱号 | 连谱号类型，可以应用到全部行 |

选中后按 `Delete` 即可删除。

## 反复房子（Volta）

反复房子在 [小节](#edit-measure) 属性栏的「反复」分组中添加。在谱面上点击房子即可选中，属性栏显示「Volta 属性」：

- **文案**：房子上显示的文字，例如「1.」。
- **反复值**：表示第几遍播放时经过这个房子（从 1 开始），可以「添加」多个，至少保留一个。
- **覆盖范围**：左扩、右扩、左缩、右缩、重置对齐。
- **开闭样式**：左闭合、右闭合。
- 可以在谱面上拖动调整，选中时覆盖的小节会显示绿框。按 `Delete` 删除。

## 小节上的反复记号

Segno、Coda、Fine、D.C.、D.S.、To Coda 等反复记号在 [小节](#edit-measure) 属性栏的「反复」分组中设置。

## 自定义符号

内置记号不够用时，可以上传自己的 SVG 作为符号。自定义符号分为**音符符号**（挂在音符 / 休止符上）和**小节符号**（挂在小节上），没有单独的列表页，全部在曲谱编辑里管理。

- **新建**：选中音符或小节，在属性栏「自定义符号」栏目点 `+`，上传 SVG，填写名称、尺寸和位置后保存。符号存进软件的符号库，所有曲谱都能用。
- **添加到曲谱**：点击栏目里的符号图标，添加到当前音符或小节；再点一次移除。
- **位置**：音符符号以音符头中心为基准，纵向偏移负值在上方、正值在下方；简谱还可以指定相对数字的哪一边。小节符号可选小节上方 / 下方、靠小节左边 / 中点 / 右边。**偏移量 1 = 一个小节的高度**（约 45 像素）。
- **管理**：点栏目右上角的「管理」，可以编辑或删除符号库里的符号；也可用「导出配置 / 导入配置」用 JSON 备份或恢复符号库。

> 符号添加到曲谱时会复制一份保存在曲谱里，所以从符号库删除符号、或在其它曲谱里修改它，都不会影响已经添加过的曲谱。编辑符号后，当前打开的曲谱里的同一个符号会同步更新。

## 倚音

倚音在音符属性栏的「属性」页中添加，见各曲谱类型的「音符」页，例如 [五线谱的音符](#edit-staff-note)。
