框选可以一次选中多个音符，批量升降音高、改时值或删除。所有曲谱类型都支持框选，能做的批量操作因谱种而异，见下方表格。

## 怎么框选

- 在曲谱空白处或小节内按住鼠标左键拖动，就会画出一个紫色的选框，松开后框内的音符被选中。
- 可以选中的有：五线谱和鼓谱的符头、简谱的数字、TAB 谱的品数（以及琶音、扫弦）、休止符。被选中的会显示紫色高亮。
- 曲谱外的编辑区空白处也可以开始拖动。在输入框、按钮、下拉框上按下不会触发框选。
- 拖动距离很短时视为普通点击，不会框选。
- 框选后，原来的单个选中会被取消；松开鼠标的那一下不会选中小节，也不会添加音符。

## 批量操作

框选后，右侧属性栏显示「已框选 N 个音符」（包含休止符时也会写出休止符的数量），并提供以下操作：

| 分组 | 操作 | 说明 |
| --- | --- | --- |
| 音高 | 降音 / 升音 | 输入 1–48 个半音后点确定。休止符不参与升降音 |
| 时值 | 时值 ×2 / 时值 ÷2 | 把所有选中音符的时值加倍或减半，范围是全音符到一百二十八分音符，到头时会提示 |
| 时值 | 附点 | 给选中的音符统一设置附点 |
| 符干 | 符干方向 | 选中的音符中有带符干的（五线谱）时才显示 |
| 操作 | 删除选中项 | 删除所有选中的音符和休止符，也可以按 `Delete` 或 `Backspace` |

- **鼓谱**：没有「音高」和「符干」两组；时值最长到四分音符。
- **TAB 谱**：没有「音高」和「符干」两组；改时值和附点时，同一时刻的所有音一起改。

## 取消框选

- 按 `Esc` 先清除框选，再按一次清除单个选中。
- 撤销操作时也会清除框选。

> 框选的内容不能复制粘贴。复制粘贴请用 [右键](#edit-context-menu) 菜单，以小节、单谱表、复谱表为单位进行。
