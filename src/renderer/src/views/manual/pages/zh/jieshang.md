欢迎使用解熵！解熵是一款集音乐游戏、曲谱制作、练琴与演唱测评、教学展示于一体的音乐软件。左侧目录的每一项都是一页，点一下就能查看；顶部搜索框可以按标题或正文查找。

## 首页一览

首页从上到下分为几块：

- **游戏模式**：「街机模式」「无限模式」「极限模式」三张卡片，点击直接开始游戏，见 [主线游戏](#game)。
- **主入口**：「我的曲谱」「我的作品」，见 [我的曲谱](#scores)、[我的作品](#works)。
- **更多入口**：「教学白板」「和弦管理」「能力测试」「模拟乐器」「我的音频」「我的图片」「我的视频」「工具」「藏品」「成就」。
- **页脚**：解熵交流 QQ 群号，遇到问题欢迎来群里交流。

> 窗口高度较小时，顶部的 Logo 和软件名会自动隐藏，给下方的入口让出位置。

## 设置

点击首页**左下角**的齿轮按钮，打开「设置」弹窗。所有改动立即生效并自动保存，点「完成」关闭即可。

| 设置项 | 说明 |
| --- | --- |
| 界面语言 | 中文 / English / 日本語，切换后整个界面立即换成对应语言 |
| 街机/无限模式难度 | 简单 / 标准 / 困难，默认简单。只影响街机模式和无限模式，极限模式不受影响 |
| 游戏曲谱模式 | 开关打开为「简谱」，关闭为「线谱」，默认线谱。对三种游戏模式都生效 |
| 音符块声音 | 0–100，游戏中音符块出现时播放的提示音音量 |
| 使用手册 | 打开本手册 |

游戏相关的设置在进入一局游戏时读取，游戏进行中修改不会影响当前这一局。

## MIDI 键盘

首页**右下角**的圆形图标显示 MIDI 键盘的连接状态：

- **绿色**：已连接，鼠标悬停提示「MIDI 琴已连接」。
- **红色**：未连接，鼠标悬停提示「MIDI 琴未连接」。

插拔 MIDI 设备时，软件会弹出「MIDI 设备已连接」或「MIDI 设备已断开」的提示。这个图标只显示状态，不能点击。

各功能对 MIDI 键盘的需求：

| 功能 | 是否需要 MIDI 键盘 |
| --- | --- |
| 主线游戏 | **必需**，游戏只接受 MIDI 键盘输入 |
| 线谱录制录入（钢琴录入） | **必需** |
| 练习模式、新手模式 | 推荐。也可以用鼠标点屏幕钢琴，或用电脑键盘弹奏 |
| 编辑模式录入音符 | 可选，线谱和简谱支持 |
| 教学白板 | 可选，也可以用鼠标点琴键，或用电脑键盘弹奏 |

设备有没有被识别、信号是否正常，可以到 [midi检测](#tool-midi) 中查看。
