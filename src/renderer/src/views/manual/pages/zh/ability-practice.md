练习模式相当于一个可以自己调难度的 [极限模式](#game-extreme)：屏幕中间只显示一个大音符块，它不会消失，弹对了才换下一个。没有生命值、计时淘汰和道具块，适合按自己的节奏专门练识谱。

## 练习设置

进入后先显示「练习设置」，设置会被记住，下次进入沿用。

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 谱面 | 线谱 / 简谱 | 线谱 |
| 谱号 | 高音 / 中音 / 低音谱号，可多选（仅线谱） | 高音、低音 |
| 调号 | 15 个调号任选，可「全选」或「仅 C 调」 | 仅 C 调 |
| 临时变音记号 | 不出现 / 升号、降号 / 含重升、重降（简谱没有重升重降） | 不出现 |
| 音域 | 拖动滑块选择最低音和最高音 | D2–B5（MIDI 38–83） |
| 音符数量 | 1–10000 个，或勾选「无限」 | 50 |
| 出题时播放这个音 | 新音符块出现时播放它的音高 | 开 |
| 弹奏时由软件发声 | 按键时由软件播放钢琴声；数码钢琴自带声音时可以关掉 | 开 |
| 显示虚拟钢琴 | 在页面底部显示钢琴，没有 MIDI 键盘也能用鼠标作答 | 开 |

- 线谱中每个谱号能出的音域是固定的：高音谱号 B3–B5，中音谱号 C3–C5，低音谱号 D2–D4。音域滑块超出所选谱号范围的部分不会出题。
- 设置下方会提示「当前设置下共有 N 个音可以出题」；为 0 时无法开始，需要放宽音域、谱号或调号。

## 练习流程

1. 点「开始练习」，中间出现一个音符块，上方显示「已完成」「错按」次数和用时，顶部显示「当前第几个 / 总数」（无限时显示 ∞）。
2. 用 MIDI 键盘或下方虚拟钢琴弹出这个音。音高必须完全一致（包括八度）。
3. 弹对后立刻换下一个；弹错时闪红光并抖动，音符块不变，可以继续尝试。
4. 达到设定数量后自动结束；也可以随时点「结束练习」查看结果，或点「中止」直接回到设置页。选「无限」时会一直练下去，直到你手动结束或中止。

- 同一个音不会连续出现两次（可出题的音只有一个时除外）。

## 结果

- **一次弹对率**：第一次按键就弹对的音占完成总数的比例。
- 完成的音数、错按次数、平均每个音用时、最长连续一次弹对个数、总用时。
- 「再练一次」用相同设置重新开始，「重新设置」回到设置页。

练习结果不会保存，也不计入成就和最高分。
