## 顶部工具栏

| 按钮 | 说明 |
| --- | --- |
| 撤销 | 撤销上一步，快捷键 `Ctrl+Z` |
| 恢复 | 恢复被撤销的操作，快捷键 `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 设置 | 打开「作品设置」，修改作品名称、作者和页面尺寸 |
| 展示 | 切换到 [展示模式](#work-show) |
| 保存 | 保存作品 |
| 导入 / 导出 / 音量 | 与展示模式相同，见 [展示模式的功能](#work-show-features) |

### 撤销与恢复

- 最多保留 30 步。一次拖动或一次输入算一步。
- 撤销时会自动跳到发生变化的那一页。
- 打开或导入作品后，撤销记录清空。
- 正在输入框中打字时，快捷键作用于输入框本身。

### 保存

- **新作品**：弹出「保存作品」，填写「作品名称」（必填）和「作者」（可选），点「确认保存」。
- **已保存过的作品**：直接保存，不再弹窗。要改名或改作者，先在「设置」中修改，见下方「作品设置」。

没有自动保存，也没有 `Ctrl+S` 快捷键。

## 页面管理

左侧缩略图下方的按钮：

| 按钮 | 说明 |
| --- | --- |
| 加页 | 在最后添加一张空白页 |
| 插入 | 在当前页后面插入一张空白页 |
| 删页 | 删除当前页（不会确认，可以撤销）。只剩一页时不能删除 |
| 复制 | 把当前页复制一份，放在它后面 |

在缩略图上点右键，还可以「复制」「粘贴」「删除」。「粘贴」会用复制的内容**覆盖**目标页。页面不能拖动排序。

## 作品设置

| 项目 | 说明 |
| --- | --- |
| 作品名称 / 作者 | 修改后点「应用」，再点顶部「保存」才会写入作品库。作品名称不能为空 |
| 默认页 | 之后新建页面的尺寸。点「保存」设为默认，「全页应用」把所有页面改成这个尺寸 |
| 当前页 | 修改当前页的宽和高，点「应用」 |
| 标准规格 | 从预设中选择：A3、A4、A5、B4、B5、Letter 的竖版和横版，以及屏幕 16:9（1280×720）、4:3（1024×768） |

尺寸单位是像素，范围 100–10000。默认是 794 × 1123，相当于 A4 竖版。

## 工具面板

### 绘制

- 点「开始绘制」后可以用「画笔」或「橡皮」在页面上绘制，画笔颜色默认黑色，笔触大小 1–80。
- 这里的笔迹**会保存到作品中**，和展示模式的临时标注不同。
- 绘制时不能选择或拖动元素，点「取消绘制」恢复。
- 「清空本页笔迹」清除当前页的所有笔迹。

### 页面背景

- 「设置背景」：从「我的图片」中选一张图片，点「设为背景」。背景会拉伸铺满整页。
- 「清除背景」：去掉背景。

### 素材库

点「打开素材库」，在「图片」「音频」「视频」中选择一项，点「添加到页面」。素材需要先上传到 [我的图片 / 音频 / 视频](#media)。

- 图片、视频按原始尺寸添加（视频读不到尺寸时为 480×270）。
- 音频是一个 320×64 的小播放器。

### 添加文本

填写「文字内容」，设置「字号」（8–200，默认 16）和「颜色」，点「添加到页面」。

添加后选中文本，可以在右上角的属性面板中修改「字号」和「颜色」。双击文本可以修改文字：`Enter` 换行，`Ctrl+Enter` 或点击别处完成，`Esc` 取消。

### 添加曲谱

1. 在搜索框中找到「我的曲谱」中的曲谱，点击选中。
2. 设置「缩放」（0.1–2，默认 0.5）和「曲谱皮肤」。
3. 点「确认添加」。

曲谱绑定的范唱、伴奏会自动带上。作品中的曲谱**不能修改音符**，要改请回到「我的曲谱」编辑后重新添加。

## 摆放元素

- **选中**：点击元素；点击页面空白处取消选中。
- **移动**：拖动元素。视频和音频需要拖动它们**边缘**一圈（中间要留给播放按钮）。
- **缩放**：拖动四个角。缩放时以中心为基准，不保持比例，最小 24 像素。
- **旋转**：拖动元素上方的圆形把手。
- **删除**：选中后按 `Delete` 或 `Backspace`，或右键「删除」。不会确认，可以撤销。

曲谱总是显示在其它元素的下面。没有对齐网格、多选和图层顺序调整。

### 右键菜单

| 菜单项 | 适用元素 | 说明 |
| --- | --- | --- |
| 扶正 | 全部 | 旋转角度恢复为 0 |
| 水平居中 | 全部 | 移到页面水平正中 |
| 比例恢复 | 曲谱、图片、视频 | 宽度不变，按原始比例重新计算高度 |
| 裁剪 / 完成裁剪 | 曲谱、图片 | 进入或退出裁剪 |
| 删除 | 全部 | |

## 属性面板

选中**曲谱、图片或文本**后，右上角显示「属性」面板。音频和视频没有属性面板。

### 位置与尺寸

X、Y、宽、高、旋转（-360 到 360）。「锁定比例」默认勾选，在面板中修改宽或高时另一项按比例变化。

### 文字样式

仅文本：「字号」8–200，「颜色」可用取色器选择。下面的「信息」和「裁剪」只对曲谱和图片显示。

### 信息

- 图片：名称、原始尺寸。
- 曲谱：范唱、伴奏、曲谱尺寸。

### 裁剪

只想显示曲谱或图片的一部分时使用：

- **拖拽裁剪**：点「拖拽裁剪」，边框变为橙色，拖动四角调整要保留的区域，向外拖可以恢复被裁掉的部分。按 `Enter` 或 `Esc`，或点「完成裁剪」结束。
- **按复谱表裁剪**（仅曲谱）：在「起点」「终点」中选择「标题」或「复谱表 n」，点「按复谱表裁剪」，只保留这几行。打开「锁定起始位置」可以固定起点。
- **数字裁剪**：直接填写起点 X / Y 和终点 X / Y。
- **保持框大小（拉伸铺满）**：勾选后裁剪不改变元素的大小，内容拉伸铺满。
- **清除裁剪**：恢复完整内容。

裁剪时选中其它元素、翻页、切换到展示模式或开始绘制，都会自动结束裁剪。
