架子鼓谱写在五线上，但每条线、每个间代表的是**一件鼓或镲**，而不是音高；不同的**音符头形状**（普通、叉号、三角形等）也代表不同的乐器或打法。

鼓谱分为上下两个声部：一般手打的鼓和镲写在**一声部**（符干朝上），脚踩的底鼓和踩镲写在**二声部**（符干朝下）。

## 添加工具栏

| 项目 | 选项 | 默认 |
| --- | --- | --- |
| 声部 | 一声部（向上） / 二声部（向下） | 一声部 |
| 添加 | 音符 / 休止符 | 音符 |
| 音符头 | 普通、叉号、叉号加圆、斜线加圆、三角形、菱形 | 普通 |
| 时值 | 四分音符到一百二十八分音符（鼓谱最长只到四分音符） | 八分音符 |
| 附点 | 无 / 单附点 / 双附点 | 无 |

选中某个声部后，另一个声部的音符会变成灰色，方便你专心编辑当前声部。点选音符头时会自动切回「音符」。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `A`–`T`（跳过 `P`） | 选中小节后，在小节末尾添加对应的鼓音符，声部、时值、附点取工具栏设置（见下表） |
| `3`–`8` | 切换时值：3 四分 …… 8 一百二十八分。`1`、`2` 无效 |
| `0` | 在「音符」和「休止符」之间切换 |

输入法处于中文状态时，字母键同样有效。鼓谱不支持 MIDI 键盘录入。通用快捷键见 [编辑模式](#score-edit)。

## 合法音符与字母键

只有下表中「位置 + 音符头」的组合才能发出声音。右上角「合法音符一览」中可以看到每种记法的样子并试听。

| 按键 | 乐器 | 位置 | 音符头 |
| --- | --- | --- | --- |
| `A` | 强音镲 2 | 上加一线上方的间 | 叉号 |
| `B` | 中国镲 | 上加一线上方的间 | 叉号加圆 |
| `C` | 强音镲 1 | 上加一线 | 叉号 |
| `D` | 踩镲（开） | 第五线上方的间 | 叉号加圆 |
| `E` | 踩镲（半开） | 第五线上方的间 | 斜线加圆 |
| `F` | 踩镲（合） | 第五线上方的间 | 叉号 |
| `G` | 高音通鼓 | 第五线上方的间 | 普通 |
| `H` | 牛铃 | 第五线上方的间 | 三角形 |
| `I` | 叮叮镲 | 第五线 | 叉号 |
| `J` | 叮叮镲帽 | 第五线 | 菱形 |
| `K` | 通鼓 1（中高通鼓） | 第四间 | 普通 |
| `L` | 通鼓 2（中筒鼓） | 第四线 | 普通 |
| `M` | 军鼓 | 第三间 | 普通 |
| `N` | 鼓边侧击 | 第三间 | 叉号 |

> 字母键只决定位置和音符头，**声部仍取工具栏的设置**。例如要输入底鼓，记得先把声部切到「二声部」。

## 鼓谱的限制

- 鼓谱小节没有调号，可以设置谱号和拍号，见 [小节](#edit-measure)。
- 鼓谱的音色是固定的打击乐，不能更换。
- 鼓谱不能转换为其它曲谱类型。
