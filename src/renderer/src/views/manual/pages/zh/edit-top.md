编辑模式右上角有两组功能按钮，底部还有一条工具栏。读写文件期间，这些按钮会暂时禁用。

## 第一组按钮

### 布局调整

打开「布局调整」弹窗，分为两部分：

- **当前曲谱布局**：调整当前曲谱的页面（总宽度、左留白、音色名字体、右留白、总高度）、标题区（高度、字体）、歌词（字体、字号；歌词画在单谱表下外边距里，不单独占高度）、复谱表边距（上 / 下）、单谱表边距（上外 / 上内 / 下内 / 下外），旁边有示意预览。修改立即写入当前曲谱。点「同步为默认」，可以把当前布局设为软件的默认布局。
- **默认布局**：软件的默认布局，修改后自动保存，影响以后新建的曲谱和新增的谱表；点「应用」可以套用到当前曲谱。总宽度和总高度不参与默认布局。

各区域的含义见 [曲谱结构](#edit-structure)。

### 结构按钮

开关。打开后，曲谱上会显示用来增删结构的按钮：

| 位置 | 按钮 | 作用 |
| --- | --- | --- |
| 复谱表下方左侧 | 红色「− 复谱表」 | 删除这个复谱表，只剩一个时不可用 |
| 复谱表下方左侧 | 粉色「+ 复谱表」 | 在后面插入一个复谱表，沿用当前复谱表的单谱表数量、谱号、调号、拍号、小节线、连谱号和音色 |
| 单谱表下方右侧 | 红色「−」 | 删除这个单谱表，复谱表里只剩一个时不可用 |
| 单谱表下方右侧 | 蓝色「↓」 | 在下方添加一个单谱表 |
| 单谱表下方右侧 | 绿色「→」 | 给这个复谱表的每个单谱表末尾各加一个小节 |

选中小节时，单谱表下方的按钮暂时不可用。关闭开关后按钮隐藏，但它们占的位置仍会保留。

### 歌词

开关，在「结构按钮」右边。关闭后隐藏曲谱上的歌词，方便专心看谱面；歌词内容不会删除。和「结构按钮」互不影响。

### 连谱模式

开关，对所有复谱表生效。打开后，同一复谱表中各单谱表的小节线会连通；修改或删除小节线时，同一列的小节线会一起改变。

### 显示音色

开关。打开后，每个单谱表左侧会显示它的音色名称。单谱表的音色通过 [右键](#edit-context-menu) 菜单中的「设置音色」设定。TAB 谱和鼓谱的音色是固定的，没有这个开关。

### 曲谱类型

在线谱和简谱之间切换。切换前会弹出确认：「切换后播放信息会尽量保持一致，但谱面样式与部分记谱细节可能丢失。可用 Ctrl+Z 撤销本次切换。」TAB 谱和鼓谱不能转换，没有这个选项。

### 转调

选择「目标调」后点「转调」。转调会以曲谱中**第一个调号**作为当前调；如果曲谱中途换过调，部分音符的音高可能会出错，确认框中也会提醒。目标调与当前调相同时不能转调。

### 升半音 / 降半音

把整首曲谱升高或降低一个半音，点击后直接生效，可以用 `Ctrl+Z` 撤销。

## 第二组按钮

| 按钮 | 说明 |
| --- | --- |
| 标准模式 | 开关。开启后录入的音符超出小节拍号时值时，自动挪到下一小节并选中它，本小节剩余时值补休止符，见 [编辑模式](#score-edit) |
| 快速录入 | 仅简谱。用文本快速录入简谱，见 [简谱快速录入](#edit-quick-number) |
| 钢琴录入 | 仅线谱。用 MIDI 键盘弹奏，录制成钢琴谱，见 [线谱录制录入](#edit-piano-record) |
| 合法音符一览 | 仅鼓谱。列出鼓谱可用的全部音符和对应的字母快捷键，见 [架子鼓谱](#edit-drum) |
| 须知 | 打开「编辑须知」，汇总选中与删除的规则、各曲谱类型的快捷键等 |
| 导入 / 导出 | 见 [导入导出](#edit-import-export) |
| 保存 | 把曲谱保存到「我的曲谱」 |

## 底部工具栏

| 按钮 | 说明 |
| --- | --- |
| 返回 | 回到上一页；没有上一页时回到首页 |
| 播放模式 | 切换到播放模式试听，会带上当前还没保存的修改 |
| 谱音同步 | 打开谱音同步面板，见 [谱音同步](#edit-sync) |

编辑模式本身没有播放按钮，想试听请切换到播放模式。
