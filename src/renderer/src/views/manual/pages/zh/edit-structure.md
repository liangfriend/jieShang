一个曲谱由**标题、复谱表、单谱表、小节**组成。它们层层包含：复谱表包含单谱表，单谱表包含小节，小节里放音符和休止符。

```
曲谱
├─ 标题区：标题、副标题、作者、调号 / 拍号 / 速度
├─ 复谱表 1
│   ├─ 单谱表 1：小节 小节 小节 …
│   └─ 单谱表 2：小节 小节 小节 …
├─ 复谱表 2
│   ├─ 单谱表 1：…
│   └─ 单谱表 2：…
└─ …
```

- **复谱表**：曲谱从上到下排列的"一大行"。
- **单谱表**：复谱表里的每一行谱。比如钢琴谱的一个复谱表包含高音谱表和低音谱表两个单谱表，用连谱号连在一起。
- **小节**：单谱表被小节线分成的一段一段。

> 同一份曲谱中，各复谱表的单谱表行数最好保持一致，比如第 1 行始终是右手、第 2 行始终是左手。练习、新手、演唱模式和谱音同步都要求所有复谱表的单谱表行数一致。

## 标题区

位于曲谱最上方，在编辑模式中可以直接点击输入：

- 「标题」「副标题」「作者」，作者一栏可以回车换行。
- 如果曲谱带有调号、拍号或速度，标题下方还有一行信息：「1 =」调号、拍号、基准拍和速度，也可以直接修改。速度填写不合法时会改回 120。

标题就是这首曲谱在「我的曲谱」中显示的名称。

## 区域划分

复谱表、单谱表、小节的上下左右都留有区域，用来摆放歌词、指法图、音色名等附加内容。下图是一个复谱表（含一个单谱表、两个小节）周围的区域示意：

![一个复谱表周围的区域：粉色是摆放内容的区域，白色是间距](score-slots.png)

- **粉色块**：摆放附加内容的区域。图中的标签是"谁 - 哪一侧"的缩写，只用来和下表对照：`g` 复谱表、`s` 单谱表、`m` 小节；`u` 上、`d` 下、`l` 左、`r` 右。比如 `g-d` 就是"复谱表下方"。
- **白色块**：内容之间的间距。图中的"复谱表 uSpace / dSpace"就是「布局调整」里复谱表的上 / 下边距；"单谱表上边距外 / 上边距内 / 下边距内 / 下边距外"对应单谱表边距的上外 / 上内 / 下内 / 下外。

常用区域如下：

| 位置 | 图中标签 | 放什么 |
| --- | --- | --- |
| 曲谱最上方（标题区） | — | 标题、副标题、作者、调号 / 拍号 / 速度 |
| 每个复谱表下方 | `g-d` | 编辑时的复谱表增删按钮（高度为 0，按钮靠左） |
| 每个单谱表左侧（左留白） | `s-l` | 打开「显示音色」后，显示该单谱表的音色名 |
| 每个单谱表右侧（右留白） | `s-r` | 跨行连音线的末端 |
| 每个单谱表下方 | `s-d` | **歌词**（高度为 0，往下画进单谱表的下外边距）；编辑时的单谱表增删按钮、加小节按钮 |
| 每个小节下方 | `m-d` | **箫、笛子的指法标记** |

左右留白的宽度、歌词的字体和字号、各种边距等，可以在 [顶部功能](#edit-top) 的「布局调整」中设置。

## 歌词

每个单谱表都有自己的歌词，写在该单谱表下方，每个音符位置下方有一个输入框，直接点击输入即可。歌词不单独占高度，而是画在单谱表的下外边距里；歌词行多或字号大时，请在「布局调整」里调大单谱表的「下外」边距。

- 「+行」添加一行歌词，用于多段歌词；「−行」删除最后一行，至少保留一行。
- 单谱表里还没有音符时，不能添加歌词行。
- 在歌词输入框里按 `Tab` 跳到下一个音的歌词，`Shift+Tab` 跳回上一个；当前音是连音线的起点时，`Tab` 直接跳到连音线终点之后那个音。
- 歌词会在播放模式、练习模式等页面中一起显示。

### 歌词匹配

顶部「歌词」开关右边的「歌词匹配」按钮会打开一个可拖动的小窗，用来一次输入整行歌词：

- 每个复谱表一个输入框（「第 1 行」「第 2 行」……），边输入边按顺序填到音符的第一行歌词上。
- 输入框里回车换行代表下一个单谱表：第一行填复谱表的第 1 个单谱表，第二行填第 2 个，以此类推。行数多于单谱表时会提示多出的行没有填入。
- 自动跳过休止符，以及连音线罩住的音：连音线起点的音唱这个字，后面被罩住的音不分配新字（从上一个复谱表连过来的也算）。例如 `1 2 3 4` 中 2 和 3 有连音线，输入「你好吗」会填到 1、2、4 上。
- 中日韩文字一字一音；其它文字按空格分词，用 `-` 拆音节（如 `hel-lo`）。
- 用 `_` 空过一个音，例如「你_好」把「你」「好」填在第 1、3 个音上。
- 字比音少时，后面的音的歌词会被清空；字多时，多出的字不填，窗口里会提示是哪个单谱表多了几个字。
- 打开窗口时输入框里是已有的歌词，可以直接接着改；`Ctrl+Z` 可以撤销。

## 箫、笛子的指法标记

指法标记画在每个小节的下方，在音符下方画出对应的指法图。它不在编辑模式里设置，而是在 [播放模式](#play-features) 底部工具栏的「标记」中选择箫或笛子的调；超出该乐器音域的音不画。
