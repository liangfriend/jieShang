本页介绍简谱中音符和休止符的添加、修改与删除。

## 用鼠标添加

1. 点击一个小节将它选中。
2. 把鼠标移到小节里，会出现一个半透明的**预览数字**。鼠标越靠上数字越大（最上方是 7，最下方是 1）。
3. 点击即可添加，时值和八度点取左上角工具栏的设置。

简谱只能在**两个音符之间**插入新音符，不能像五线谱那样点在已有音符上叠加成和弦。想在同一位置叠加多个音，请用下面的「添加多声部音符」。

## 用键盘添加

选中小节后，按主键盘的 `1`–`7` 直接在小节末尾添加音符，按 `0` 添加休止符。详见 [简谱](#edit-number) 的快捷键说明。

## 修改音高：拖动

选中音符后，按住数字**上下拖动**即可改变音高。拖过 7 会自动进入高一个八度的 1，拖过 1 会进入低一个八度的 7，八度点会跟着变化。

## 音符属性栏

点击一个数字将它选中，右侧显示「音符属性」，分为「属性」「记号」「连线」三个标签页。

### 属性

**音高**

- **唱名**：1、2、3、4、5、6、7、X。其中 X 表示节奏音（只表示节奏、没有具体音高）。
- **八度点**：-3 到 +3，对应低三个八度到高三个八度，0 为不加点。
- **变音符号**：无 / 升号 ♯ / 降号 ♭ / 重升 𝄪 / 重降 𝄫 / 还原 ♮。设置后可以调整它的横向偏移。

**节奏**

- **时值**：全 / 二分 / 四分 / 八分 / 16分 / 32分 / 64分 / 128分。简谱中，二分和全音符用数字后面的增时线表示，八分及更短的音符用数字下方的减时线表示。
- **附点**：无 / · / ·· / ···。
- **减时线连接**：全连 / 右连 / 无，控制相邻音符的减时线是否连在一起。

**添加多声部音符**

在同一个位置叠加一个音（例如和声）：

1. 选好要叠加的「唱名」（1–7）、「八度点」和「变音符号」。
2. 点「添加到同一位置」。

**横向偏移**：滑块 -40 到 40，微调整个音符的左右位置。

**倚音**：「添加前倚音」「添加后倚音」，下方列表可以逐个删除。在谱面上点击倚音可以单独选中并修改。

### 记号

添加重音、断奏、颤音、力度等单音符记号，见 [其它符号](#edit-symbols)。

简谱音符还多两组**古筝**记号：

- **古筝指法**：托、劈、抹、挑、勾、剔、打、摘、提、拨、小撮、大撮，组内只能选一个。
- **古筝技法**：扫、摇指，可以和指法同时添加。

### 连线

添加琶音、连音线、踏板、8va / 8vb、颤音线、渐强渐弱等跨音符记号，见 [其它符号](#edit-symbols)。简谱的连音线没有居中控制点。

简谱还可以添加**古筝连续指法**：先选好「跨度」，再点连托、连劈、连抹、连挑、连勾、连剔、连打、连摘中的一个。连续指法画在谱表下方，从当前音符一直延续到跨度的最后一个音符。在谱面上点中它后，可以改指法、调整覆盖范围和两端位置，也可以拖动两端和中间的把手。

## 休止符属性栏

简谱的休止符是「0」。选中后显示「属性」和「记号」两个标签页，可以修改时值、附点、减时线连接和横向偏移，也可以添加记号。

## 删除

- 选中后按 `Delete` 或 `Backspace`。
- 同一位置叠加了多个音时，只删除选中的那一个。
