工具里是几个练琴时常用的小工具。在首页点「工具」进入。

| 工具 | 用途 | 需要的设备 |
| --- | --- | --- |
| [调弦](#tool-tune) | 给吉他、贝斯、尤克里里调弦 | 麦克风 |
| [节拍器](#tool-metronome) | 按指定速度和拍号打拍子 | 无 |
| [音高检测](#tool-pitch) | 实时显示你唱或弹的音名、频率 | 麦克风 |
| [麦克风检测](#tool-mic) | 确认麦克风能正常收音 | 麦克风 |
| [midi检测](#tool-midi) | 确认 MIDI 键盘连接正常、信号正确 | MIDI 键盘 |

遇到「演唱模式没反应」「游戏里按键没反应」之类的问题时，可以先用麦克风检测和 midi检测排查设备。
