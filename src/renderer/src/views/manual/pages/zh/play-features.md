播放模式的所有功能都在底部工具栏。播放时曲谱会自动滚动，让正在播放的音符保持在画面中间；停止后回到开头。

## 工具栏

从左到右依次是：

| 按钮 | 说明 |
| --- | --- |
| 返回 | 回到上一页 |
| 编辑模式 | 停止播放，进入这首曲谱的编辑模式 |
| 曲谱 / 范唱 / 伴奏 | 选择播放什么，默认「曲谱」。「范唱」「伴奏」需要先在 [谱音同步](#edit-sync) 中绑定音频，否则是灰色的。播放或暂停中不能切换，要先点「停止」 |
| 播放 / 暂停 / 停止 | 暂停后再点「播放」从暂停处继续 |
| 选段 | 只播放其中一段，见下文。只在「曲谱」时可用 |
| 音量 | 0–100%，默认 100%。范唱、伴奏的音量也由它控制 |
| BPM | 播放速度，40–240，默认取曲谱的速度（换算成以四分音符为一拍），曲谱没有速度时为 120。播放范唱、伴奏时隐藏 |
| 音色 | 「曲谱设定」或你拥有的任一音色藏品。播放或暂停中不能切换，要先点「停止」。TAB 谱、鼓谱没有这个按钮 |
| 曲谱类型 | 在线谱和简谱之间临时切换显示 |
| 转调 | 选择「目标调」后点「转调」，临时把整首曲谱转到另一个调 |
| 升半音 / 降半音 | 临时把整首曲谱升高或降低一个半音 |
| 标记 | 在简谱上标出箫或笛的指法，见下文 |
| 练习模式 / 新手模式 / 演唱模式 | 进入对应的子模式，见 [播放模式](#score-play) |

「曲谱类型」「转调」「升半音 / 降半音」在播放时不能使用，TAB 谱和鼓谱没有这几项。

> 「曲谱类型」「转调」「升降半音」只改变当前看到的曲谱，**不会保存**到「我的曲谱」。如果此时点「编辑模式」，这些改动会带进编辑器，在编辑器中保存后才会生效。

### 音色的默认值

每次进入播放模式，音色都默认选「曲谱设定」，也就是每个单谱表各自设置的音色；没有设置音色的单谱表用三角钢琴。

## 选段播放

只想反复听某一段时：

1. 点「选段」，曲谱上方出现选段提示条。
2. 点击一个音符作为**起点**（显示为绿色），提示「再点击一个音符设置结束音符」。
3. 再点击一个音符作为**终点**（显示为蓝色）。
4. 点「播放」，只播放这一段。

- 再点击音符会重新设置起点。
- 提示条上的「清空选段」清除已选的起点和终点，「结束选段」退出选段。
- 没选完就点播放，会提示「请先点击音符选择起始和结束音符」。
- 切换「曲谱 / 范唱 / 伴奏」或「曲谱类型」会自动结束选段。

## 播放范唱和伴奏

在 [谱音同步](#edit-sync) 中绑定了范唱或伴奏后，就可以在下拉框中选择它们：

- 播放的是真实的音频，曲谱高亮按对齐好的时间移动。
- 绑定了音频但还没对齐时，音频照样播放，只是曲谱不会高亮，并提示「当前曲谱还没有范唱的谱音同步时间……」。
- 绑定的音频在「我的音频」中被删除后，会提示「未找到绑定音频」。

## 箫笛指法标记

「标记」可以在每个音符下方标出指法，方便吹奏：

- **八孔箫**：C、♭D、D、♭E、E、F、♭G、G、♭A、A、♭B、B 调箫。
- **六孔笛**：大G、A、♭B、C、D、E、F、小G 调笛。
- 选「无」去掉标记。播放过程中也可以切换。

请选择和你手中的乐器同调的选项。

## 键盘快捷键

播放模式没有键盘快捷键，所有操作都通过工具栏完成。
