曲谱管理就是「我的曲谱」列表页，从首页点「我的曲谱」进入。

## 浏览与搜索

- 每首曲谱显示为一张卡片，卡片上是曲谱名称；名称为空时显示「？」。
- 列表按最近更新时间排列，最近修改的排在最前面。
- 在顶部搜索框输入关键字，稍停片刻会自动按名称模糊搜索，点输入框右侧的 × 可清空。
- **点击卡片**，进入这首曲谱的 [播放模式](#score-play)。
- 左上角带「弹唱」标记的是 [和弦弹唱谱](#cl-sheet)，点击后进入弹唱谱页面。

## 新建曲谱

点右上角「新建曲谱」，在「选择模版」弹窗中选一个模版，会直接进入 [编辑模式](#score-edit)。

| 分组 | 模版 |
| --- | --- |
| 线谱 | 空 / 单声部 / 双声部 |
| 简谱 | 空 / 单声部 / 双声部 |
| TAB谱 | 吉他谱 / 尤克里里谱 / 四弦贝斯谱 / 五弦贝斯谱 / 六弦贝斯谱 |
| 鼓谱 | 架子鼓谱 |
| 和弦弹唱谱 | 空（进入 [和弦弹唱谱](#cl-sheet) 页面） |

新建的曲谱要在编辑模式中点「保存」后，才会出现在列表里。

> 曲谱类型在新建时就决定了。线谱和简谱之后还可以互相转换；TAB 谱和鼓谱创建后不能再转换成其它类型。

## 导入已有的曲谱文件

列表页没有导入按钮，导入在编辑模式中进行：

1. 点「新建曲谱」，任选一个模版进入编辑模式。
2. 点右上角「导入」，选择文件格式和文件。导入的内容会**覆盖**当前曲谱。
3. 检查无误后点「保存」。

支持的格式和注意事项见 [导入导出](#edit-import-export)。

## 重命名

曲谱名称就是曲谱的**标题**。要改名，进入编辑模式，修改谱面最上方的标题，然后点「保存」。标题为空时，曲谱会保存为「未命名曲谱」。

## 删除

鼠标移到卡片上，右上角会出现红色垃圾桶按钮。点击后在「删除曲谱」弹窗中点「删除」确认。

> 删除后**无法恢复**。重要的曲谱建议先在编辑模式中导出一份 `.sj` 文件备份。
