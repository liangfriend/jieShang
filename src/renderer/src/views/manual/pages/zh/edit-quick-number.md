「快速录入」让你像打字一样用文本写简谱，适合快速录入一整首歌。只有**简谱**可以使用，入口是编辑模式右上角的「快速录入」按钮。

## 界面

点击后底部弹出「简谱快速录入」面板：左侧是「文本」输入区，下方显示解析提示；右侧是「预览」。顶部有四个按钮：

| 按钮 | 作用 |
| --- | --- |
| 曲谱转换文本 | 把当前曲谱转换成文本，填入左侧，方便在已有曲谱的基础上修改 |
| 更新预览 | 按左侧文本刷新右侧预览，快捷键 `Ctrl+S`（仅在面板打开时有效） |
| 同步预览到曲谱 | 用预览**覆盖**当前曲谱，成功后关闭面板 |
| 规则须知 | 查看文本写法规则和示例 |

预览沿用当前曲谱的标题、调号、拍号、速度、基准拍和页面宽度。

> 文本录入无法表示所有符号（如变音记号、歌词等）。同步时会弹出确认，同步后当前曲谱中的这部分信息可能丢失。同步后仍可以用 `Ctrl+Z` 撤销。

## 写法规则

### 结构

- 一行就是一个单谱表。
- 连续的非空行组成一个复谱表；空一行开始新的复谱表。
- 音符之间用空格分隔。

### 音符

- `1`~`7` 对应 do~si。
- `0` 是休止符。
- `X` 是节奏音（没有音高）。
- 数字**前**加点 `.5` 表示高八度，数字**后**加点 `5.` 表示低八度，点可以写多个。

### 时值

- `/` 减时线：每加一条，时值减半。`5/` 是八分音符，`5//` 是十六分音符。
- `-` 加时线：`5-` 是二分音符，`5--` 是附点二分，`5---` 是全音符。
- `,` 附点，可以写多个，例如 `5,`。
- `-` 和 `/` 不能同时使用。
- 小节的总时值和拍号对不上时，会在提示区给出提示。

### 组合

- `5(1)`：在同一位置叠一个音，可以连写多个，例如 `5(1)(3)`。
- `[3]5`：前倚音；`5[3]`：后倚音。倚音里也可以加 `/` 和八度点。
- `<5`、`>3`：连音线的起点和终点，写在音符前面。

### 小节线

- `|` 写在小节末尾，每个用空格隔开的 `|` 结束一个小节。
- `| |` 前面没有音符，就是一个空小节。`1 | | | |` 是 4 个小节。
- 行首的 `|` 会生成一个空小节，而不是前置小节线。
- `|1|2` 这样紧贴在一起的只算一个，后面的覆盖前面的。
- 在 `|` 后面加数字可以指定小节线类型：

| 写法 | 小节线类型 | 写法 | 小节线类型 |
| --- | --- | --- | --- |
| `\|1` | 反复开始 | `\|6` | 虚线 |
| `\|2` | 反复结束 | `\|7` | 点线 |
| `\|3` | 终止线 | `\|8` | 反向终止线 |
| `\|4` | 前后反复 | `\|9` | 粗线 |
| `\|5` | 双小节线 | `\|10` | 双粗线 |

### 不支持的内容

标题、调号、拍号、速度沿用当前曲谱。变音记号、前置小节线、歌词等不支持，转换时会被忽略，并在提示区列出。

## 示例

下面是两个复谱表，第一个复谱表有一行，第二个复谱表有两行（中间的空行分隔复谱表）：

```
5. 4. <7. >6. .5(.6) | .7 .5 .5/ 5- |4

[1/2/]3 3/ 2/ <1, >2/ | 3(5) 0 .1- |2
1 1 5. 5. | 6.(1) 6. 5.- |2
```

## 推荐用法

1. 打开面板，点「曲谱转换文本」，得到当前曲谱的文本。
2. 在左侧修改或继续输入，随时按 `Ctrl+S` 查看预览。
3. 留意提示区的提示，确认预览正确后，点「同步预览到曲谱」。
4. 回到编辑器，再补上变音记号、歌词等文本无法表示的内容，最后保存。
