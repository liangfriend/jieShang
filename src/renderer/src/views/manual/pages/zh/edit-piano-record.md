「钢琴录入」可以把你在 MIDI 键盘上的弹奏实时录成钢琴谱：右手写在高音谱表，左手写在低音谱表。只有**线谱**可以使用，入口是编辑模式右上角的「钢琴录入」按钮。

> 需要连接 MIDI 键盘。没有连接时会提示「钢琴录入需要连接 MIDI 键盘，请连接后再试」。

## 录制前的设置

点「钢琴录入」后，底部弹出「钢琴录入」面板：

| 设置 | 说明 |
| --- | --- |
| 速度 | 30–240，默认取曲谱的速度（曲谱没有速度时为 90）。建议先用较慢的速度，弹得稳更容易录准 |
| 拍号 | 录制使用的拍号。修改拍号会清空已经录好的结果 |
| 录制中开启节拍器 | 默认开启，跟着节拍器弹，录出来的节奏更准 |
| 节拍器音量 | 0–100，默认 80 |
| MIDI 设备 | 显示当前连接的设备名，没有设备时显示「未连接」 |

「录制设置」里还有三个高级选项，保存在本机，可以点「恢复默认」还原：

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 拍点吸附（拍） | 0.2 | 起音离拍点在这个范围内，直接算在拍上，用来消除轻微的早晚。不超过 0.25 时，真正的拍后十六分音符不会被吸走。设为 0 关闭 |
| 最短休止 | 八分音符 | 同一只手两个音之间的空档比这个短，就并进前一个音，不写休止符。代价是想写短休止时，要停够这个长度。可选不合并 / 十六分 / 八分 / 四分 |
| 延迟补偿（毫秒） | 0 | 所有按键时间先减去这个值，适合录出来整体固定偏晚的情况（比如节拍器有输出延迟）。不要设得太大 |

## 录制步骤

1. 点「开始录制」。先响一小节**预备拍**，听完这一小节再开始弹；预备拍期间可以点「取消」。
2. 预备拍结束后开始计时，跟着节拍弹奏 MIDI 键盘，谱面会实时滚动显示录到的内容。
3. 弹完点「结束录制」，面板会显示一共录到多少个音符组。不满意可以点「重新录制」。
4. 点「同步到曲谱」，确认后，录制结果会**覆盖当前曲谱的全部内容**。

## 录制规则

- 按速度量化到十六分音符。
- **自动分左右手**：软件根据音的位置和你的手的移动来判断，不是简单地以中央 C 分界，所以连续的旋律跨过中央 C 也不会乱跳谱表。一次按下的音跨度超过一个八度时，会从中间最大的音程处拆给两只手。
- 几乎同时按下（约 60 毫秒内）的音算作一个和弦。
- 跨小节的音会拆开并用连音线连接；每行排 4 个小节。
- 保留当前曲谱的调号、标题和页面宽度。
