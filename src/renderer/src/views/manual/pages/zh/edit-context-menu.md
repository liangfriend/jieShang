在编辑模式中，在曲谱上点击鼠标右键会弹出菜单。菜单中和小节相关的操作，作用于你右键点到的小节（或当前选中的小节）。点击菜单外、按 `Esc` 或滚动页面都会关闭菜单。

## 菜单项

| 菜单项 | 作用 |
| --- | --- |
| 删除 | 删除选中的内容，效果和按 `Delete` 键相同 |
| 长休止符 / 取消长休止符 | 仅鼓谱。把整个小节设为长休止符；设置后该小节不能再添加音符 |
| 复制 ▸ 小节 / 单谱表 / 复谱表 | 复制对应范围的内容 |
| 粘贴 ▸ 小节 / 单谱表 / 复谱表 | 把复制的内容粘贴到这里，替换原有内容 |
| 清空音符 | 清空这个小节里的音符，空小节时不可用 |
| 增加小节 ▸ 左 / 右 | 在左边或右边插入一列空小节，复谱表里每一行同步插入 |
| 删除此索引所有单谱表 | 删除**所有复谱表**中与它同一行的单谱表（例如所有复谱表的第 2 行）。会让某个复谱表变空时不可用 |
| 设置音色 | 为单谱表设置播放音色。TAB 谱和鼓谱的音色固定，没有这一项 |
| 设置音量 | 为单谱表设置播放音量，默认 100 |

## 复制与粘贴

- 复制的内容只保存在本次使用期间，关闭软件后清空。
- **复制小节**只复制音符，不含歌词。粘贴时会替换目标小节的音符，并清掉挂在原来音符上的连音线等跨音符符号。
- **复制单谱表或复谱表**会连同结构和其中的跨音符符号一起复制。粘贴时替换目标，并自动对齐小节数量。
- 只能粘贴到**同一种类型**的曲谱中，例如线谱复制的内容不能粘贴到简谱里。剪贴板为空或类型不一致时，「粘贴」显示为灰色。
- 编辑模式没有 `Ctrl+C` / `Ctrl+V` 快捷键，复制粘贴请使用右键菜单。

## 设置音色

选择「设置音色」后弹出音色选择窗口：

- 为这个小节所在的单谱表设置音色。**当前及之后**的复谱表中，同一行的单谱表会一起设置；之前的复谱表不受影响。
- 可以搜索音色，音色按乐器族分组，只列出你已拥有的音色。
- 点「确定」应用，点「清除音色」恢复为未设置。

设置后：

- 播放模式的音色选择「曲谱设定」时，会使用这里设置的音色；
- 打开顶部的「显示音色」开关后，谱表左侧会显示音色名，见 [顶部功能](#edit-top)。

## 设置音量

选择「设置音量」后弹出音量窗口：

- 为这个小节所在的单谱表设置播放音量，按百分比计，范围 0–200，默认 100。和设置音色不同，**所有**复谱表中同一行的单谱表都会一起设置，包括之前的复谱表。
- 拖动滑块或直接输入数值，点「确定」应用；点「恢复 100」回到默认值。
