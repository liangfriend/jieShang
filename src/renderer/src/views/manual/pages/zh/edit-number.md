简谱用数字 1–7 表示 do 到 si，用数字上下的圆点（八度点）表示高低八度，是最容易上手的记谱方式。简谱的音高由**数字和八度点**决定，所以除了鼠标，用电脑键盘录入会更快。

## 添加工具栏

| 项目 | 选项 | 默认 |
| --- | --- | --- |
| 添加 | 音符 / 休止符 | 音符 |
| 时值 | 全音符到一百二十八分音符 | 四分音符 |
| 八度点 | -3、-2、-1、0、1、2、3（选择休止符时隐藏） | 0 |

八度点表示新添加的音符带几个点：正数是高八度（点在上方），负数是低八度（点在下方），0 是不带点。

## 快捷键

简谱的数字键和其它曲谱不同：**主键盘的数字和三排字母直接输入音符**，小键盘的数字才是切换时值。

| 按键 | 作用 |
| --- | --- |
| 主键盘 `1`–`7` | 在选中小节的末尾添加中音 do、re、mi、fa、sol、la、si，时值取工具栏设置 |
| `Q` `W` `E` `R` `T` `Y` `U` | 依次添加高音 1–7（上方一个八度点） |
| `A` `S` `D` `F` `G` `H` `J` | 依次添加中音 1–7 |
| `Z` `X` `C` `V` `B` `N` `M` | 依次添加低音 1–7（下方一个八度点） |
| 主键盘 `0` / `~` / `I` / `K` | 在选中小节的末尾添加一个休止符 |
| 主键盘 `8` / `9` | 工具栏的八度点减一 / 加一，范围 -3 到 +3，影响鼠标点击添加 |
| 小键盘 `1`–`8` | 切换时值：1 全音符 …… 8 一百二十八分音符 |
| 小键盘 `0` | 在「音符」和「休止符」之间切换 |
| MIDI 键盘 | 选中小节后按琴键，在小节末尾添加对应的音符，按曲谱的调换算成唱名和八度点 |

通用快捷键见 [编辑模式](#score-edit)。

> 按物理键位判断，输入法处于中文状态时字母键同样有效。

### 键盘录入示例

想输入「5 5 6 5 | 1̇ 7」（第二小节的 1 是高音）：

1. 选中第一小节，依次按 `5` `5` `6` `5`。
2. 按 `→` 切到右边的下一小节（或者在属性栏 / 右键菜单里插入小节再选中）。打开右上角「标准模式」后，录满一小节会自动跳到下一小节，这一步可以省掉。
3. 按 `Q` 添加高音 1，再按 `7`（或 `J`）添加中音 7。

## 简谱特有的功能

- **快速录入**：用一行文字快速写出整段简谱，见 [简谱快速录入](#edit-quick-number)。
- **框选**：批量升降音、改时值，见 [框选音符](#edit-box-select)。
- **转换为五线谱**：右上角「曲谱类型」，见 [顶部功能](#edit-top)。
- 简谱小节没有谱号和调号，只能设置拍号；调号在标题区的「1 =」中设置，见 [曲谱结构](#edit-structure)。
