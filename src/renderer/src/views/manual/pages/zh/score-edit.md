编辑模式用来写谱和改谱。进入方式有两种：

- 在「我的曲谱」中点「新建曲谱」并选择模版；
- 在播放模式底部工具栏点「编辑模式」。

## 界面布局

- **左上**：添加音符用的工具栏，例如添加音符还是休止符、时值等。工具栏内容随曲谱类型变化。
- **右上**：功能按钮，见 [顶部功能](#edit-top)。
- **中间**：曲谱本身。点击曲谱上的元素即可选中。
- **右侧**：属性栏，显示当前选中元素的可编辑属性。可以选中小节、音符、休止符、连音线、记号、八度记号、反复房子（Volta）、连谱号等；没有选中时会显示提示。
- **底部**：「返回」「播放模式」「谱音同步」三个按钮。

## 基本流程

1. **选中小节**：点击一个小节，小节被选中后就进入添加音符的状态。
2. **添加音符**：在选中的小节里用鼠标点击，或用键盘、MIDI 键盘录入。不同曲谱类型的方法见 [五线谱编辑](#edit-staff)、[简谱](#edit-number)、[架子鼓谱](#edit-drum)、[Tab谱](#edit-tab)。
3. **修改**：点击音符等元素选中，在右侧属性栏中修改，或直接在谱面上拖动。
4. **保存**：点右上角「保存」。

## 撤销与恢复

- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 恢复。编辑模式没有撤销按钮，只能用快捷键。
- 最多保留约 20 步，离开编辑页后撤销记录清空。
- 撤销或恢复后，如果原来选中的小节还在，会继续保持选中。
- 光标在输入框（如标题、歌词）里时，这几个快捷键作用于输入框本身。

## 保存

- 只能点右上角「保存」按钮保存，没有保存快捷键。
- 曲谱名称取自谱面的标题；标题为空时保存为「未命名曲谱」。

> **注意**：离开编辑页时**不会**提示你保存。切换到「播放模式」会带上当前的修改，可以先去试听再回来，但只有点了「保存」，修改才会真正写入「我的曲谱」。

## 快捷键总表

| 按键 | 作用 | 适用曲谱 |
| --- | --- | --- |
| `Esc` | 先清除框选，再取消选中 | 全部 |
| `Delete` / `Backspace` | 删除当前选中项（音符、小节、谱表、跨音符记号等） | 全部 |
| `Backspace`（选中小节） | 只删小节最后一个音符 / 休止符，小节保留；要删整个小节用 `Delete` | 全部 |
| `<`（或 `,`） / `>`（或 `.`） | 选中音符（或小节，取最后一个音，不必先点音符）时：`>` 从当前音连到下一个音，当前音已是某条连音线的起点时改为把它往右扩一个音；`<` 从上一个音连到当前音，当前音已是某条连音线的终点时改为把它往左扩一个音 | 全部 |
| `/` | 删除选中音符（或小节最后一个音）上的所有连音线 | 全部 |
| `{`（或 `[`） | 选中小节时，循环切换前置小节线：无 → 反复开始 → 反向 | 全部 |
| `}`（或 `]`） | 选中小节时，循环切换后置小节线（单、双、反复结束、虚线、终止、点线、粗、粗双，共 8 种） | 全部 |
| `Ctrl+Z` | 撤销 | 全部 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 恢复 | 全部 |
| `↑` `↓` `←` `→` | 选中小节时，切换到上下左右相邻的小节 | 全部 |
| `*` | 在当前单谱表下方添加一个单谱表；未选中时加在最后 | 全部 |
| `-` | 在当前复谱表下方添加一个复谱表；未选中时加在最后 | 全部 |
| `空格` | 选中有音符的小节时，弹出音值组合浮窗，见下文「音值组合输入」 | 全部 |
| `P` | 选中小节时，把本小节的音符复制到下一小节（替换原有音符）并选中下一小节，连按可一路往后复制；行末跳到下一个复谱表同一行单谱表的第一小节 | 全部 |
| `1`–`8` | 切换时值：全音符、二分、四分、八分、十六分、三十二分、六十四分、一百二十八分 | TAB、鼓谱（鼓谱只有 3–8；简谱、线谱用小键盘） |
| `0` | 切换「音符 / 休止符」 | 鼓谱、TAB（简谱、线谱用小键盘 0） |
| 主键盘 `1`–`7`、`0` / `~` / `I` / `K` | 在小节末尾直接添加中音 do–si / 休止符 | 简谱、线谱 |
| `Q`–`U` / `A`–`J` / `Z`–`M` | 在小节末尾添加高音 / 中音 / 低音 1–7 | 简谱、线谱 |
| 主键盘 `8` / `9` | 工具栏八度点减一 / 加一（-3 到 +3） | 简谱 |
| `A`–`T`（跳过 `P`） | 在小节末尾添加对应的鼓音符 | 鼓谱 |
| `A`–`Z`（跳过 `P`） | 切换品位 0–24，鼠标在小节内时同时写入 | TAB |
| MIDI 键盘 | 选中小节后按琴键，在小节末尾添加音符 | 线谱、简谱 |

## 音值组合输入

先按音名把一小节的音符录进去（时值随便），再统一换节奏：

1. 选中这个小节，按 `空格`，弹出音值组合浮窗。
2. 浮窗按当前生效的拍号，把这一小节的音名排成尽可能多的节奏型（二八、四十六、前八后十六、小切分、前后小附点、大切分、前后大附点、长音等的各种组合），每张卡片一种，正好占满整小节。常用的排在前面，最多列 60 种。
3. 按卡片上的键（主键盘数字、字母，不够时用右侧小键盘的数字和 `.` `+` `-` `*` `/`，卡片上显示为 `Num1`、`Num+` 等）直接套用；也可以用方向键挑选后按 `Enter` 或 `空格`，或用鼠标点击。键按显示顺序分配，排在后面的卡片没有键，用方向键或鼠标选。鼠标移过卡片不会改当前候选，只有方向键或点击才会换。
4. 按 `Esc` 关闭浮窗。

编辑页顶部的「音值组合」可切换两种模式（浮窗打开时也可按 `Tab` 切换），默认是「按拍」，选择会被记住：

- **按小节**：上面说的方式，把整个小节换成所选节奏型。
- **按拍**：只组合小节末尾一拍的音，适合边录边组合。
  - 从最后一个音往前找，遇到带「组合标记」的音就停下，标记之后的音就是这次要组合的音。
  - 选好节奏型后，这组的最后一个音会打上组合标记。比如录了 1 2 3 按 `空格` 组合，3 会被标记；不满意可以再按 `空格` 重新组合 1 2 3；接着录 4 5 再按 `空格`，就只组合 4 5。
  - 音多到一拍放不下时，从后往前只取一拍能放下的音（四分音符为一拍时最多 16 个六十四分音符），前面的音不参与组合，浮窗会提示。例如 111122223333444455556666 只组合 3333444455556666，卡片里既有整拍一条符杠的方案，也有按半拍断开成 33334444、55556666 两组符杠的方案。
  - 组合标记显示在音符 / 休止符属性栏「节奏」分组里，可以手动关掉，让下一次组合越过它。按小节组合不会改动这些标记。

- 6/8、9/8、12/8 等复拍子按附点四分一拍来组合。
- 音太多或太少、怎么排都占不满小节时，浮窗会提示没有可用的节奏型。
- 只改时值、附点和符杠，音高、歌词、连音线等保持不变；可以用 `Ctrl+Z` 撤销。
- 鼓谱上下两个声部互相独立，只按工具栏当前声部的音符数组合、预览也只显示该声部；当前声部为空时不弹出。时值不超过四分音符。
- 暂不支持三连音。

## 标准模式

编辑页右上角的「标准模式」开关，选择会被记住。开启后：

- 用键盘、鼠标或 MIDI 键盘录入的音符，如果让小节的总时值超过拍号，这个音会自动挪到**下一小节**的末尾，并选中下一小节；本小节剩下的时值用休止符补满。
- 音符本身比整个小节还长时（例如 2/4 拍里写全音符），提示「音符时值不正确」，不会写入。
- 「下一小节」和方向键 `→` 一致：行末跳到下一个复谱表同一行单谱表的第一小节；已经是最后一个小节时提示，不会写入。
