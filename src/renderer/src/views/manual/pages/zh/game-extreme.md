「不准漏音，挑战存活」。极限模式不计分，比的是**存活时间**，而且难度会随时间不断升高。

## 规则

- 开局 3 条命。
- **任何音符块超时消失都扣 1 条命**，包括治疗块。
- 乱按（按了场上没有的音）直接扣 1 条命。
- 不会出现炸弹、冰冻、加倍，只会出现绿色光晕的**治疗块**：切到后恢复 1 条命，最多 3 条。
- 没有连击，也不计分。顶部显示剩余生命和已存活时间（秒.毫秒）。
- **不受**首页「街机/无限模式难度」设置影响；「游戏曲谱模式」（线谱 / 简谱）仍然有效。

## 难度递增

开局很温和：只有高音和低音谱号，只有 C 大调，没有变音记号（只会出白键上的音），音符块停留 3 秒，再用 2 秒淡出。

之后难度连续上升：音符块的停留时间、出块间隔都按**每 60 秒减半**的速度缩短，60 秒时是开局的一半，120 秒时是四分之一，以此类推。同时，每过 10 秒还会解锁新的内容：

| 存活时间 | 新增内容 |
| --- | --- |
| 10 秒 | 出现升号、降号 |
| 20 秒 | F、G 大调 |
| 30 秒 | D、B♭ 大调 |
| 40 秒 | A、E♭ 大调 |
| 50 秒 | E、A♭ 大调 |
| 60 秒 | B、D♭ 大调，并出现重升、重降 |
| 70 秒 | F♯、G♭ 大调 |
| 80 秒 | C♯、C♭ 大调（至此全部 15 个调号都会出现），并出现中音谱号 |

音域始终是 D2 到 B5（MIDI 38–83）。

成绩就是存活时间。历史最长存活按线谱和简谱分别记录，可以在 [成就](#achievements) 页查看。
