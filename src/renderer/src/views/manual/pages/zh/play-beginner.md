新手模式**不限速度**：把需要同时按下的键全部按住，才会进入下一步。适合刚开始学一首曲子、还跟不上速度的时候。

## 界面

和 [练习模式](#play-practice) 类似：上方是曲谱，下方是屏幕钢琴。不同的是瀑布流换成了一叠**彩色方块**，每一层方块就是下一步要按的键。

## 怎么弹

1. 点「开始练习」。会先响一小节节拍器作为预备拍。
2. 看最下面一层方块，按下对应的键。同时开始的音（例如和弦）是一层，需要**同时按住**。
3. 全部按对后，方块落下，进入下一步。曲谱上当前要弹的音符显示为红色，弹完的变为绿色，曲谱也会自动滚动到当前位置。
4. 弹完最后一步后自动结束，颜色清除。

- 没有时间限制，也不判定早晚；按错不扣分，只是不会前进。
- 新手模式没有分数，也没有暂停按钮，结果不会保存。

## 输入方式与声音

| 输入方式 | 能否推进 | 是否发声 |
| --- | --- | --- |
| MIDI 键盘 | 能 | 发声，使用工具栏选择的音色 |
| 鼠标点击屏幕钢琴 | 能 | 发声 |
| 电脑键盘 | 能 | 发声，和 MIDI 键盘相同 |

电脑键盘的键位和用法见 [练习模式](#play-practice) 的「电脑键盘弹琴」。新手模式**不播放曲谱**，你听到的只有自己弹的声音。

## 工具栏

| 按钮 | 说明 |
| --- | --- |
| 返回 | 回到播放模式 |
| 设置 | 打开「新手模式设置」，只能在停止时打开 |
| 开始练习 / 停止 | 开始或结束 |
| 音量 | 0–100%，默认 100%，控制你弹奏的声音 |
| 音色 | 你弹奏时使用的音色，只能在停止时修改 |
| 曲谱类型 / 转调 / 升半音 / 降半音 | 与 [播放模式](#play-features) 相同，只是临时改变 |
| 快捷键 | 打开电脑键盘键位图，见 [练习模式](#play-practice) |
| 隐藏曲谱 / 显示曲谱 | 隐藏后只看彩色方块 |

曲谱中没有可以弹的音符时，会提示「当前曲谱没有可练习的音符」。

## 新手模式设置

| 分组 | 设置 | 说明 |
| --- | --- | --- |
| 显示 | 遮盖 midi 块 | 默认关闭。打开后挡住彩色方块，只能看曲谱或凭耳朵 |
| 声音 | 虚拟钢琴音量 | 0–100，默认 100，控制你弹奏的声音。和工具栏的「音量」是同一项，改哪边都一样 |
| 节拍器 | 节拍器音量 | 0–100，默认 80 |
| 节拍器 | BPM | 40–240，默认取曲谱的速度。只影响预备拍和节拍器，不影响弹奏 |
| 节拍器 | 练习过程开启节拍器 | 默认关闭 |
| 声部选择 | 单谱表 1、2…… | 默认全部打开。关闭某一行后，这一行变透明，也不再需要弹 |

可以用「声部选择」只练右手或左手。
