本页介绍 TAB 谱中音符的添加、修改与删除。

## 用鼠标添加

1. 点击一个小节将它选中。
2. 在左上角工具栏选好类型、时值和品数。
3. 把鼠标移到小节里，会出现一个半透明的**预览**，上下移动选择弦。
4. 点击即可添加。

添加的位置取决于你点在哪里：

- 点在**两个音符之间**：插入一个新音符。
- 点在**已有音符上**、但在另一根弦：在同一时刻叠加一个音，组成和弦。
- 点在已有音符上、同一根弦：改为选中它。
- 琶音、扫弦和休止符只能插在音符之间。

## 修改弦：拖动

选中一个品数后，按住它**上下拖动**即可换到其它弦上。

## 音符属性栏

选中一个品数（或琶音、扫弦）后，右侧显示「音符属性」，和五线谱一样分为「属性」「记号」「连线」三个标签页。

### 属性

| 项目 | 说明 |
| --- | --- |
| 和弦图 | 从「和弦管理」中选择一个和弦图，显示在音符上方；选「无」去掉。只列出和当前弦数对应的和弦：4 弦谱列出四弦和弦，5 弦谱列出五弦和弦，6 弦谱列出六弦和弦 |
| 品 | x、0–27。只有标准音和泛音有这一项 |
| 开始弦 / 结束弦 | 只有琶音和扫弦有这一项 |
| 时值 | 全音符到一百二十八分音符。同一时刻的所有音一起改 |
| 附点 | 无 / 1 / 2 / 3 个附点。同一时刻的所有音一起改 |
| 符杠 | 全连 / 右连 / 无 |
| 拍弦 | 勾选后标记为拍弦 |
| 推弦 | 只有标准音和泛音有这一项，见下文 |
| 倚音 | 添加前倚音 / 后倚音（只有标准音和泛音） |
| 横向偏移 | 滑块 -40 到 40，微调这个音的左右位置；「重置位置」恢复为 0 |

### 记号

给选中的音添加重音、断奏、颤音、力度等单音符记号，见 [其它符号](#edit-symbols)。

### 连线

添加琶音、扫弦、前奏括号、连音线、踏板、8va / 8vb、颤音线、渐强渐弱等跨音符记号，见 [其它符号](#edit-symbols)。

和弦图来自 [和弦管理](#chords) 中保存的和弦，你也可以在那里创建自己的和弦图。和弦图放进曲谱时会复制一份，之后在和弦管理中修改它，不会影响已经放进曲谱的和弦图。

### 推弦

点「添加推弦」后可以设置：

- **类型**：推弦、推弦再回来、预推弦、预推弦再回来、预推弦再升高。
- **阶段 1**、**阶段 2**：两个阶段的推弦幅度，可选 0–3，以 0.5 为一档。
- 点「移除推弦」删除。

在谱面上点击推弦的曲线也可以选中它，属性栏显示同样的设置，另外还有：

- **位置偏移**：X / Y 输入框，微调整条推弦曲线的位置。
- **重置位置**：恢复默认位置。
- **删除**：删除这个推弦。

## 连音线的类型

在谱面上点击一条连音线，可以设置它的类型：

| 类型 | 含义 |
| --- | --- |
| 无 | 普通的连音线 |
| 击弦 H | 左手手指直接敲击琴弦发出后一个音 |
| 滑弦 S | 按住琴弦滑到后一个品 |
| 勾弦 P | 左手手指勾拨琴弦发出后一个音 |
| 击勾弦 HP | 击弦和勾弦组合 |

其余设置和五线谱的连音线一样：线宽、覆盖范围（含「重置对齐」）、和弦时的起止音、起止点位置、居中控制点，以及「应用当前位置到」本小节 / 单谱表 / 复谱表 / 全谱的其它连音线。

## 删除

- 选中后按 `Delete` 或 `Backspace`。
- 同一时刻有多个音时，只删除选中的那一个。
