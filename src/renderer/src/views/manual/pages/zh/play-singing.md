演唱模式通过麦克风实时识别你唱的音高，把它画在瀑布图上和标准音高对比，唱完后给出综合评分。

> 建议**戴耳机**。软件没有开启回声消除，用外放时麦克风可能会把伴奏也当成你的声音。

## 要求

- 需要麦克风，第一次使用时请允许麦克风权限。可以先在 [麦克风检测](#tool-mic) 中确认麦克风正常。
- 进入条件和其它子模式相同，见 [播放模式](#score-play)。
- **只判定第一行（第一个单谱表）**，其它行会变淡。一般把旋律放在第一行。

## 界面

- **曲谱**：一长行，自动滚动。
- **信息栏**：BPM、要判定的音符数量、当前偏移、状态（准备中 / 检测中）。
- **瀑布图**：横向的音高图，音域 C2 到 C6，左侧标有各个 C 的位置。音符从右向左移动，经过中间固定的竖线时就是该唱的时刻。
- **偏移栏**和**工具栏**。

瀑布图中的颜色：

| 元素 | 含义 |
| --- | --- |
| 粉色条 | 标准音：应该唱的音高和时长 |
| 绿色条 | 已唱：你唱对的部分 |
| 黄色小球 | 实时音高：你现在唱的音高，只在检测中显示 |

## 选择音源

工具栏的下拉框可以选择伴随你演唱的声音：

| 音源 | 说明 |
| --- | --- |
| 曲谱 | 播放曲谱本身（全部声部），速度取曲谱的速度 |
| 范唱 | 播放绑定的范唱音频，按 [谱音同步](#edit-sync) 对齐的时间判定 |
| 伴奏 | 播放绑定的伴奏音频，按谱音同步对齐的时间判定 |

- 没有绑定范唱或伴奏时，对应选项是灰色的。
- 选择范唱或伴奏时，没有对齐时间的音符不参与判定；一个都没对齐时，「开始检测」按钮不可用。

## 开始演唱

1. 选好音源，点「开始检测」。
2. 麦克风打开后，瀑布图左侧倒数 3、2、1。
3. 倒数结束，音源开始播放，跟着唱即可。
4. 唱完最后一个音后自动结束，也可以随时点「停止」。倒数过程中停止不会出结果。

演唱模式没有音量、BPM、音色的调节。

## 判定规则

- 你唱的音和目标音相差 **3 个半音以内**时，会被校正到目标音上。
- 软件会自动估计你的嗓音和曲谱之间整体差了多少个半音。所以男生唱女生的歌、整体低一个八度唱，也能正常判定。
- 曲谱上的音符会按结果描边变色。

### 初始音高偏移

偏移栏的「初始音高偏移」（-48 到 48 个半音，默认 0）用来告诉软件你通常比曲谱高或低多少，让判定一开始就对准：

- 例如习惯低八度唱，可以填 -12。
- 填好后直接开始就会生效；点「保存」后，下次打开软件也会从这个偏移开始。

## 测评结果

演唱结束后弹出「演唱测评结果」，从三个方面打分：

| 项目 | 含义 |
| --- | --- |
| 音准 | 在所有音符的总时长中，你唱在正确音高上的时间占多少 |
| 节奏 | 有多少音符你在开始后一个十六分音符的时间内就唱准了 |
| 完整度 | 有多少音符你在它持续期间唱准过 |

总分是三项的平均值：90 分以上「出色！」，80 分以上「很好」，70 分以上「不错」，60 分以上「继续加油」，60 分以下「再试一次」。点「知道了」关闭。结果不会保存。

## 从作品进入

在「我的作品」展示模式中，右键带有范唱或伴奏的曲谱，选择「进入演唱模式」，也可以直接演唱，见 [元素功能](#work-show-elements)。
