和弦弹唱谱是「歌词 + 和弦」的弹唱谱：每个字上方标出要按的和弦，适合吉他、尤克里里边弹边唱。它和线谱、简谱不同，没有节拍和时值，只记录歌词与和弦的位置。

## 新建与打开

- 在「我的曲谱」点「新建曲谱」，选「和弦弹唱谱」分组里的「空」，进入编辑页面。
- 保存后会出现在「我的曲谱」列表中，卡片左上角带「弹唱」标记，点击即可打开。
- 曲谱名称就是弹唱谱的**歌名**，歌名为空时保存为「未命名弹唱谱」。

## 展示与编辑

页面右上角可以在「展示」和「编辑」之间切换：

- **展示**：只显示谱面，适合弹唱时看。打开已保存的弹唱谱时默认是展示。
- **编辑**：可以改歌名、描述、作者、歌词与和弦，右侧显示样式和和弦文本面板。描述写在歌名下方左侧（如「1=C 4/4」），作者在右侧。

## 写歌词与和弦

| 操作 | 说明 |
| --- | --- |
| 添加一行 | 点谱面最下方「＋ 添加一行」，直接输入歌词，Enter 换行 |
| 改整行文字 | 双击这一行（或选中字后按 Enter）；Enter 拆行，行首 Backspace 与上一行合并，可一次粘贴多行 |
| 设置和弦 | 点一个字，在弹出的面板里选和弦，也可以设置这个字的颜色和下划线 |
| 切换选中 | ← → ↑ ↓ 切换字，Delete 删除和弦，Esc 取消选中 |
| 移动和弦 | 拖动和弦到别的字上；按住 Ctrl 拖动是复制 |
| 行操作 | 鼠标移到行上，右侧出现编辑、上移、下移、插入、删除按钮 |

> 行尾需要放和弦但没有字时，可以在行尾打空格，再给空格设置和弦。

## 和弦文本

右侧「和弦文本」用方括号写和弦，放在对应的字前面，例如：

```text
[C]好一朵美丽的[Am]茉莉[C]花
[F]好一朵美丽的[C]茉莉[G]花
```

- 谱面修改后，文本会同步更新，点「复制文本」可复制出去分享。
- 把网上找到的和弦歌词粘贴进来，点「导入到曲谱」即可生成谱面（会替换当前全部歌词与和弦）。
- `{#e6553a}` 写在字前是歌词颜色，写在 `[和弦]` 前是和弦颜色；`{u}` 是下划线。

## 顶部曲谱

弹唱时常需要看节奏型，可以在编辑模式右侧「顶部曲谱」里，从「我的曲谱」中选一首打好的曲谱，添加到弹唱谱最上方。

- 添加时会把曲谱复制一份存进弹唱谱。之后修改或删除「我的曲谱」里的原曲谱，弹唱谱里的这份都不受影响；想同步修改，重新选一次即可。
- 已添加时，下拉框用来替换成另一首曲谱；点「移除」去掉顶部曲谱。
- 展示区默认较矮，编辑时拖动展示区的下边缘，或用「区域高度」滑块调节高度；内容放不下时可在区域内滚动。
- 「曲谱缩放」调节曲谱显示大小。
- 打开「和弦只显示名称」后，曲谱里的和弦图只画和弦名，不画指法框，更省地方。

## 样式

在「样式」面板可调整纸张宽度、歌词字号、行距、字体、歌词颜色和和弦颜色，这些设置随弹唱谱一起保存。点「恢复默认」可还原。

「新加歌词」「新加和弦」是之后新加的字和和弦写入的颜色，比如想把副歌标成另一种颜色，先选好颜色再写。它们不改已有内容；清空后新加的内容跟随上面的歌词颜色、和弦颜色。

## 和弦歌词

右侧「和弦歌词」面板一次修改所有带和弦的字，没有和弦的字不变：

- **加下划线**：打开给所有带和弦的字加下划线，关闭则全部去掉。只有全部都有下划线时开关才显示为打开。
- **改颜色**：选一个颜色，所有带和弦的字都改成这个颜色；清空颜色则恢复为默认歌词颜色。颜色不一致时取色器显示为空。

行尾只为放和弦打的空格不算在内。

## 保存

点右上角「保存」或按 Ctrl + S。有未保存的改动时，标题旁会显示「未保存」，离开页面前会提示确认。

## 导入与导出

弹唱谱用 `.json` 文件导入导出（不是曲谱的 `.sj` 格式），适合备份或分享给别人。

- **导出**：点右上角「导出」，把当前弹唱谱存成 `.json` 文件，包括歌词、和弦、描述、样式和顶部曲谱。还没保存的改动也会一起导出。
- **导入**：点右上角「导入」选择 `.json` 文件，文件内容会替换当前弹唱谱。导入后显示「未保存」，点「保存」才写入；想另存为一份新弹唱谱，先新建一个空白弹唱谱再导入。
