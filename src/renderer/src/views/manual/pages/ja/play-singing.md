歌唱モードでは、マイクで歌声の音程をリアルタイムに検出し、ウォーターフォール図上に描いて基準の音程と比べます。歌い終わると総合評価が表示されます。

> **ヘッドホンの使用**をおすすめします。エコーキャンセルは有効になっていないため、スピーカーで鳴らすと、マイクが伴奏の音まで歌声として拾ってしまうことがあります。

## 必要な条件

- マイクが必要です。初めて使うときはマイクの使用を許可してください。先に [マイクチェック](#tool-mic) でマイクが正常に動作するか確認できます。
- 入るための条件はほかのサブモードと同じです。[再生モード](#score-play) を参照してください。
- **判定されるのは 1 段目（最初の単譜表）だけ**で、ほかの段は薄く表示されます。通常はメロディーを 1 段目に置きます。

## 画面構成

- **楽譜**：1 行に長く並び、自動でスクロールします。
- **情報バー**：BPM、判定する音符の数、現在のオフセット、状態（準備中 / 検出中）。
- **ウォーターフォール図**：横向きの音程図で、音域は C2〜C6、左側に各 C の位置が示されています。音符は右から左へ流れ、中央の固定された縦線を通過する瞬間が歌うタイミングです。
- **オフセットバー**と**ツールバー**。

ウォーターフォール図の色：

| 要素 | 意味 |
| --- | --- |
| ピンクのバー | 基準音：歌うべき音程と長さ |
| 緑のバー | 歌唱済み：正しく歌えた部分 |
| 黄色の小さな玉 | リアルタイムピッチ：今歌っている音程。検出中のみ表示されます |

## 音源の選択

ツールバーのドロップダウンで、歌に合わせて流す音を選べます：

| 音源 | 説明 |
| --- | --- |
| 楽譜 | 楽譜そのもの（全声部）を楽譜のテンポで再生します |
| 模範歌唱 | 関連付けられた模範歌唱のオーディオを再生し、[譜面と音声の同期](#edit-sync) で合わせたタイミングで判定します |
| 伴奏 | 関連付けられた伴奏のオーディオを再生し、譜面と音声の同期で合わせたタイミングで判定します |

- 模範歌唱や伴奏が関連付けられていない場合、該当する項目はグレー表示になります。
- 模範歌唱または伴奏を選んだ場合、タイミングが合わせられていない音符は判定の対象外です。1 つも合わせられていない場合は「検出開始」ボタンを使えません。

## 歌い始める

1. 音源を選び、「検出開始」をクリックします。
2. マイクがオンになると、ウォーターフォール図の左側で 3、2、1 とカウントダウンします。
3. カウントダウンが終わると音源の再生が始まるので、合わせて歌います。
4. 最後の音を歌い終えると自動で終了します。いつでも「停止」をクリックして止めることもできます。カウントダウン中に停止した場合、結果は表示されません。

歌唱モードには音量、BPM、音色の調整はありません。

## 判定ルール

- 歌った音と目標の音の差が **3 半音以内**であれば、目標の音に補正されます。
- 歌声と楽譜の間に全体として何半音のずれがあるかを自動で推定します。そのため、男性が女性の曲を歌う場合や、全体を 1 オクターブ低く歌う場合でも、正しく判定できます。
- 楽譜上の音符は、結果に応じて縁取りの色が変わります。

### 初期ピッチオフセット

オフセットバーの「初期ピッチオフセット」（-48〜48 半音、既定は 0）で、普段楽譜よりどれくらい高く・低く歌うかを伝えておくと、最初から判定が合いやすくなります：

- たとえば、いつも 1 オクターブ低く歌うなら -12 と入力します。
- 入力してそのまま開始すれば反映されます。「保存」をクリックすると、次回アプリを開いたときもこのオフセットから始まります。

## 評価結果

歌い終わると「歌唱評価の結果」が表示され、3 つの観点で採点されます：

| 項目 | 意味 |
| --- | --- |
| 音程 | すべての音符の合計時間のうち、正しい音程で歌えていた時間の割合 |
| リズム | 音符の開始から 16 分音符 1 つ分の時間内に正しく歌えた音符の数 |
| 完成度 | 音符が続いている間に一度でも正しく歌えた音符の数 |

総合点は 3 項目の平均です。90 点以上は「素晴らしい！」、80 点以上は「とても良い」、70 点以上は「いい感じ」、60 点以上は「もう少し頑張ろう」、60 点未満は「もう一度挑戦」です。「OK」をクリックすると閉じます。結果は保存されません。

## 作品から入る

「マイ作品」のプレゼンモードで、模範歌唱または伴奏のある楽譜を右クリックし、「歌唱モードに入る」を選ぶと、そのまま歌うこともできます。[要素の機能](#work-show-elements) を参照してください。
