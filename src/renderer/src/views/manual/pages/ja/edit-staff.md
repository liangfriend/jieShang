五線譜は最も広く使われている記譜法です。五線譜では音高が五線上の音符の**位置**で決まるため、マウスでクリックした位置の音が追加されます。

## 追加ツールバー

五線譜の編集中、左上のツールバーには次の 2 つの項目があります。

| 項目 | 選択肢 | 既定 |
| --- | --- | --- |
| 追加 | 音符 / 休符 | 音符 |
| 音価 | 全音符、2分、4分、8分、16分、32分、64分、128分 | 4分音符 |

ツールバーの設定は、手動で変更するまで保持されます。付点や臨時記号などは、追加した後に右側のプロパティパネルで変更します。

## ショートカット

数字譜と同じく、**メインキーボードの数字と 3 列の文字キーで階名どおりに音符を入力**し、テンキーの数字で音価を切り替えます。階名は小節の調号に合わせた移動ドです（ハ長調なら 1 = C、ト長調なら 1 = G）。ト音記号の中音は C4–B4、ヘ音記号は 1 オクターブ下になります。

| キー | 機能 |
| --- | --- |
| メインキーボード `1`〜`7` | 選択中の小節の末尾に中音の ド、レ、ミ、ファ、ソ、ラ、シ を追加します。音価はツールバーの設定を使います |
| `Q` `W` `E` `R` `T` `Y` `U` | 1 オクターブ上の 1〜7 を追加します |
| `A` `S` `D` `F` `G` `H` `J` | 中音の 1〜7 を追加します |
| `Z` `X` `C` `V` `B` `N` `M` | 1 オクターブ下の 1〜7 を追加します |
| メインキーボード `0` / `~` / `I` / `K` | 選択中の小節の末尾に休符を追加します |
| テンキー `1`〜`8` | 音価を切り替えます：1 全音符、2 2分、3 4分、4 8分、5 16分、6 32分、7 64分、8 128分 |
| テンキー `0` | 「音符」と「休符」を切り替えます（マウスでの追加に反映） |
| MIDI キーボード | 小節を選択して鍵盤を押すと、対応する音高の音符を小節の末尾に追加します。音価はツールバーの設定を使います |

共通のショートカットは [編集モード](#score-edit) を参照してください。

## 五線譜だけの機能

- **ピアノ入力**：MIDI キーボードで演奏して、ピアノ譜をリアルタイムに記録します。[五線譜の録音入力](#edit-piano-record) を参照してください。
- **範囲選択**：まとめて音高を上げ下げしたり、音価を変更したりできます。[音符の範囲選択](#edit-box-select) を参照してください。
- **数字譜に変換**：右上の「楽譜の種類」で行います。[上部の機能](#edit-top) を参照してください。
- 小節には音部記号・調号・拍子記号を設定できます。[小節](#edit-measure) を参照してください。
