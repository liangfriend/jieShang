楽譜の管理とは、「マイ楽譜」の一覧画面のことです。ホーム画面で「マイ楽譜」をクリックすると開きます。

## 閲覧と検索

- 各楽譜はカードとして表示され、カードには楽譜名が表示されます。名前が空の場合は「？」と表示されます。
- 一覧は最終更新日時の順に並び、最近変更した楽譜が先頭に来ます。
- 上部の検索ボックスにキーワードを入力して少し待つと、名前で自動的にあいまい検索されます。入力欄の右側の × をクリックするとクリアできます。
- **カードをクリック**すると、その楽譜の [再生モード](#score-play) に入ります。
- 左上に「弾き語り」マークが付いたカードは [コード弾き語り譜](#cl-sheet) で、クリックすると弾き語り譜の画面が開きます。

## 楽譜の新規作成

右上の「新規楽譜」をクリックし、「テンプレートを選択」ダイアログでテンプレートを選ぶと、そのまま [編集モード](#score-edit) に入ります。

| グループ | テンプレート |
| --- | --- |
| 五線譜 | 空白 / 単声部 / 二声部 |
| 数字譜 | 空白 / 単声部 / 二声部 |
| TAB譜 | ギター譜 / ウクレレ譜 / 4弦ベース譜 / 5弦ベース譜 / 6弦ベース譜 |
| ドラム譜 | ドラムセット譜 |
| コード弾き語り譜 | 空白（[コード弾き語り譜](#cl-sheet) の画面に入ります） |

新規作成した楽譜は、編集モードで「保存」をクリックしてはじめて一覧に表示されます。

> 楽譜の種類は新規作成時に決まります。五線譜と数字譜はあとから相互に変換できますが、TAB譜とドラム譜は作成後にほかの種類へ変換できません。

## 既存の楽譜ファイルのインポート

一覧画面にはインポートボタンがありません。インポートは編集モードで行います。

1. 「新規楽譜」をクリックし、任意のテンプレートを選んで編集モードに入ります。
2. 右上の「読み込む」をクリックし、ファイル形式とファイルを選びます。インポートした内容で現在の楽譜が**上書き**されます。
3. 内容に問題がないことを確認してから「保存」をクリックします。

対応形式と注意点は [インポートとエクスポート](#edit-import-export) を参照してください。

## 名前の変更

楽譜の名前は楽譜の**タイトル**です。名前を変えるには、編集モードに入って譜面の一番上にあるタイトルを変更し、「保存」をクリックします。タイトルが空の場合、楽譜は「無題の楽譜」として保存されます。

## 削除

カードにマウスを重ねると、右上に赤いゴミ箱ボタンが表示されます。クリックし、「楽譜を削除」ダイアログで「削除」をクリックして確定します。

> 削除した楽譜は**元に戻せません**。大切な楽譜は、先に編集モードで `.sj` ファイルをエクスポートしてバックアップしておくことをおすすめします。
