このページでは、ドラムセット譜での音符と休符の追加・変更・削除について説明します。

## マウスで追加する

1. 小節をクリックして選択します。
2. 左上のツールバーで、声部・符頭・音価・付点を選びます。
3. マウスを小節の中に動かすと、半透明の**プレビュー音符**が表示されます。上下に動かして位置（線または間）を選びます。
4. クリックすると追加されます。

追加される位置は、クリックした場所によって変わります。

- **2 つの音符の間**：新しい音符を挿入します。
- **既存の音符の上**で、位置が異なる場合：同じタイミングに符頭を重ねます。たとえばスネアとハイハットを同時に叩く場合です。
- 既存の音符の上で、位置が同じ場合：その符頭を選択します。
- 休符は音符の間にのみ挿入できます。

挿入や重ねる操作は、現在選択している声部の中でのみ行われます。

## キーボードで追加する

小節を選択した状態で `A`–`T` の文字キー（`P` を除く）を押すと、対応するドラムの音符が現在の声部の末尾に追加されます。対応表は [ドラムセット譜](#edit-drum) を参照してください。

## 位置を変更する：ドラッグ

符頭または休符を選択したあと、**上下にドラッグ**すると、配置される線や間を変更できます。

## 音符のプロパティパネル

符頭を選択すると、右側に「音符のプロパティ」が表示されます。五線譜と同じく「基本」「記号」「ライン」の 3 つのタブに分かれています。

### 基本

| 項目 | 説明 |
| --- | --- |
| 符頭 | 通常、バツ、丸囲みバツ、丸囲みスラッシュ、三角形、ひし形 |
| 線位置 | 位置を数値で表します。0 が第1線（いちばん下の線）で、線または間を 1 つ上がるごとに 1 増え、8 が第5線（いちばん上の線）です。範囲は -6～14 です |
| 音価 | 4分音符から128分音符まで。音符全体（同じタイミングのすべての符頭）が変更されます |
| 付点 | なし / 付点 / 複付点 |
| 連桁 | 両側連結 / 右側のみ連結 / なし |
| 装飾音 | 前打音 / 後打音を追加します。符頭と線位置は主音符と同じになります |

「符頭」と「線位置」を変更するときは、[ドラムセット譜](#edit-drum) の使用可能な音符の表と照らし合わせてください。表にない組み合わせは、再生しても音が鳴りません。

### 記号

選択した符頭に、アクセント、スタッカート、強弱記号などの単一音符の記号を追加します。[その他の記号](#edit-symbols) を参照してください。

### ライン

アルペジオ、前奏括弧、スラー、ペダル、8va / 8vb、トリル線、クレッシェンド・ディミヌエンドなど、複数音符にまたがる記号を追加します。[その他の記号](#edit-symbols) を参照してください。右方向の音符は同じ声部の中だけで数えます。

## 休符のプロパティパネル

休符を選択すると「基本」と「記号」の 2 つのタブが表示されます。

| 項目 | 説明 |
| --- | --- |
| 音価 | 4分音符から128分音符まで |
| 付点 | なし / 付点 / 複付点 |
| 線位置 | -6～14。「中央」をクリックすると第3線に戻ります |

## 削除

- 選択して `Delete` または `Backspace` を押します。
- 同じタイミングに複数の符頭がある場合は、選択したものだけが削除されます。
