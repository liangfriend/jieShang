このページでは、数字譜での音符と休符の追加・変更・削除について説明します。

## マウスで追加する

1. 小節をクリックして選択します。
2. マウスを小節の中に移動すると、半透明の**プレビュー数字**が表示されます。マウスが上にあるほど数字が大きくなります（いちばん上が 7、いちばん下が 1）。
3. クリックすると追加されます。音価とオクターブ点は左上のツールバーの設定を使います。

数字譜では、新しい音符は**2 つの音符の間**にしか挿入できず、五線譜のように既存の音符の上をクリックして和音を重ねることはできません。同じ位置に複数の音を重ねたい場合は、後述の「多声部の音符を追加」を使ってください。

## キーボードで追加する

小節を選択してから、メインキーボードの `1`〜`7` を押すと小節の末尾に音符が直接追加され、`0` を押すと休符が追加されます。詳しくは [数字譜](#edit-number) のショートカットの説明を参照してください。

## 音高を変える：ドラッグ

音符を選択してから、数字を押したまま**上下にドラッグ**すると音高を変えられます。7 を超えてドラッグすると 1 オクターブ上の 1 に、1 を超えてドラッグすると 1 オクターブ下の 7 に自動で移り、オクターブ点もそれに合わせて変わります。

## 音符のプロパティパネル

数字をクリックして選択すると、右側に「音符のプロパティ」が表示され、「基本」「記号」「ライン」の 3 つのタブに分かれています。

### 基本

**音高**

- **階名**：1、2、3、4、5、6、7、X。X はリズム音（リズムだけを表し、具体的な音高を持たない音）です。
- **オクターブ点**：-3〜+3。3 オクターブ下から 3 オクターブ上に対応し、0 は点なしです。
- **臨時記号**：なし / シャープ ♯ / フラット ♭ / ダブルシャープ 𝄪 / ダブルフラット 𝄫 / ナチュラル ♮。設定すると横方向オフセットを調整できます。

**リズム**

- **音価**：全 / 2分 / 4分 / 8分 / 16分 / 32分 / 64分 / 128分。数字譜では、2 分音符と全音符は数字の後ろの延長線で、8 分音符以下の音符は数字の下の下線で表します。
- **付点**：なし / · / ·· / ···。
- **下線の連結**：両側連結 / 右側のみ連結 / なし。隣り合う音符の下線をつなげるかどうかを設定します。

**多声部の音符を追加**

同じ位置に音を重ねる（ハーモニーなど）手順：

1. 重ねたい音の「階名」（1〜7）、「オクターブ点」、「臨時記号」を選びます。
2. 「同じ位置に追加」を押します。

**横方向オフセット**：-40〜40 のスライダーで、音符全体の左右の位置を微調整します。

**装飾音**：「前打音を追加」「後打音を追加」で追加し、下の一覧から 1 つずつ削除できます。譜面上の装飾音をクリックすると単独で選択して変更できます。

### 記号

アクセント、スタッカート、トリル、強弱記号などの単一音符の記号を追加します。[その他の記号](#edit-symbols) を参照してください。

数字譜の音符には、さらに 2 つの**古箏**グループがあります。

- **古箏の指法**：托、劈、抹、挑、勾、剔、打、摘、提、撥、小撮、大撮。グループ内で 1 つのみ選べます。
- **古箏の奏法**：掃、揺指。指法と同時に追加できます。

### ライン

アルペジオ、スラー、ペダル、8va / 8vb、トリル線、クレッシェンド・ディミヌエンドなど、複数音符にまたがる記号を追加します。[その他の記号](#edit-symbols) を参照してください。数字譜のスラーには中央の制御点はありません。

数字譜では**古箏の連続指法**も追加できます。「範囲」を選んでから、連托、連劈、連抹、連挑、連勾、連剔、連打、連摘のいずれかをクリックします。譜表の下に、現在の音符から範囲の最後の音符まで描かれます。譜面上でクリックして選択すると、指法の変更、範囲や両端の位置の調整ができ、両端と中央のハンドルもドラッグできます。

## 休符のプロパティパネル

数字譜の休符は「0」です。選択すると「基本」と「記号」の 2 つのタブが表示され、音価、付点、下線の連結、横方向オフセットを変更したり、記号を追加したりできます。

## 削除

- 選択して `Delete` または `Backspace` を押します。
- 同じ位置に複数の音が重なっている場合は、選択した音だけが削除されます。
