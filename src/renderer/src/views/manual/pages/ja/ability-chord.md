コード聴き取りでは、コードが 1 つ再生され、4 つの選択肢からそのコード名を選びます。

## テスト設定

| 設定 | 選択肢 | 初期値 |
| --- | --- | --- |
| コードの種類（複数選択可） | メジャー / マイナー / セブンス / メジャーセブンス / マイナーセブンス。少なくとも 1 つ選びます | メジャー、マイナー |
| 音域 | 標準（ルート音が中央 C を含むオクターブ内）/ 全音域（ルート音の範囲がより広い） | 標準 |
| 鍵盤を表示 | 回答エリアにピアノを表示するかどうか | オン |
| 耳だけで判断 | オンにすると、回答中はピアノにコードが表示されず、結果が出てから表示されます。「鍵盤を表示」がオフのときは使えません | オフ |
| 出題数 | 1–12 | 6 |
| 制限時間（秒） | 3–20 | 8 |

## テストの流れ

1. 「テスト開始」をクリックすると、すべての音が同時に鳴るランダムなコードが再生されます（12 のルート音 × 選んだコードの種類。2 ラウンド続けて同じになることはありません）。
2. リングをクリックすると再生し直せます。
3. 4 つの選択肢からコード名を選びます。例：「C メジャー」「Cm」「C7」「Cmaj7」「Cm7」。ルート音はすべてシャープで表記されます。
4. 正誤が表示されたあと、自動で次のラウンドに進みます。

> 「鍵盤を表示」がオンで「耳だけで判断」がオフのときは、回答中にピアノ上でコードの構成音が青く表示されるため、ヒントが出ている状態になります。耳だけで聴き分けたい場合は「耳だけで判断」をオンにしてください。回答中はピアノに音が表示されず、結果が出たあとで正しいコードが緑で表示されるので、照らし合わせて確認できます。

## 結果

正答率、正解 / 不正解 / 時間切れのラウンド数、平均回答時間、最大連続正解数に加えて、コードの種類ごとの正答率も表示されるので、自分が混同しやすい種類を見つけられます。
