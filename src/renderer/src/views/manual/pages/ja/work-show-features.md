## 上部ツールバー

| ボタン | 説明 |
| --- | --- |
| 戻る | 作品一覧に戻ります |
| 編集 | [編集モード](#work-edit) に切り替えます |
| インポート | .sjw ファイルを選び、その内容で現在の作品を**置き換えます**。下記を参照してください |
| エクスポート | 「解熵作品 (.sjw)」「画像」「PDF」としてエクスポートします。下記を参照してください |
| 音量 | 0〜100%、既定は 100%。楽譜の再生と模範歌唱・伴奏の音量です。動画とオーディオの要素にはそれぞれの音量があり、この設定の影響を受けません |
| 一時注釈 | 「注釈」「ペン」「消しゴム」、色、太さ、「注釈をクリア」。下記を参照してください |

## ページ送り

左側のサムネイルをクリックしてページを切り替えます。プレゼンモードには全画面表示、拡大縮小、キーボードでのページ送りはありません。

## 一時注釈

授業で説明するときに、ページ上に直接書き込めます：

1. 「注釈」をクリックして注釈状態に入ります。
2. 「ペン」または「消しゴム」を選びます。
3. ペンは色を選べます（既定は黒）。太さは 1〜80 で、既定はペンが 3、消しゴムが 20 です。
4. ページ上でマウスをドラッグして描きます。ページの外まで描くこともできます。
5. もう一度「注釈」をクリックすると注釈状態を終了し、楽譜や動画などの要素を操作できる状態に戻ります。

- 「注釈をクリア」で消えるのは**現在のページ**の注釈だけです。注釈状態に入っていなくてもクリックできます。
- 注釈は**作品には保存されません**。ページを切り替えても残りますが、作品を離れるとすべて消えます。
- ずっと残しておきたい線は、編集モードの「描画を開始」で描いてください。[編集モードの機能](#work-edit-features) を参照してください。

> 編集モードで描いた線は作品に保存され、プレゼンモードでも表示されますが、「注釈をクリア」や消しゴムでは消せません。削除するには、編集モードに戻って「描画を開始」をクリックし消しゴムで消すか、「このページの描画をクリア」をクリックしてから「保存」してください。

## エクスポート

| 形式 | 説明 |
| --- | --- |
| 解熵作品 (.sjw) | すべての素材を含む完全な作品ファイルです。ほかのパソコンでインポートできます |
| 画像 | 1 ページにつき 1 枚の PNG を 2 倍の解像度で書き出します。1 ページだけの場合は画像が 1 枚、複数ページの場合は 01.png、02.png……を含む圧縮ファイルになります |
| PDF | 1 ページにつき 1 枚の画像を、1 つの PDF にまとめます |

画像と PDF をエクスポートする場合：

- オーディオの要素は画像に含まれません。
- 動画は最初のフレームとして表示されます。読み込めない場合は、黒地に再生アイコンが表示されます。
- 一時注釈はエクスポートされません。

エクスポート中は「エクスポート中… X / Y ページ」と表示されます。

## インポート

「インポート」をクリックして .sjw ファイルを選びます：

- ファイルの内容で**現在開いている作品の内容が置き換えられ**、1 ページ目に戻ります。
- インポートで変わるのは今表示されている内容だけです。保存するには編集モードに切り替えて「保存」をクリックします。**保存すると現在の作品が上書きされます**。

> ほかの人から受け取った .sjw を新しい作品としてインポートしたい場合は、先に作品一覧で「新規作品」をクリックし、新しい作品の中でインポートしてから保存してください。
