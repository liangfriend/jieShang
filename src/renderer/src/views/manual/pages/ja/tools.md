ツールには、練習でよく使う小さな道具がまとめられています。ホーム画面で「ツール」をクリックして開きます。

| ツール | 用途 | 必要なデバイス |
| --- | --- | --- |
| [チューナー](#tool-tune) | ギター、ベース、ウクレレのチューニング | マイク |
| [メトロノーム](#tool-metronome) | 指定したテンポと拍子記号で拍を刻む | なし |
| [ピッチ検出](#tool-pitch) | 歌ったり弾いたりした音の音名と周波数をリアルタイムで表示 | マイク |
| [マイクチェック](#tool-mic) | マイクが正常に音を拾えるか確認 | マイク |
| [MIDI デバイスチェック](#tool-midi) | MIDI キーボードが正しく接続され、信号が正常か確認 | MIDI キーボード |

「歌唱モードが反応しない」「ゲームで鍵盤を押しても反応しない」といった問題が起きたときは、まずマイクチェックと MIDI デバイスチェックでデバイスを確認してください。
