MIDI デバイスチェック（ページ名は「MIDI デバイスチェック」）では、MIDI キーボードが正しく接続されているか、送られる信号が正常かを確認できます。

## デバイス一覧

「入力」と「出力」の 2 列に分かれており、各デバイスの名前、メーカー、接続状態（接続済み / 未接続）が表示されます。

- MIDI キーボードは「入力」に表示され、「接続済み」になっているはずです。
- デバイスがないときは「MIDI 入力デバイスがありません」と表示されます。
- デバイスを抜き差しすると、アプリのどのページでも「MIDI デバイスが接続されました」または「MIDI デバイスが切断されました」という通知が表示されます。

## シグナルモニター

鍵盤を押したり、ペダルを踏んだり、ホイールを回したりすると、受信した信号がここにリアルタイムで表示されます：

| 項目 | 説明 |
| --- | --- |
| ランプ | アクティビティ（何らかの信号を受信すると点滅）、押鍵中、サステインペダル、ソフトペダル、ソステヌートペダル |
| メーター | ピッチベンド、モジュレーション、エクスプレッション、ボリューム CC7、チャンネルプレッシャー、ポリアフタータッチ |
| 数値 | チャンネル、プログラム番号、直近の MIDI ノート、ベロシティ、押下中、アフタータッチ音、直近の CC、入力元デバイス、生バイト |

「シグナルをリセット」ですべての表示をクリアします。

## 88 鍵ピアノ

ページ下部のピアノは MIDI キーボードに合わせて光るので、すべての鍵盤が認識されるか、音高が正しく対応しているかを確認できます。マウスで鍵盤をクリックして試聴することもできます。

## よくある質問

- **デバイス一覧にキーボードがない**：ケーブルと電源を確認する、別の USB ポートに挿す、または抜き差ししてから通知を待ってください。
- **「MIDI へのアクセス権限がありません。許可してから再試行してください」と表示される**：権限を許可してから、このページを開き直してください。
- **鍵盤のランプは光るのにほかの機能が反応しない**：ほかのソフトが MIDI デバイスを占有していないか確認してください。

ホーム画面右下の丸いアイコンでも、MIDI キーボードが接続されているかをすぐに確認できます。[解熵](#jieshang) を参照してください。
