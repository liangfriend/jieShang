再生モードの機能はすべて下部のツールバーにあります。再生中は楽譜が自動的にスクロールし、再生中の音符が画面の中央に来るようにします。停止すると先頭に戻ります。

## ツールバー

左から順に次のボタンがあります。

| ボタン | 説明 |
| --- | --- |
| 戻る | 前のページに戻ります |
| 編集モード | 再生を停止し、この楽譜の編集モードに入ります |
| 楽譜 / 模範歌唱 / 伴奏 | 何を再生するかを選びます。デフォルトは「楽譜」です。「模範歌唱」「伴奏」は、先に [譜面と音声の同期](#edit-sync) でオーディオを関連付けないとグレー表示のままです。再生中や一時停止中は切り替えられないので、先に「停止」をクリックしてください |
| 再生 / 一時停止 / 停止 | 一時停止したあと、もう一度「再生」をクリックすると一時停止した位置から続けます |
| 区間 | 一部の区間だけを再生します。下記を参照してください。「楽譜」のときのみ使えます |
| 音量 | 0–100%、デフォルトは 100% です。模範歌唱や伴奏の音量もこれで調整します |
| BPM | 再生テンポで、40–240 です。デフォルトは楽譜のテンポ（4分音符を 1 拍として換算）で、楽譜にテンポがない場合は 120 です。模範歌唱や伴奏の再生中は非表示になります |
| 音色 | 「楽譜の設定」または所持している任意の音色コレクションを選べます。再生中・一時停止中は切り替えられないため、先に「停止」をクリックしてください。TAB譜とドラムセット譜にはこのボタンがありません |
| 楽譜の種類 | 五線譜と数字譜の表示を一時的に切り替えます |
| 移調 | 「移調先の調」を選んで「移調」をクリックすると、楽譜全体を一時的に別の調へ移調します |
| 半音上げる / 半音下げる | 楽譜全体を一時的に半音上げる、または下げます |
| マーク | 数字譜に簫や笛子の運指を表示します。下記を参照してください |
| 練習モード / 初心者モード / 歌唱モード | 対応するサブモードに入ります。[再生モード](#score-play) を参照してください |

「楽譜の種類」「移調」「半音上げる / 半音下げる」は再生中には使えません。また、TAB譜とドラムセット譜にはこれらの項目がありません。

> 「楽譜の種類」「移調」「半音上げる / 半音下げる」は、いま表示している楽譜を変えるだけで、「マイ楽譜」には**保存されません**。この状態で「編集モード」をクリックすると、これらの変更はエディターに引き継がれ、エディターで保存したときに初めて反映されます。

### 音色のデフォルト

再生モードに入るたびに、音色は「楽譜の設定」、つまり単譜表ごとに設定した音色がデフォルトになります。音色を設定していない単譜表はグランドピアノで再生されます。

## 区間再生

特定の区間だけを繰り返し聴きたいときは、次のようにします。

1. 「区間」をクリックすると、楽譜の上に区間選択のバーが表示されます。
2. 音符をクリックして**開始位置**に設定します（緑色で表示）。「もう一つ音符をクリックして終了位置を設定」と表示されます。
3. もう一つ音符をクリックして**終了位置**に設定します（青色で表示）。
4. 「再生」をクリックすると、その区間だけが再生されます。

- もう一度音符をクリックすると、開始位置を設定し直せます。
- バーの「区間をクリア」で選択した開始位置と終了位置をクリアし、「区間選択を終了」で区間選択を終了します。
- 選択が終わる前に再生をクリックすると、「先に開始と終了の音符を選んでください」と表示されます。
- 「楽譜 / 模範歌唱 / 伴奏」や「楽譜の種類」を切り替えると、区間選択は自動的に終了します。

## 模範歌唱と伴奏の再生

[譜面と音声の同期](#edit-sync) で模範歌唱や伴奏を関連付けると、ドロップダウンで選べるようになります。

- 再生されるのは実際のオーディオで、楽譜のハイライトは合わせたタイミングに沿って移動します。
- オーディオを関連付けてもまだタイミングを合わせていない場合、オーディオは再生されますが楽譜はハイライトされず、「この楽譜には模範歌唱の譜面同期タイミングがまだありません……」と表示されます。
- 関連付けたオーディオを「マイオーディオ」で削除すると、「関連付けられたオーディオが見つかりません」と表示されます。

## 簫と笛子の運指マーク

「マーク」を使うと、各音符の下に運指を表示でき、吹奏に便利です。

- **8孔簫**：C、♭D、D、♭E、E、F、♭G、G、♭A、A、♭B、B 調の簫。
- **6孔笛子**：低いG、A、♭B、C、D、E、F、高いG 調の笛子。
- 「なし」を選ぶとマークが消えます。再生中でも切り替えられます。

お使いの楽器と同じ調の選択肢を選んでください。

## キーボードショートカット

再生モードにはキーボードショートカットはなく、すべての操作をツールバーから行います。
