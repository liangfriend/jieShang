ピッチ検出は、歌ったり演奏したりした音の高さをマイクでリアルタイムに判定し、ピアノと声域の上に表示します。正しい音程で歌う練習や、自分の声域の確認に使えます。

## 使い方

1. 「検出開始」をクリックし、マイクの使用を許可します。
2. マイクに向かって**安定した**音を歌うか演奏します。
3. 左側の「リアルタイム結果」に音名、周波数（Hz）、MIDI 番号が表示され、右側の縦向きのピアノで対応する鍵盤が光ります。
4. 「停止」をクリックすると終了します。

音高が検出されないときは「聴き取り中…安定した音を出してみてください」と表示されます。

## 無音しきい値

この値より小さい音は判定しません。範囲は 0.005–0.1、デフォルトは 0.020 です。周囲がうるさく誤検出が多いときは上げ、音が小さく検出されないときは下げてください。

## 声域の目安

右側に一般的な 6 種類の声域が表示されるので、自分が出せる最高音・最低音と比べてみましょう：

| 声域 | 範囲 |
| --- | --- |
| バス | E2–E4 |
| 一般男性 | A2–A4 |
| テノール | C3–C5 |
| アルト | F3–F5 |
| 一般女性 | A3–A5 |
| ソプラノ | C4–C6 |
