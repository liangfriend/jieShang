編集モードは作品を作るためのモードです。ページの管理、要素の追加と配置、楽譜や画像のトリミングを行います。

入り方：

- 作品一覧で「新規作品」をクリックします。
- プレゼンモードで上部の「編集」をクリックします。

## 画面構成

- **左側**：ページのサムネイル。下に「ページ追加」「挿入」「ページ削除」「コピー」ボタンがあります。
- **中央**：現在のページ。要素をクリックすると選択できます。
- **右側**：「ツール」パネル。描画、背景の設定、素材・テキスト・楽譜の追加に使います。
- **右上**：楽譜・画像・テキストを選択すると表示される「プロパティ」パネル。
- **上部**：「元に戻す」「やり直す」「設定」「プレゼン」「保存」と、インポート、エクスポート、音量。

## 基本的な流れ

1. 右側の「ツール」で楽譜、素材、テキストを追加します。新しく追加した要素は、すべてページ左上の (100, 100) の位置に置かれます。
2. 要素をドラッグして位置を調整し、四隅をドラッグしてサイズを調整します。
3. ページが足りなくなったら、左側の「ページ追加」または「挿入」をクリックします。
4. 「保存」をクリックします。

> **編集モードには自動保存がなく、離れるときにも保存の確認は表示されません。** こまめに「保存」をクリックしてください。

詳しくは [機能](#work-edit-features) を参照してください。
