解熵へようこそ！解熵は、音楽ゲーム、楽譜作成、ピアノ練習と歌唱評価、授業でのプレゼンをひとつにまとめた音楽ソフトです。左側の目次の各項目がそれぞれ 1 ページになっており、クリックすると表示できます。上部の検索ボックスでは、タイトルや本文からページを探せます。

## ホーム画面の概要

ホーム画面は上から順に、いくつかのブロックに分かれています。

- **ゲームモード**：「アーケードモード」「エンドレスモード」「エクストリームモード」の 3 枚のカードです。クリックするとすぐにゲームが始まります。[メインゲーム](#game) を参照してください。
- **メイン入口**：「マイ楽譜」「マイ作品」です。[マイ楽譜](#scores)、[マイ作品](#works) を参照してください。
- **その他の入口**：「授業用ホワイトボード」「コード管理」「能力テスト」「楽器シミュレーター」「マイオーディオ」「マイ画像」「マイ動画」「ツール」「コレクション」「実績」です。
- **フッター**：解熵の交流 QQ グループ番号です。困ったことがあれば、ぜひグループで質問してください。

> ウィンドウの高さが小さいときは、上部のロゴとソフト名が自動的に非表示になり、下の入口のためのスペースが確保されます。

## 設定

ホーム画面の**左下**にある歯車ボタンをクリックすると、「設定」ダイアログが開きます。変更はすべてすぐに反映され、自動的に保存されます。「完了」をクリックすれば閉じられます。

| 設定項目 | 説明 |
| --- | --- |
| 表示言語 | 中文 / English / 日本語。切り替えると画面全体がすぐにその言語に変わります |
| アーケード/エンドレスモードの難易度 | かんたん / ふつう / むずかしい。既定は「かんたん」です。アーケードモードとエンドレスモードにのみ影響し、エクストリームモードには影響しません |
| ゲームの楽譜モード | スイッチをオンにすると「数字譜」、オフにすると「五線譜」になります。既定は五線譜です。3 つのゲームモードすべてに適用されます |
| 音符ブロックの音 | 0–100。ゲーム中にノートブロックが出現したときに鳴る合図音の音量です |
| 使用マニュアル | このマニュアルを開きます |

ゲーム関連の設定は 1 回のゲームを始めるときに読み込まれます。ゲーム中に変更しても、プレイ中のゲームには影響しません。

## MIDI キーボード

ホーム画面の**右下**にある丸いアイコンは、MIDI キーボードの接続状態を表します。

- **緑**：接続済みです。マウスを重ねると「MIDI キーボード接続済み」と表示されます。
- **赤**：未接続です。マウスを重ねると「MIDI キーボード未接続」と表示されます。

MIDI デバイスを抜き差しすると、「MIDI デバイスが接続されました」または「MIDI デバイスが切断されました」というメッセージが表示されます。このアイコンは状態を表示するだけで、クリックはできません。

各機能で MIDI キーボードが必要かどうか：

| 機能 | MIDI キーボードの要否 |
| --- | --- |
| メインゲーム | **必須**。ゲームは MIDI キーボードからの入力しか受け付けません |
| 五線譜の録音入力（ピアノ入力） | **必須** |
| 練習モード、初心者モード | 推奨。マウスで画面上のピアノをクリックしたり、パソコンのキーボードで演奏したりすることもできます |
| 編集モードでの音符入力 | 任意。五線譜と数字譜で使えます |
| 授業用ホワイトボード | 任意。マウスで鍵盤をクリックしたり、パソコンのキーボードで弾いたりすることもできます |

デバイスが認識されているか、信号が正常かどうかは、[MIDI デバイスチェック](#tool-midi) で確認できます。

## マイク

[歌唱モード](#play-singing)、[チューナー](#tool-tune)、[ピッチ検出](#tool-pitch)、[マイクチェック](#tool-mic)、およびピッコロシミュレーターのマイク息入れモードではマイクを使います。初めて使うときはマイクへのアクセスを許可してください。マイクが正常に動作しているかどうかは、先に [マイクチェック](#tool-mic) で確認できます。

## 戻る

ほとんどの画面に「戻る」ボタンがあり、クリックすると前の画面に戻ります。前の画面がない場合はホーム画面に戻ります。
