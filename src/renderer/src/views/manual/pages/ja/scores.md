「マイ楽譜」は解熵の中心となる機能です。ここで楽譜を新規作成・編集・再生し、その楽譜を使ってピアノの練習や歌唱、作品づくりができます。

ホーム画面で「マイ楽譜」をクリックすると、楽譜一覧が開きます。各楽譜には 2 つの主なモードがあります。

- **再生モード**：一覧で楽譜カードをクリックすると開きます。試聴、移調、区間再生ができ、ここから練習モード、初心者モード、歌唱モードに入れます。
- **編集モード**：楽譜を新規作成したとき、または再生モードで「編集モード」をクリックすると開きます。楽譜の作成や修正に使います。

## 対応している楽譜の種類

| 種類 | できること |
| --- | --- |
| 五線譜 | 編集、再生、練習、歌唱。数字譜と相互に変換できます |
| 数字譜 | 同上 |
| TAB譜 | ギター譜、ウクレレ譜、4 / 5 / 6 弦ベース譜。編集と再生ができます。種類の変換はできず、練習モード、初心者モード、歌唱モードにも入れません |
| ドラム譜 | ドラムセット譜。編集と再生ができます。制限は TAB譜と同じです |

## 基本的な流れ

1. [楽譜の管理](#score-manage) で楽譜を新規作成します。MusicXML、MIDI、数字譜の画像などのファイルがすでにある場合は、編集モードで [インポート](#edit-import-export) できます。
2. [編集モード](#score-edit) で楽譜を作成・修正し、終わったら「保存」をクリックします。
3. 一覧に戻って楽譜をクリックし、[再生モード](#score-play) で試聴します。
4. [練習モード](#play-practice) や [初心者モード](#play-beginner) でピアノを練習したり、[歌唱モード](#play-singing) で歌唱を評価したりします。
5. 楽譜と画像、動画、テキストを組み合わせて教材を作りたい場合は、[マイ作品](#works) で楽譜を作品に追加できます。
