プレゼンモードでは、要素によってできる操作が異なります。楽譜、画像、動画の機能はすべて**右クリックメニュー**にあります。

## 楽譜

楽譜を右クリックすると、メニューに次の項目があります：

| メニュー項目 | 説明 |
| --- | --- |
| 再生 | 楽譜を再生し、再生中の音符をハイライトします。テンポは楽譜のテンポです。一時停止後にもう一度「再生」をクリックすると、止めた位置から続けて再生します |
| 区間選択 | 一部の区間だけを再生します。下記を参照してください |
| 模範歌唱を再生 | この楽譜に関連付けられた模範歌唱を再生し、合わせたタイミングで楽譜をハイライトします。模範歌唱がない場合はグレー表示です |
| 伴奏を再生 | 関連付けられた伴奏を再生します。伴奏がない場合はグレー表示です |
| 一時停止 / 停止 | |
| 歌唱モードに入る | この楽譜とその模範歌唱・伴奏を使って [歌唱モード](#play-singing) に入ります。模範歌唱も伴奏もない場合はグレー表示です |

- 再生時の音色：ギター譜・ウクレレ譜はナイロン弦ギター、ベース譜はアコースティックベース、ドラム譜は打楽器、それ以外はピアノです。楽譜内の単譜表に音色が設定されている場合は、その設定が優先されます。
- 楽譜の再生と模範歌唱 / 伴奏の再生は同時にはできません。一方を始めると、もう一方は停止します。
- 楽譜の模範歌唱と伴奏は、「マイ楽譜」で [譜面と音声の同期](#edit-sync) により関連付けたオーディオです。作品に追加するときに自動で引き継がれます。

### 区間選択

1. 右クリックして「区間選択」を選ぶと、ページ上に区間選択のバーが表示されます。
2. 音符をクリックして開始位置（緑）にし、もう一つ音符をクリックして終了位置（青）にします。
3. バーの「区間を再生」をクリックすると、その区間だけを再生します。

- もう一度音符をクリックすると、開始位置を設定し直します。
- バーには「停止」「区間をクリア」「区間選択を終了」もあります。右クリックメニューにも「区間をクリア」「区間選択を終了」があります。
- ページを切り替えたとき、モードを切り替えたとき、注釈を始めたときは、区間選択が自動で終了します。

## 画像

右クリックして「拡大」を選ぶと、ポップアップで大きな画像を表示します。

## 動画

- ページ上でそのまま再生する：画面中央の再生ボタンをクリックするか、画面をクリックして再生 / 一時停止を切り替えます。マウスを乗せると、下部にシークバー、時間、音量、ミュートボタンが表示されます。
- 右クリックして「再生」または「拡大」を選ぶと、ポップアップで拡大して再生します。

## オーディオ

オーディオの要素は小さなプレーヤーです。再生 / 一時停止、シークバー、時間があり、音量アイコンにマウスを乗せると音量の調整やミュートができます。オーディオには右クリックメニューはありません。

## テキスト

テキストは表示専用で、操作できる機能はありません。
