「クイック入力」を使うと、文字を打つように数字譜をテキストで書けるので、1 曲まるごとすばやく入力するのに便利です。**数字譜**でのみ使用でき、編集モード右上の「クイック入力」ボタンから開きます。

## 画面構成

クリックすると、下部に「数字譜クイック入力」パネルが表示されます。左側が「テキスト」の入力エリアで、その下に解析のヒントが表示されます。右側は「プレビュー」です。上部には 4 つのボタンがあります。

| ボタン | 機能 |
| --- | --- |
| 楽譜をテキストに変換 | 現在の楽譜をテキストに変換して左側に入力します。既存の楽譜をもとに修正したいときに便利です |
| プレビューを更新 | 左側のテキストから右側のプレビューを更新します。ショートカットは `Ctrl+S`（パネルを開いているときのみ有効） |
| プレビューを楽譜に反映 | プレビューで現在の楽譜を**上書き**し、成功するとパネルを閉じます |
| ルール | テキストの書き方のルールと例を表示します |

プレビューには、現在の楽譜のタイトル、調号、拍子記号、テンポ、基準となる拍、ページの幅がそのまま使われます。

> テキスト入力ではすべての記号（臨時記号、歌詞など）を表せません。反映時に確認が表示され、反映後は現在の楽譜にあったそれらの情報が失われる可能性があります。反映後も `Ctrl+Z` で元に戻せます。

## 書き方のルール

### 構成

- 1 行が 1 つの単譜表になります。
- 連続した空でない行が 1 つの大譜表になり、空行を 1 行入れると新しい大譜表が始まります。
- 音符はスペースで区切ります。

### 音符

- `1`~`7` はド~シに対応します。
- `0` は休符です。
- `X` はリズム音（音高なし）です。
- 数字の**前**に点を付けた `.5` は 1 オクターブ上、数字の**後**に点を付けた `5.` は 1 オクターブ下を表します。点は複数書けます。

### 音価

- `/` 下線：1 本ごとに音価が半分になります。`5/` は 8 分音符、`5//` は 16 分音符です。
- `-` 延長線：`5-` は 2 分音符、`5--` は付点 2 分音符、`5---` は全音符です。
- `,` 付点です。複数書けます。例：`5,`。
- `-` と `/` は同時に使えません。
- 小節の合計の音価が拍子記号と合わない場合は、ヒントエリアにヒントが表示されます。

### 組み合わせ

- `5(1)`：同じ位置に音を重ねます。複数続けて書けます。例：`5(1)(3)`。
- `[3]5`：前打音、`5[3]`：後打音です。装飾音の中でも `/` やオクターブ点が使えます。
- `<5`、`>3`：スラーの始点と終点です。音符の前に書きます。

### 小節線

- `|` は小節の終わりに書きます。スペースで区切った `|` ごとに 1 つの小節が終わります。
- `| |` のように前に音符がない場合は空の小節になります。`1 | | | |` は 4 小節です。
- 行頭の `|` は前方の小節線ではなく、空の小節になります。
- `|1|2` のように続けて書いたものは 1 本として扱われ、後のものが前のものを上書きします。
- `|` の後に数字を付けると、小節線の種類を指定できます。

| 書き方 | 小節線の種類 | 書き方 | 小節線の種類 |
| --- | --- | --- | --- |
| `\|1` | リピート開始 | `\|6` | 破線 |
| `\|2` | リピート終了 | `\|7` | 点線 |
| `\|3` | 終止線 | `\|8` | 逆終止線 |
| `\|4` | 両側リピート | `\|9` | 太線 |
| `\|5` | 複縦線 | `\|10` | 太い複縦線 |

### 対応していない内容

タイトル、調号、拍子記号、テンポは現在の楽譜を引き継ぎます。臨時記号、前方の小節線、歌詞などには対応しておらず、変換時に無視されてヒントエリアに一覧表示されます。

## 例

以下は 2 つの大譜表で、1 つ目の大譜表は 1 行、2 つ目の大譜表は 2 行です（間の空行で大譜表を区切っています）。

```
5. 4. <7. >6. .5(.6) | .7 .5 .5/ 5- |4

[1/2/]3 3/ 2/ <1, >2/ | 3(5) 0 .1- |2
1 1 5. 5. | 6.(1) 6. 5.- |2
```

## おすすめの使い方

1. パネルを開き、「楽譜をテキストに変換」を押して現在の楽譜のテキストを取得します。
2. 左側で修正したり続きを入力したりし、随時 `Ctrl+S` でプレビューを確認します。
3. ヒントエリアの内容に注意し、プレビューが正しいことを確認したら「プレビューを楽譜に反映」を押します。
4. エディターに戻り、臨時記号や歌詞などテキストで表せない内容を追加して、最後に保存します。
