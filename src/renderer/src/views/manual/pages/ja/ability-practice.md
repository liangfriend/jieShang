練習モードは、難易度を自分で決められる [エクストリームモード](#game-extreme) のようなものです。画面中央に大きな音符ブロックが 1 つだけ表示され、消えることはなく、正しく弾くと次のブロックに替わります。ライフ、時間切れ、特殊ブロックはないので、自分のペースで譜読みを練習できます。

## 練習の設定

最初に「練習の設定」が表示されます。設定は記憶され、次回も引き継がれます。

| 設定 | 説明 | 初期値 |
| --- | --- | --- |
| 譜面 | 五線譜 / 数字譜 | 五線譜 |
| 音部記号 | ト音記号 / ハ音記号（アルト）/ ヘ音記号から複数選択（五線譜のみ） | ト音、ヘ音 |
| 調号 | 15 種類の調号から自由に選択。「すべて」「C のみ」で一括設定 | C のみ |
| 臨時記号 | なし / シャープ・フラット / ダブルシャープ・ダブルフラットを含む（数字譜にダブルはありません） | なし |
| 音域 | スライダーで最低音と最高音を設定 | D2–B5（MIDI 38–83） |
| 音符の数 | 1–10000、または「無制限」にチェック | 50 |
| 出題時にその音を鳴らす | 新しいブロックが出たときにその音高を鳴らします | オン |
| 弾いたときにアプリで発音する | 鍵盤を押したときにアプリがピアノの音を鳴らします。電子ピアノ自体が鳴る場合はオフにできます | オン |
| バーチャルピアノを表示 | 画面下部にピアノを表示し、MIDI キーボードがなくてもマウスで答えられます | オン |

- 五線譜では音部記号ごとに出題できる音域が決まっています：ト音記号 B3–B5、ハ音記号 C3–C5、ヘ音記号 D2–D4。選んだ音部記号の範囲外の音域は出題されません。
- 設定の下に「現在の設定で出題できる音は N 個です」と表示されます。0 個のときは開始できないので、音域・音部記号・調号を広げてください。

## 練習の流れ

1. 「練習を始める」をクリックすると、中央に音符ブロックが表示されます。上には「完了」「ミス」の回数と経過時間、ヘッダーには「現在の番号 / 総数」（無制限のときは ∞）が表示されます。
2. MIDI キーボードかバーチャルピアノでその音を弾きます。オクターブも含めて音高が完全に一致する必要があります。
3. 正解するとすぐに次のブロックに替わります。間違えると赤く光って揺れ、ブロックはそのまま残るので弾き直せます。
4. 設定した数に達すると自動で終了します。「練習を終える」でいつでも結果を見られ、「中止」で設定画面に直接戻ります。「無制限」の場合は、手動で終えるか中止するまで続きます。

- 同じ音が 2 回続けて出ることはありません（出題できる音が 1 つだけの場合を除く）。

## 結果

- **一発正解率**：完了した音のうち、最初の打鍵で正しく弾けた割合。
- 完了した音の数、ミスタッチの回数、1 音あたりの平均時間、最長連続一発正解数、合計時間。
- 「もう一度練習」で同じ設定のままやり直し、「設定し直す」で設定画面に戻ります。

練習結果は保存されず、実績やハイスコアにもカウントされません。
