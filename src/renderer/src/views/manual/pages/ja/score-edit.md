編集モードは、楽譜の作成や修正を行うモードです。入り方は 2 通りあります。

- 「マイ楽譜」で「新規楽譜」をクリックし、テンプレートを選ぶ。
- 再生モードの下部ツールバーで「編集モード」をクリックする。

## 画面構成

- **左上**：音符を追加するためのツールバーです。音符と休符のどちらを追加するか、音価などを選びます。ツールバーの内容は楽譜の種類によって変わります。
- **右上**：機能ボタンです。[上部の機能](#edit-top) を参照してください。
- **中央**：楽譜本体です。楽譜上の要素をクリックすると選択できます。
- **右側**：プロパティパネルです。選択中の要素の編集可能なプロパティが表示されます。小節、音符、休符、タイ・スラー、記号、オクターブ記号、反復括弧（Volta）、括弧などを選択できます。何も選択していないときはヒントが表示されます。
- **下部**：「戻る」「再生モード」「譜面と音声の同期」の 3 つのボタンです。

## 基本的な流れ

1. **小節を選択する**：小節をクリックします。小節が選択されると、音符を追加できる状態になります。
2. **音符を追加する**：選択した小節内をマウスでクリックするか、パソコンのキーボードや MIDI キーボードで入力します。楽譜の種類ごとの方法は、[五線譜の編集](#edit-staff)、[数字譜](#edit-number)、[ドラムセット譜](#edit-drum)、[TAB譜](#edit-tab) を参照してください。
3. **修正する**：音符などの要素をクリックして選択し、右側のプロパティパネルで変更するか、譜面上で直接ドラッグします。
4. **保存する**：右上の「保存」をクリックします。

## 元に戻す・やり直し

- `Ctrl+Z` で元に戻し、`Ctrl+Y` または `Ctrl+Shift+Z` でやり直します。編集モードには元に戻すボタンがなく、ショートカットキーでのみ操作できます。
- 保持されるのは最大で約 20 ステップです。編集画面を離れると、元に戻す履歴はクリアされます。
- 元に戻す・やり直しを行ったあと、もともと選択していた小節がまだ存在すれば、選択状態が維持されます。
- カーソルが入力欄（タイトルや歌詞など）にあるときは、これらのショートカットは入力欄そのものに対して働きます。

## 保存

- 保存は右上の「保存」ボタンをクリックする方法しかなく、保存用のショートカットキーはありません。
- 楽譜の名前は譜面のタイトルから取られます。タイトルが空の場合は「無題の楽譜」として保存されます。

> **注意**：編集画面を離れるときに、保存を促すメッセージは**表示されません**。「再生モード」に切り替えると現在の変更が引き継がれるので、先に試聴してから戻ってくることもできますが、「保存」をクリックしない限り、変更は「マイ楽譜」に実際には書き込まれません。

## ショートカットキー一覧

Ctrl / Alt を押している間や、入力欄で文字を入力している間は、単一キーのショートカットは効きません。右上の「注意事項」ボタンにも詳しい説明があります。

| キー | 動作 | 対象の楽譜 |
| --- | --- | --- |
| `Esc` | まず範囲選択を解除し、次に選択を解除します | すべて |
| `Delete` / `Backspace` | 選択中の項目（音符、小節、譜表、複数の音符にまたがる記号など）を削除します | すべて |
| `Backspace`（小節を選択中） | 小節の最後の音符 / 休符だけを削除し、小節は残します。小節全体は `Delete` で削除します | すべて |
| `<`（または `,`） / `>`（または `.`） | 音符（または小節。その最後の音符。先に音符をクリックする必要はありません）を選択中：`>` は現在の音から次の音へスラーを付けます。現在の音がすでにスラーの始点なら、そのスラーを右に 1 音広げます。`<` は前の音から現在の音へ付け、現在の音がすでにスラーの終点なら左に 1 音広げます | すべて |
| `/` | 選択中の音符（または小節の最後の音符）を始点・終点とするスラーをすべて削除します | すべて |
| `{`（または `[`） | 小節を選択中、前置小節線を なし → リピート開始 → 逆向き の順に切り替えます | すべて |
| `}`（または `]`） | 小節を選択中、後置小節線を順に切り替えます（単・複・リピート終了・破線・終止・点線・太線・太い複線の 8 種類） | すべて |
| `Ctrl+Z` | 元に戻す | すべて |
| `Ctrl+Y` / `Ctrl+Shift+Z` | やり直し | すべて |
| `↑` `↓` `←` `→` | 小節を選択しているとき、上下左右の隣の小節に移動します | すべて |
| `*` | 現在の単譜表の下に単譜表を追加します。選択していない場合は最後に追加されます | すべて |
| `-` | 現在の大譜表の下に大譜表を追加します。選択していない場合は最後に追加されます | すべて |
| `スペース` | 音符のある小節を選択中に、リズムパターンのポップアップを開きます。下の「リズムパターン入力」を参照 | すべて |
| `P` | 小節を選択中、その小節の音符を次の小節にコピーし（元の音符は置き換え）、次の小節を選択します。続けて押すと次々に後ろへコピーできます。行末では次の大譜表の同じ段の単譜表の最初の小節に移ります | すべて |
| `1`–`8` | 音価を切り替えます：全音符、2 分、4 分、8 分、16 分、32 分、64 分、128 分 | TAB譜、ドラム譜（ドラム譜は 3–8 のみ。数字譜・五線譜はテンキーを使用） |
| `0` | 「音符 / 休符」を切り替えます | ドラム譜、TAB譜（数字譜・五線譜はテンキーの 0） |
| メインキーボードの `1`–`7`、`0` / `~` / `I` / `K` | 小節の末尾に中音の do–si / 休符を直接追加します | 数字譜、五線譜 |
| `Q`–`U` / `A`–`J` / `Z`–`M` | 小節の末尾に高音 / 中音 / 低音の 1–7 を追加します | 数字譜、五線譜 |
| メインキーボード `8` / `9` | ツールバーのオクターブ点を 1 つ下げる / 上げる（-3 〜 +3） | 数字譜 |
| `A`–`T`（`P` を除く） | 対応するドラムの音符を小節の末尾に追加します | ドラム譜 |
| `A`–`Z`（`P` を除く） | フレット 0–24 を切り替えます。マウスが小節内にあるときは同時に書き込みます | TAB譜 |
| MIDI キーボード | 小節を選択した状態で鍵盤を弾くと、小節の末尾に音符を追加します | 五線譜、数字譜 |

## リズムパターン入力

先に小節の音名を入力し（音価は何でも構いません）、あとからまとめてリズムを付けます。

1. 小節を選択して `スペース` を押すと、リズムパターンのポップアップが開きます。
2. ポップアップは、現在有効な拍子に合わせて小節の音名をできるだけ多くのリズムパターンで並べます（8 分 ×2、16 分 ×4、8 分 + 16 分 ×2、小シンコペーション、付点リズム、大シンコペーション、長い音などの組み合わせ）。1 枚のカードが 1 パターンで、どれも小節をちょうど満たします。よく使うものが先頭に並び、最大 60 枚です。
3. カードのキー（メインキーボードの数字、文字、足りない分はテンキーの数字と `.` `+` `-` `*` `/`。カードには `Num1`、`Num+` などと表示）を押すと適用されます。矢印キーで選んで `Enter` または `スペース`、またはクリックでも適用できます。キーは表示順に割り当てるため、後ろのほうのカードにはキーがありません。矢印キーかマウスで選んでください。マウスをカード上に動かしても候補は変わりません。
4. `Esc` で閉じます。

編集画面上部の「リズムパターン」で 2 つのモードを切り替えられます（ポップアップ表示中は `Tab` でも切り替え可）。デフォルトは「拍単位」で、選んだモードは記憶されます。

- **小節単位**：上で説明した方法で、小節全体を選んだリズムに置き換えます。
- **拍単位**：小節末尾の音だけを 1 拍にまとめます。入力しながら少しずつまとめたいときに便利です。
  - 最後の音から前へたどり、「まとめ印」の付いた音で止まります。その印より後の音が今回まとめる対象です。
  - リズムを選ぶと、まとめた最後の音に印が付きます。たとえば 1 2 3 を入力して `スペース` でまとめると 3 に印が付きます。気に入らなければもう一度 `スペース` で 1 2 3 をまとめ直せます。続けて 4 5 を入力して `スペース` を押すと、4 5 だけがまとめられます。
  - 1 拍に収まらないほど音が多い場合は、後ろから 1 拍に収まる分だけを使います（4 分音符 1 拍なら 64 分音符 16 個まで）。前の音は対象外になり、ポップアップに表示されます。たとえば 111122223333444455556666 では 3333444455556666 だけをまとめ、1 拍通しの連桁と、半拍で 33334444・55556666 の 2 本に分けた連桁の両方がカードに並びます。
  - まとめ印は音符 / 休符のプロパティパネルの「リズム」グループに表示され、手動でオフにすると次のまとめはその音を越えて続きます。小節単位のまとめはこの印を変更しません。

- 6/8、9/8、12/8 などの複合拍子は付点 4 分を 1 拍として組み合わせます。
- 音が多すぎる・少なすぎて小節を満たせない場合は、使えるパターンがないと表示されます。
- 変わるのは音価・付点・連桁だけで、音高・歌詞・スラーなどはそのままです。`Ctrl+Z` で元に戻せます。
- ドラム譜の上下 2 声部は独立しており、ツールバーで選択中の声部の音符数だけで組み合わせを作り、プレビューもその声部のみ表示します。選択中の声部が空なら開きません。4 分音符より長い音価は使いません。
- 3 連符にはまだ対応していません。

## 標準モード

編集画面右上の「標準モード」スイッチで切り替えます。選んだ状態は記憶されます。オンにすると：

- キーボード、マウス、MIDI キーボードで入力した音符によって小節の合計音価が拍子を超える場合、その音符は自動的に**次の小節**の末尾に移され、次の小節が選択されます。現在の小節の残りは休符で埋められます。
- 音符そのものが 1 小節より長い場合（たとえば 2/4 拍子で全音符を書く場合）は「音価が正しくありません」と表示され、書き込まれません。
- 「次の小節」は矢印キー `→` と同じです。行末では次の大譜表の同じ段の単譜表の最初の小節になります。すでに最後の小節の場合はメッセージが表示され、書き込まれません。
