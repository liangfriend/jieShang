練習モードは音楽ゲームのようなモードです。音符が上から落ちてきて、鍵盤に届いたときに対応する鍵盤を押すと、正確に押せたかどうかをソフトが判定します。

## 画面構成

上から順に次のようになっています。

- **楽譜**：楽譜全体を 1 本の長い行につなげたもので、再生中は自動的にスクロールします。
- **統計バー**：総音符数、弾き漏れ、早い、遅い、合格、グレート、パーフェクト、リアルタイムスコア、進捗。
- **ウォーターフォール**：88 鍵すべてをカバーします。音符ブロックが下端に届いた瞬間が押すタイミングです。
- **画面上のピアノ**。
- **ツールバー**。

## ツールバー

| ボタン | 説明 |
| --- | --- |
| 戻る | 再生モードに戻ります |
| 設定 | 「練習設定」を開きます。下記を参照してください。停止中のみ開けます |
| 再生 | 練習を開始します。停止状態から開始すると、まず 1 小節分のメトロノームが予備拍として鳴ります |
| デモ再生 | 3 秒のカウントダウンのあと、曲を自動で 1 回演奏します。すべての音符がパーフェクトと判定され、鍵盤も光るので、先にどう弾くかを見ておけます。デモ中は「デモ停止」に変わります |
| 一時停止 / 停止 | 一時停止したあと「再生」をクリックするとそのまま続き、予備拍は鳴りません |
| 音色 | 楽譜の再生に使う音色です。停止中のみ変更できます |
| 楽譜の種類 / 移調 / 半音上げる / 半音下げる | [再生モード](#play-features) と同じで、一時的な変更です |
| 演奏データをクリア | 統計と楽譜上の色をクリアします |
| ショートカット | パソコンのキーボードのキー配置図を表示します。下記「パソコンのキーボードで演奏」を参照してください |
| 楽譜を隠す / 楽譜を表示 | 楽譜を隠して、ウォーターフォールだけを見て練習できます |

## 弾き方

次の 3 つの方法で入力できます。

- **MIDI キーボード**（推奨）。
- **マウス**で画面上のピアノをクリック。
- **パソコンのキーボード**。下記「パソコンのキーボードで演奏」を参照してください。

> どの方法で押した鍵盤もピアノの音が鳴ります。音量は「練習設定」の「仮想ピアノの音量」で調整し、0 にすると楽譜の再生音だけが聞こえます。デモ再生で自動的に弾かれる鍵盤は、追加で音を鳴らしません。

### パソコンのキーボードで演奏

パソコンのキーボードは数字譜（1 = C）の並びになっていて、押したときの動作は MIDI キーボードとまったく同じです（音が鳴り、鍵盤が光り、判定されます）。何も開かなくてもそのまま弾けます。

ツールバーの「ショートカット」をクリックするとキー配置図が表示されます。各キーには対応する数字譜の音とオクターブの点が書かれ、押したキーが光ります。タイトルバーをドラッグすると移動でき、もう一度「ショートカット」をクリックするか右上の × で閉じます。

既定の音高（C4 が中央の C）：

| キー | 音高 |
| --- | --- |
| 数字キーの列 `1`–`7`、`8`–`=` | C5–B5、C6–G6 |
| `Q`–`U`、`I`–`\` | C4–B4、C5–A5 |
| `A`–`J`、`K`–`'` | C3–B3、C4–F4 |
| `Z`–`M`、`,`–`/` | C2–B2、C3–E3 |
| テンキー `0` `.` | A3、B3 |
| テンキー `1`–`7` | C4–B4 |
| テンキー `8` `9` `/` `*` `-` `+` `Enter` | C5–B5 |

- **Shift** を押しながら弾くと半音上がります（黒鍵）。
- キー配置図の下に 2 つのオクターブ設定があります。「文字キー側のオクターブ」はメインのキー部分を、「テンキーのオクターブ」はテンキーをまとめて上下させます。範囲は −3 〜 +3 で、横に `Q` キーとテンキー `1` の現在の音が表示されます。設定は自動で保存され、練習モード・初心者モード・授業用ホワイトボードで共通です。
- 88 鍵の範囲外になるキーは音が出ず、数字が薄く表示されます。
- Ctrl・Alt・Win を押している間や、カーソルが入力欄にあるときは演奏されません。

## 判定ルール

- 判定するのは**鍵盤を押した瞬間**と音符の開始時刻とのずれだけで、離すタイミングや押し続けた長さは判定しません。
- 間違えた鍵盤がどの音符の判定範囲にも入っていなければ、そのまま無視され、減点されません。
- 判定範囲を過ぎても押されなかった音符は「弾き漏れ」になります。
- ウォーターフォールは常にテンポどおりに進み、**あなたを待ちません**。自分のペースで練習したい場合は [初心者モード](#play-beginner) を使ってください。

判定範囲（ミリ秒。プラスとマイナスは早い・遅いを表します）：

| 難易度 | パーフェクト | グレート | 合格 | 早い / 遅い |
| --- | --- | --- | --- | --- |
| 初心者（デフォルト） | ±90 | ±140 | ±200 | ±260 |
| 経験者 | ±35 | ±60 | ±100 | ±150 |
| マスター | ±20 | ±35 | ±60 | ±100 |

**リアルタイムスコア**は、判定済みの音符の平均点です。パーフェクト 100、グレート 80、合格 60、早い / 遅い 50、弾き漏れ 0 で計算します。**進捗**は、すべての音符のうち判定済みの音符の割合です。

統計は曲が終わったあとも画面に残り、次に最初から「再生」したときや「演奏データをクリア」をクリックしたときにリセットされます。練習の結果は保存されず、実績にも反映されません。

## 楽譜上の色

「音符の判定をリアルタイム表示」をオンにすると、楽譜上の音符が判定結果に応じて色分けされます。

| 結果 | 色 |
| --- | --- |
| パーフェクト | 虹色のグラデーション |
| グレート | 緑 |
| 合格 | オレンジ |
| 早い | 水色 |
| 遅い | 薄いピンク |
| 弾き漏れ | 赤 |

停止中は `Shift` を押しながらマウスホイールを回すと、楽譜を左右に移動して確認できます。

## 練習設定

| グループ | 設定 | 説明 |
| --- | --- | --- |
| 表示 | 音符の判定をリアルタイム表示 | デフォルトはオン |
| 表示 | ウォーターフォールを隠す | デフォルトはオフ。オンにすると背景画像でウォーターフォールを隠し、耳と楽譜だけで練習します |
| 音量とテンポ | 楽譜の音量 | 0–100、デフォルトは 100 |
| 音量とテンポ | 仮想ピアノの音量 | 0–100、デフォルトは 100。あなたが押した鍵盤の音で、楽譜の音量とは別に調整します。楽譜の音量が 0 のときは鍵盤も消音されます |
| 音量とテンポ | メトロノームの音量 | 0–100、デフォルトは 80。予備拍もこの音量で鳴ります |
| 音量とテンポ | BPM | 40–240、デフォルトは楽譜のテンポ |
| 音量とテンポ | 再生中にメトロノームを鳴らす | デフォルトはオフ。オンにすると練習中ずっとメトロノームが鳴ります |
| 声部の選択 | 譜表 1、2…… | デフォルトはすべてオン。いずれかの行をオフにすると、その行は薄く表示され、**判定も再生もされません** |
| 難易度 | 初心者 / 経験者 / マスター | デフォルトは初心者。判定範囲は上の表を参照してください |

練習モードには「左手 / 右手」の選択肢はありません。ピアノ譜では通常 1 行目が右手、2 行目が左手なので、「声部の選択」で片手だけを練習できます。

設定はソフトを閉じるまで保持され、ソフトを再び開くとデフォルトに戻ります。
