初心者モードには**テンポの制限がありません**。同時に押す必要のある鍵盤をすべて押さえると、次のステップに進みます。曲を覚え始めたばかりで、まだテンポについていけないときに向いています。

## 画面構成

[練習モード](#play-practice) と同様に、上に楽譜、下に画面上のピアノがあります。違いは、ウォーターフォールの代わりに**カラフルなブロック**が積み重なって表示される点です。ブロックの各段が、次に押す鍵盤を表します。

## 弾き方

1. 「練習開始」をクリックします。まず予備拍として 1 小節分のメトロノームが鳴ります。
2. いちばん下の段のブロックを見て、対応する鍵盤を押します。同時に始まる音（和音など）は 1 つの段になっており、**同時に押さえる**必要があります。
3. すべて正しく押すとブロックが落ち、次のステップに進みます。楽譜上では今弾くべき音符が赤、弾き終えた音符が緑で表示され、楽譜も現在位置まで自動でスクロールします。
4. 最後のステップを弾き終えると自動で終了し、色がクリアされます。

- 時間制限はなく、早い・遅いの判定もありません。間違えても減点はなく、先に進まないだけです。
- 初心者モードにはスコアも一時停止ボタンもなく、結果は保存されません。

## 入力方法とサウンド

| 入力方法 | 進行できるか | 音が出るか |
| --- | --- | --- |
| MIDI キーボード | できる | 出る（ツールバーで選んだ音色を使用） |
| 画面上のピアノをマウスでクリック | できる | 出る |
| パソコンのキーボード | できる | 出る（MIDI キーボードと同じ） |

パソコンのキーボードの配置と使い方は、[練習モード](#play-practice) の「パソコンのキーボードで演奏」を参照してください。初心者モードでは**楽譜は再生されません**。聞こえるのは自分が弾いた音だけです。

## ツールバー

| ボタン | 説明 |
| --- | --- |
| 戻る | 再生モードに戻ります |
| 設定 | 「初心者モード設定」を開きます。停止中のみ開けます |
| 練習開始 / 停止 | 開始または終了します |
| 音量 | 0〜100%、既定は 100%。自分が弾く音の音量です |
| 音色 | 自分が弾くときの音色です。停止中のみ変更できます |
| 楽譜の種類 / 移調 / 半音上げる / 半音下げる | [再生モード](#play-features) と同じですが、変更は一時的なものです |
| ショートカット | パソコンのキーボードのキー配置図を表示します。[練習モード](#play-practice) を参照してください |
| 楽譜を隠す / 楽譜を表示 | 隠すとカラフルなブロックだけを見て弾けます |

楽譜に弾ける音符がない場合は、「この楽譜には練習できる音符がありません」と表示されます。

## 初心者モード設定

| グループ | 設定 | 説明 |
| --- | --- | --- |
| 表示 | MIDI ブロックを隠す | 既定はオフ。オンにするとカラフルなブロックが隠れ、楽譜を見るか耳だけを頼りに弾きます |
| サウンド | 仮想ピアノの音量 | 0〜100、既定は 100。自分が弾く音の音量です。ツールバーの「音量」と同じ設定で、どちらで変えても同じです |
| メトロノーム | メトロノームの音量 | 0〜100、既定は 80 |
| メトロノーム | BPM | 40〜240、既定は楽譜のテンポ。予備拍とメトロノームにだけ影響し、演奏には影響しません |
| メトロノーム | 練習中にメトロノームを鳴らす | 既定はオフ |
| 声部の選択 | 譜表 1、2…… | 既定ではすべてオン。ある段をオフにすると、その段は透明になり、弾く必要もなくなります |

「声部の選択」を使うと、右手だけ・左手だけを練習できます。
