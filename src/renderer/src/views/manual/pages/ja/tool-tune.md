チューナーは、弾いた開放弦の音をマイクで聴き取り、音程が高いか低いかを教えてくれます。

## 対応楽器

| 楽器 | 各弦の音高 |
| --- | --- |
| ギター：レギュラー（デフォルト） | 6 弦から 1 弦：E2 A2 D3 G3 B3 E4 |
| 4弦ベース | E1 A1 D2 G2 |
| ウクレレ | G4 C4 E4 A4 |

基準音は A4 = 440 Hz に固定されています。

## 使い方

1. ページを開くと自動的に検出が始まります（初回はマイクの使用を許可する必要があります）。上部のボタンで「停止」したり、もう一度「検出開始」したりできます。
2. ヘッドの横にある丸い音名ボタンをクリックして、**チューニングする弦を選びます**（デフォルトは 1 弦）。どの弦を弾いたかは自動では判別しません。
3. その開放弦を弾き、音が自然に消えるまで待ちます。弦が鳴っている間は「計算中…」と表示され、音が止まると針が結果の位置に移動します。
4. 表示に従ってペグを回し、もう一度弾いて確認します：

| 表示 | 意味 |
| --- | --- |
| ぴったり！（緑） | 誤差が ±8 セント以内で、この弦は合っています |
| 上げて！ | 音が低いので、弦を少し締めます |
| 下げて！ | 音が高いので、弦を少し緩めます |
| 聴き取り中… | 弦が弾かれるのを待っています |

メーターの左側が「低め」、右側が「高め」で、範囲は ±50 セント（100 セントで半音）です。

> 判定では音名だけを見て、オクターブは見ません。弦の音高がちょうど 1 オクターブずれていても「ぴったり！」と表示されるので、先におおよその音高を確認してから微調整してください。
