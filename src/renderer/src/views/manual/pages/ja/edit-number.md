数字譜は、数字の 1〜7 でドからシを表し、数字の上下の点（オクターブ点）で高いオクターブ・低いオクターブを表す記譜法で、最も手軽に始められます。数字譜の音高は**数字とオクターブ点**で決まるため、マウスに加えてパソコンのキーボードで入力するとより速く入力できます。

## 追加ツールバー

| 項目 | 選択肢 | 既定 |
| --- | --- | --- |
| 追加 | 音符 / 休符 | 音符 |
| 音価 | 全音符〜128分音符 | 4分音符 |
| オクターブ点 | -3、-2、-1、0、1、2、3（休符を選んでいるときは非表示） | 0 |

オクターブ点は、新しく追加する音符に付く点の数を表します。正の数は高いオクターブ（点は上）、負の数は低いオクターブ（点は下）、0 は点なしです。

## ショートカット

数字譜の数字キーはほかの楽譜と異なり、**メインキーボードの数字と 3 列の文字キーで音符を直接入力**し、テンキーの数字で音価を切り替えます。

| キー | 機能 |
| --- | --- |
| メインキーボード `1`〜`7` | 選択中の小節の末尾に中音の ド、レ、ミ、ファ、ソ、ラ、シ を追加します。音価はツールバーの設定を使います |
| `Q` `W` `E` `R` `T` `Y` `U` | 高音の 1〜7 を順に追加します（上に点 1 つ） |
| `A` `S` `D` `F` `G` `H` `J` | 中音の 1〜7 を順に追加します |
| `Z` `X` `C` `V` `B` `N` `M` | 低音の 1〜7 を順に追加します（下に点 1 つ） |
| メインキーボード `0` / `~` / `I` / `K` | 選択中の小節の末尾に休符を 1 つ追加します |
| メインキーボード `8` / `9` | ツールバーのオクターブ点を 1 つ下げる / 上げる（-3 〜 +3）。マウスでの追加に反映されます |
| テンキー `1`〜`8` | 音価を切り替えます：1 全音符 …… 8 128分音符 |
| テンキー `0` | 「音符」と「休符」を切り替えます |
| MIDI キーボード | 小節を選択して鍵盤を押すと、対応する音符を小節の末尾に追加します。楽譜の調に合わせて階名とオクターブ点に換算されます |

共通のショートカットは [編集モード](#score-edit) を参照してください。

> キーは物理的な位置で判定するため、IME が中国語入力の状態でも文字キーは有効です。

### キーボード入力の例

「5 5 6 5 | 1̇ 7」（2 小節目の 1 は高音）を入力する場合：

1. 1 小節目を選択し、`5` `5` `6` `5` の順に押します。
2. `→` を押して右隣の小節に移動します（またはプロパティパネル / 右クリックメニューで小節を挿入して選択します）。右上の「標準モード」をオンにすると、1 小節分を入力し終えた時点で自動的に次の小節へ移るため、この手順は省略できます。
3. `Q` を押して高音の 1 を追加し、続けて `7`（または `J`）を押して中音の 7 を追加します。

## 数字譜だけの機能

- **クイック入力**：1 行のテキストで数字譜の一節をすばやく書けます。[数字譜のクイック入力](#edit-quick-number) を参照してください。
- **範囲選択**：まとめて音高を上げ下げしたり、音価を変更したりできます。[音符の範囲選択](#edit-box-select) を参照してください。
- **五線譜に変換**：右上の「楽譜の種類」で行います。[上部の機能](#edit-top) を参照してください。
- 数字譜の小節には音部記号と調号がなく、設定できるのは拍子記号だけです。調はタイトル領域の「1 =」で設定します。[楽譜の構成](#edit-structure) を参照してください。
