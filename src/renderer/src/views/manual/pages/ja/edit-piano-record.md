「ピアノ入力」を使うと、MIDI キーボードでの演奏をリアルタイムでピアノ譜として録音できます。右手は高音部譜表に、左手は低音部譜表に書き込まれます。**五線譜**でのみ使用でき、編集モード右上の「ピアノ入力」ボタンから開きます。

> MIDI キーボードの接続が必要です。接続されていない場合は「ピアノ入力には MIDI キーボードが必要です。接続してからもう一度お試しください」と表示されます。

## 録音前の設定

「ピアノ入力」を押すと、下部に「ピアノ入力」パネルが表示されます。

| 設定 | 説明 |
| --- | --- |
| テンポ | 30–240。デフォルトは楽譜のテンポです（楽譜にテンポがない場合は 90）。最初は遅めのテンポがおすすめです。安定して弾くほど正確に録音できます |
| 拍子 | 録音に使う拍子記号です。拍子を変更すると、録音済みの結果は消去されます |
| 録音中にメトロノームを鳴らす | デフォルトでオンです。メトロノームに合わせて弾くと、録音されるリズムがより正確になります |
| メトロノーム音量 | 0–100、デフォルトは 80 |
| MIDI デバイス | 現在接続されているデバイス名を表示します。デバイスがない場合は「未接続」と表示されます |

「録音設定」には、さらに 3 つの詳細オプションがあります。設定はこのコンピューターに保存され、「デフォルトに戻す」で元に戻せます。

| オプション | デフォルト値 | 説明 |
| --- | --- | --- |
| 拍スナップ（拍） | 0.2 | 打鍵が拍からこの範囲内であれば、そのまま拍の位置とみなし、わずかな早い・遅いのずれを解消します。0.25 以下であれば、本当の裏拍の 16 分音符が吸い寄せられることはありません。0 にするとオフになります |
| 最短の休符 | 8 分音符 | 同じ手の 2 つの音の隙間がこれより短い場合は、休符を書かずに前の音に結合します。その代わり、短い休符を書きたいときはこの長さ以上止める必要があります。結合しない / 16 分音符 / 8 分音符 / 4 分音符 から選べます |
| 遅延補正（ミリ秒） | 0 | すべての打鍵時刻からこの値を先に引きます。録音結果が全体的に一定して遅れる場合（メトロノームに出力遅延がある場合など）に使います。大きくしすぎないでください |

## 録音の手順

1. 「録音開始」を押します。まず 1 小節分の**予備拍**が鳴るので、それを聞き終えてから弾き始めます。予備拍の間は「キャンセル」を押せます。
2. 予備拍が終わると計時が始まります。拍に合わせて MIDI キーボードを弾くと、録音された内容が譜面上にリアルタイムでスクロール表示されます。
3. 弾き終えたら「録音終了」を押します。パネルに録音された音符グループの数が表示されます。気に入らない場合は「もう一度録音」を押してください。
4. 「楽譜に反映」を押して確認すると、録音結果で**現在の楽譜の内容がすべて上書き**されます。

## 録音のルール

- テンポに応じて 16 分音符単位でクオンタイズされます。
- **左右の手の自動振り分け**：単純に中央ハで分けるのではなく、音の位置と手の動きから判断します。そのため、中央ハをまたいで続くメロディーでも譜表が飛び飛びになることはありません。同時に押した音の幅が 1 オクターブを超える場合は、中間でいちばん広い音程のところで両手に分けます。
- ほぼ同時（約 60 ミリ秒以内）に押した音は 1 つの和音として扱われます。
- 小節をまたぐ音は分割してタイでつなぎます。1 段に 4 小節ずつ並べます。
- 現在の楽譜の調号、タイトル、ページの幅は保持されます。

## その他の入力方法

ピアノ入力のほかに、五線譜はマウス、キーボード、MIDI キーボードで音符を 1 つずつ入力することもできます。[五線譜の編集](#edit-staff) と [音符](#edit-staff-note) を参照してください。
