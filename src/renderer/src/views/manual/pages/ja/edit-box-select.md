範囲選択を使うと、複数の音符を一度に選択して、まとめて音高の上げ下げ、音価の変更、削除ができます。範囲選択はすべての種類の楽譜で使えます。できる一括操作は楽譜の種類によって異なります（下の表を参照）。

## 範囲選択の方法

- 楽譜の空白部分または小節内で、マウスの左ボタンを押したままドラッグすると紫の選択枠が表示され、ボタンを離すと枠内の音符が選択されます。
- 選択できるのは、五線譜とドラムセット譜の符頭、数字譜の数字、TAB譜のフレット番号（アルペジオ・ストロークを含む）、休符です。選択されたものは紫でハイライトされます。
- 楽譜の外にある編集エリアの空白部分からもドラッグを始められます。入力欄、ボタン、ドロップダウンの上で押した場合は範囲選択になりません。
- ドラッグ距離がごく短い場合は通常のクリックとみなされ、範囲選択されません。
- 範囲選択すると、それまでの単一選択は解除されます。マウスを離した瞬間に小節が選択されたり、音符が追加されたりすることはありません。

## 一括操作

範囲選択すると、右側のプロパティパネルに「N 個の音符を選択中」と表示され（休符を含む場合は休符の数も表示されます）、次の操作ができます。

| グループ | 操作 | 説明 |
| --- | --- | --- |
| 音高 | 下げる / 上げる | 1〜48 の半音数を入力して「OK」を押します。休符は音高の上げ下げの対象外です |
| 音価 | 音価 ×2 / 音価 ÷2 | 選択したすべての音符の音価を 2 倍または半分にします。範囲は全音符から 128 分音符までで、限界に達するとメッセージが表示されます |
| 音価 | 付点 | 選択した音符にまとめて付点を設定します |
| 符幹 | 符幹の向き | 選択した音符に符幹のあるもの（五線譜）が含まれる場合のみ表示されます |
| 操作 | 選択項目を削除 | 選択したすべての音符と休符を削除します。`Delete` または `Backspace` でも削除できます |

- **ドラムセット譜**：「音高」と「符幹」のグループはありません。音価は 4 分音符までです。
- **TAB譜**：「音高」と「符幹」のグループはありません。音価や付点を変えると、同じタイミングの音はすべて一緒に変わります。

## 範囲選択の解除

- `Esc` を 1 回押すと範囲選択が解除され、もう 1 回押すと単一選択が解除されます。
- 元に戻す操作をしたときも範囲選択は解除されます。

> 範囲選択した内容はコピー・貼り付けできません。コピー・貼り付けは [右クリックメニュー](#edit-context-menu) を使い、小節・単譜表・大譜表の単位で行ってください。
