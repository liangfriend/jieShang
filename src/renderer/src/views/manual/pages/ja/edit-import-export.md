編集モード右上の「読み込む」「書き出す」は、ほかのソフトと楽譜をやり取りするための機能で、バックアップにも使えます。

## インポート

> インポートすると**現在の楽譜の内容がすべて上書き**されます。インポート後は内容を確認してから「保存」を押してください。

| 項目 | ファイル形式 | 説明 |
| --- | --- | --- |
| 解熵楽譜 (.sj) | `.sj` | 解熵独自の楽譜形式で、そのまま復元されます |
| MusicXML | `.xml`、`.musicxml` | 汎用の楽譜交換形式です。圧縮形式の `.mxl` には対応していません |
| MIDI | `.mid`、`.midi` | インポート後は**必ず五線譜**になります |
| 画像から楽譜(数字譜) | PNG、JPG、WebP、BMP 画像 | 画像の中の数字譜を認識します |

インポートに成功すると「（ファイル名） を読み込みました」と表示されます。

### MIDI インポートのルール

- 16 分音符単位でクオンタイズされ、細かすぎるリズムは 16 分音符に揃えられます。
- 各トラックのチャンネルごとに 1 つの単譜表が作られます。音域がとても広いピアノのトラックは、中央ハで自動的に上下 2 段に分けられます。
- 10 チャンネル（打楽器）は無視されます。
- 対応していない拍子記号は 4/4 に変更されます。テンポが複数ある場合は最初のものだけが残ります。
- 1 段に 4 小節ずつ並べ、小節をまたぐ音はタイでつなぎます。譜表が複数ある場合は自動的に波括弧が付きます。
- 保持できなかった内容がある場合は「MIDI の一部の内容を保持できませんでした」と表示され、理由が一覧表示されます。

### 画像から楽譜（数字譜）

1. 「画像から楽譜(数字譜)」を選ぶと、変換ウィンドウが開きます。**認識できるのは数字譜だけです。**
2. クリックまたはドラッグで画像を追加します。一度に複数枚追加できます（たとえば 1 曲の複数ページ）。上へ・下へ移動、ファイル名順に並べ替え、削除ができ、サムネイルをクリックすると拡大表示できます。
3. 「生成する」を押すと、1 枚ずつ認識して進行状況を表示します。各画像には、認識された段数、小節数、調号、拍子記号、注意が表示されます。認識中に停止することもできます。
4. 認識に失敗した画像は赤く表示されます。画像を差し替えて再試行するか、失敗した画像をスキップして残りの画像で生成できます。
5. 複数の画像はリストの順に 1 つの楽譜につなげられます。曲全体の調号と拍子記号は最初に認識されたものを使います。あるページで調号や拍子記号が変わっている場合は、そのページの最初の小節に書き込まれます。
6. 生成結果は現在の楽譜を上書きします。`Ctrl+Z` で元に戻せます。

> 認識結果には誤りが含まれることがあります。生成後は元の画像と照らし合わせて確認してから保存してください。

## エクスポート

| 項目 | 説明 |
| --- | --- |
| 解熵楽譜 (.sj) | 楽譜を完全に保存します。解熵でそのままインポートでき、バックアップや共有に向いています |
| MusicXML(ms4) | MusicXML 4.0。比較的新しい浄書ソフト向けです |
| MusicXML(ms3) | MusicXML 3.1。MuseScore 3 などの古いソフトと互換性があります |
| MIDI | 単譜表ごとに 1 つのトラックとして書き出します |
| 作品 | 楽譜を新しい作品に配置し、ページサイズに合わせて自動で分割します。下記を参照 |

数字譜を MusicXML に書き出す場合は、まず自動的にハ調で表記した五線譜に変換してから書き出します。

### 作品として書き出す

1. 「書き出す」→「作品」を選ぶと、設定ウィンドウが開きます。
2. ページテンプレート（A4、A5、B5、Letter、16:9 など。用紙は縦向きと横向きがあります）を選ぶか、ページの幅と高さを直接入力します。
3. **楽譜の幅**を設定します。楽譜はこの幅に合わせて拡大縮小されます。
4. **楽譜の上余白**を設定します。ページ上端からどれだけ下げて楽譜を置くかです。
5. 「確定」を押すと、新しい作品が作成され作品編集が開きます。
   - 各ページで楽譜は左右中央に、上余白の位置から配置されます。
   - ページに収まらない大譜表は行ごと次のページへ移り、ページ下にも同じ余白が残ります。
   - タイトルは 1 ページ目に入ります。

作品は保存するまで「マイ作品」に表示されません。確認してから保存してください。前回の設定は記憶されます。
