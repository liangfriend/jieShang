音符や休符のほかに、楽譜にはさまざまな記号を付けられます。記号は、**1 つの音符**に付く記号、**複数の音符**にまたがる記号、**小節**に付く反復記号の 3 種類に分かれます。

## 単一音符の記号

音符（または休符）を選択し、右側のプロパティパネルで「記号」タブに切り替えます（タブの数字は付いている記号の数を表します）。アイコンをクリックすると追加され、もう一度クリックすると取り消されます。

| グループ | 記号 | 説明 |
| --- | --- | --- |
| アーティキュレーション | アクセント、スタッカート、スタッカーティッシモ、テヌート、ルーレ、マルカート、アクセント + スタッカート、マルカート + スタッカート、マルカート + テヌート、スタッカーティッシモ（縦線）、スタッカーティッシモ（楔形）、ストレス、テヌート + アクセント、アンストレス | 複数同時に付けられます |
| 奏法 / ボウイング | 開放、ミュート、ハーモニクス、アップボウ、ダウンボウ、ブレス | 複数同時に付けられます |
| 装飾記号 | ターン、逆ターン、トリル、プラルトリラー、モルデント | グループ内で 1 つのみ選べます |
| 強弱記号 | ppp、pp、p、mp、mf、f、ff、fff、fp、pf、sf、sfz、sffz、sfp、rfz、rf、fz | グループ内で 1 つのみ選べます |
| 古箏の指法（数字譜のみ） | 托、劈、抹、挑、勾、剔、打、摘、提、撥、小撮、大撮 | グループ内で 1 つのみ選べます |
| 古箏の奏法（数字譜のみ） | 掃、揺指 | 指法と同時に追加できます |

アイコンの見た目は、使用中の楽譜スキンによって変わります。

### 記号の調整と削除

譜面上の記号をクリックすると選択され、記号の周りに点線の枠、右側に緑の移動ボタンが表示されます。ボタンをドラッグすると位置を微調整できます。プロパティパネルには「記号のプロパティ」が表示されます。

- **X / Y**：位置のオフセットを数値で入力します。
- **位置をリセット**：既定の位置に戻します。
- **削除**：この記号を削除します。`Delete` を押しても削除できます。
- **置き換え**：同じグループの別の記号に置き換えます。位置のオフセットは保持されます。

> 譜面上でクリックしにくい記号は、音符の「記号」タブでアイコンをもう一度クリックして取り消せます。

## 複数音符にまたがる記号

音符を選択し、プロパティパネルで「ライン」タブに切り替えます。

### 列の記号

- 「アルペジオを追加」「前奏括弧（を追加」「前奏括弧）を追加」。
- アルペジオは現在の音符がある列だけに付き、1 列に 1 つまでです。すでに追加した記号のボタンは表示されなくなります。

### 複数音符にまたがる記号を追加

1. まず「範囲」を選びます。現在の音符から右へ 1 / 2 / 3 / 4 個の音符を覆います。
2. 次に追加する記号をクリックします：スラー、ペダル、8va（1 オクターブ上）、8vb（1 オクターブ下）、トリル線、クレッシェンド、ディミヌエンド。数字譜では古箏の連続指法（連托、連劈、連抹、連挑、連勾、連剔、連打、連摘）も追加できます。
3. スラーは 2 個以上の音符にまたがる必要があります。終点の列に複数の音（和音）がある場合は、どの音につなぐかを選べます。

後続の音符は現在の小節と次の小節の中だけで探します。音符が足りない場合はメッセージが表示されます。

### この音符から開始

「ライン」タブの下部には、この音符から始まる複数音符にまたがる記号が一覧表示され、そのまま削除できます。スラーは線の太さ（2〜12）も調整できます。何もない場合は「なし」と表示されます。

## 複数音符にまたがる記号を選択したとき

譜面上でこれらの記号をクリックすると選択できます（記号そのものを正確にクリックする必要があります）。右側に対応するプロパティが表示されます。

| 記号 | 調整できる内容 |
| --- | --- |
| スラー | 線の太さ、適用範囲（左へ拡張、右へ拡張、左を縮小、右を縮小、位置揃えをリセット）、和音のときの始点・終点の音、始点 / 終点の位置、制御点を中央に（数字譜にはありません）。譜面上でハンドルをドラッグして形を調整できます。「現在の位置を適用」で、現在の形を小節 / 単譜表 / 大譜表 / 楽譜全体のほかのスラーにまとめて適用できます |
| オッターヴァ記号 | 1 オクターブ上 / 1 オクターブ下 |
| トリル線 | 開始記号：tr / 上行トリル / 下行トリル / 長いトリル。両端と中央のハンドルをドラッグできます |
| クレッシェンド / ディミヌエンド | スタイル（松葉、または cresc. / dim. の文字線）。松葉は開き幅を調整できます。両端と中央のハンドルをドラッグできます |
| 古箏の連続指法 | 指法（連托 / 連劈 / 連抹 …）、適用範囲、両端の位置。両端と中央のハンドルをドラッグできます |
| ペダル | 専用のプロパティはありません |
| アルペジオ | スタイル（波線 / 直線）、矢印、位置をリセット |
| 括弧 | 括弧の種類。すべての段に適用できます |

選択して `Delete` を押すと削除できます。

## 反復括弧（Volta）

反復括弧は [小節](#edit-measure) のプロパティパネルの「反復」グループで追加します。譜面上の反復括弧をクリックすると選択され、プロパティパネルに「Volta のプロパティ」が表示されます。

- **テキスト**：反復括弧に表示する文字です（例：「1.」）。
- **反復回**：何回目の演奏時にこの反復括弧を通過するかを表します（1 から）。「追加」で複数設定でき、少なくとも 1 つは残す必要があります。
- **適用範囲**：左へ拡張、右へ拡張、左を縮小、右を縮小、位置揃えをリセット。
- **端の形状**：左端を閉じる、右端を閉じる。
- 譜面上でドラッグして調整できます。選択中は、覆っている小節が緑の枠で表示されます。`Delete` を押すと削除します。

## 小節の反復記号

Segno、Coda、Fine、D.C.、D.S.、To Coda などの反復記号は、[小節](#edit-measure) のプロパティパネルの「反復」グループで設定します。

## カスタム記号

内蔵の記号で足りないときは、自分の SVG を記号としてアップロードできます。**音符記号**（音符・休符に付ける）と **小節記号**（小節に付ける）があり、専用の一覧ページはなく、すべて楽譜編集の中で管理します。

- **作成**：音符または小節を選択し、プロパティパネルの「カスタム記号」グループで `+` をクリックします。SVG をアップロードし、名前・サイズ・位置を設定して保存します。記号はアプリの記号ライブラリに保存され、どの楽譜でも使えます。
- **楽譜に追加**：グループ内の記号アイコンをクリックすると現在の音符・小節に追加され、もう一度クリックすると削除されます。
- **位置**：音符記号は符頭の中心が基準で、縦オフセットが負なら上、正なら下に付きます。数字譜では数字のどの辺を基準にするかも選べます。小節記号は小節の上・下、左端・中央・右端から選べます。**オフセット 1 = 小節の高さ**（約 45 px）。
- **管理**：グループ右上の「管理」から、ライブラリの記号を編集・削除できます。「設定を書き出し / 読み込み」で記号ライブラリを JSON でバックアップ・復元できます。

> 楽譜に追加するとき記号のコピーが楽譜内に保存されるため、ライブラリから削除したり別の楽譜を開いて編集したりしても、すでに追加した楽譜には影響しません。記号を編集すると、現在開いている楽譜の同じ記号は更新されます。

## 装飾音

装飾音は音符のプロパティパネルの「基本」タブで追加します。各楽譜の種類の「音符」ページ、たとえば五線譜の [音符](#edit-staff-note) を参照してください。
