このページでは、TAB譜での音符の追加・変更・削除について説明します。

## マウスで追加する

1. 小節をクリックして選択します。
2. 左上のツールバーで、種類・音価・フレットを選びます。
3. マウスを小節の中に動かすと、半透明の**プレビュー**が表示されます。上下に動かして弦を選びます。
4. クリックすると追加されます。

追加される位置は、クリックした場所によって変わります。

- **2 つの音符の間**：新しい音符を挿入します。
- **既存の音符の上**で、別の弦の場合：同じタイミングに音を重ねて和音にします。
- 既存の音符の上で、同じ弦の場合：その音を選択します。
- アルペジオ、ストローク、休符は音符の間にのみ挿入できます。

## 弦を変更する：ドラッグ

フレット番号を選択したあと、**上下にドラッグ**するとほかの弦に移動できます。

## 音符のプロパティパネル

フレット番号（またはアルペジオ、ストローク）を選択すると、右側に「音符のプロパティ」が表示されます。五線譜と同じく「基本」「記号」「ライン」の 3 つのタブに分かれています。

### 基本

| 項目 | 説明 |
| --- | --- |
| コードダイアグラム | 「コード管理」からコードダイアグラムを選ぶと、音符の上に表示されます。「なし」を選ぶと外れます。現在の弦の数に合うコードだけが表示されます。4 弦の譜には 4 弦のコード、5 弦の譜には 5 弦のコード、6 弦の譜には 6 弦のコードが表示されます |
| フレット | x、0–27。通常音とハーモニクスのみの項目です |
| 開始弦 / 終了弦 | アルペジオとストロークのみの項目です |
| 音価 | 全音符から128分音符まで。同じタイミングの音はすべて一緒に変わります |
| 付点 | なし / 1 / 2 / 3 個の付点。同じタイミングの音はすべて一緒に変わります |
| 連桁 | 両側連結 / 右側のみ連結 / なし |
| スラップ | チェックを入れるとスラップとしてマークされます |
| チョーキング | 通常音とハーモニクスのみの項目です。下記を参照してください |
| 装飾音 | 前打音 / 後打音を追加します（通常音とハーモニクスのみ） |
| 横方向のオフセット | -40 から 40 のスライダーで音の左右位置を微調整します。「位置をリセット」で 0 に戻ります |

### 記号

選択した音に、アクセント、スタッカート、トリル、強弱記号などの単一音符の記号を追加します。[その他の記号](#edit-symbols) を参照してください。

### ライン

アルペジオ、ストローク、前奏括弧、スラー、ペダル、8va / 8vb、トリル線、クレッシェンド・ディミヌエンドなど、複数音符にまたがる記号を追加します。[その他の記号](#edit-symbols) を参照してください。

コードダイアグラムは、[コード管理](#chords) に保存されたコードから選びます。自分のコードダイアグラムもそこで作成できます。コードダイアグラムは楽譜に配置したときにコピーされるため、あとでコード管理で変更しても、すでに楽譜に配置したコードダイアグラムには影響しません。

### チョーキング

「チョーキングを追加」をクリックすると、次の項目を設定できます。

- **種類**：チョーキング、チョーキング＆リリース、プリベンド、プリベンド＆リリース、プリベンド＆チョーキング。
- **段階 1**、**段階 2**：2 つの段階それぞれのチョーキング幅です。0–3 の範囲で、0.5 刻みで選べます。
- 「チョーキングを削除」をクリックすると削除されます。

譜面上でチョーキングの曲線をクリックしても選択でき、プロパティパネルには同じ設定に加えて次の項目が表示されます。

- **位置オフセット**：X / Y の入力欄で、チョーキングの曲線全体の位置を微調整します。
- **位置をリセット**：既定の位置に戻します。
- **削除**：このチョーキングを削除します。

## スラーの種類

譜面上でスラーをクリックすると、種類を設定できます。

| 種類 | 意味 |
| --- | --- |
| なし | 通常のスラー |
| ハンマリング H | 左手の指で弦を直接叩いて次の音を鳴らします |
| スライド S | 弦を押さえたまま次のフレットまで滑らせます |
| プリング P | 左手の指で弦を引っかけて次の音を鳴らします |
| ハンマリング＆プリング HP | ハンマリングとプリングの組み合わせ |

そのほかの設定は五線譜のスラーと同じです：線の太さ、適用範囲（「位置揃えをリセット」を含む）、和音のときの始点・終点の音、両端の位置、制御点を中央に、「現在の位置を適用」で小節 / 単譜表 / 大譜表 / 楽譜全体のほかのスラーへ適用。

## 削除

- 選択して `Delete` または `Backspace` を押します。
- 同じタイミングに複数の音がある場合は、選択したものだけが削除されます。
