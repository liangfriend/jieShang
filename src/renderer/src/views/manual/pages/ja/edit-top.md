編集モードの右上には 2 つのボタングループがあり、下部にはツールバーがあります。ファイルの読み書き中は、これらのボタンは一時的に無効になります。

## 1 つ目のボタングループ

### レイアウト調整

「レイアウト調整」ダイアログを開きます。ダイアログは 2 つの部分に分かれています。

- **現在の楽譜レイアウト**：現在の楽譜のページ（全体の幅、左余白、音色名フォント、右余白、全体の高さ）、タイトル領域（高さ、フォント）、歌詞（フォント、文字サイズ。歌詞は単譜表の下外側余白の中に描かれ、独自の高さは持ちません）、大譜表の余白（上 / 下）、単譜表の余白（上外側 / 上内側 / 下内側 / 下外側）を調整でき、横にプレビューが表示されます。変更はすぐに現在の楽譜へ書き込まれます。「デフォルトに同期」を押すと、現在のレイアウトをソフトのデフォルトレイアウトにできます。
- **デフォルトレイアウト**：ソフトのデフォルトレイアウトです。変更は自動保存され、今後新規作成する楽譜や追加する譜表に反映されます。「適用」を押すと現在の楽譜に適用できます。全体の幅と全体の高さはデフォルトレイアウトに含まれません。

各領域の意味は [楽譜の構成](#edit-structure) を参照してください。

### 構造ボタン

オン / オフの切り替えです。オンにすると、楽譜上に構造を追加・削除するためのボタンが表示されます。

| 位置 | ボタン | 機能 |
| --- | --- | --- |
| 大譜表の下の左側 | 赤い「− 大譜表」 | この大譜表を削除します。残り 1 つのときは使えません |
| 大譜表の下の左側 | ピンクの「+ 大譜表」 | 後ろに大譜表を挿入します。現在の大譜表の単譜表の数、音部記号、調号、拍子記号、小節線、括弧、音色を引き継ぎます |
| 単譜表の右下 | 赤い「−」 | この単譜表を削除します。大譜表内に 1 つしか残っていないときは使えません |
| 単譜表の右下 | 青い「↓」 | 下に単譜表を追加します |
| 単譜表の右下 | 緑の「→」 | この大譜表の各単譜表の末尾に小節を 1 つずつ追加します |

小節を選択している間は、単譜表の下のボタンは一時的に使えません。切り替えをオフにするとボタンは非表示になりますが、ボタンが占めていたスペースは残ります。

### 歌詞

「構造ボタン」の右にあるオン / オフの切り替えです。オフにすると楽譜上の歌詞が非表示になり、譜面に集中できます。歌詞の内容は削除されません。「構造ボタン」とは独立して動作します。

### 連結譜表モード

オン / オフの切り替えで、すべての大譜表に適用されます。オンにすると、同じ大譜表内の各単譜表の小節線がつながり、小節線を変更・削除すると同じ列の小節線も一緒に変わります。

### 音色を表示

オン / オフの切り替えです。オンにすると、各単譜表の左側にその音色名が表示されます。単譜表の音色は [右クリックメニュー](#edit-context-menu) の「音色を設定」で設定します。TAB 譜とドラムセット譜は音色が固定されているため、この切り替えはありません。

### 楽譜の種類

五線譜と数字譜を切り替えます。切り替える前に確認が表示されます：「切り替え後も再生情報はできるだけ維持されますが、譜面のスタイルや一部の記譜の詳細が失われる場合があります。Ctrl+Z で切り替えを元に戻せます。」TAB 譜とドラムセット譜は変換できないため、この項目はありません。

### 移調

「移調先の調」を選んで「移調」を押します。移調では楽譜内の**最初の調号**を現在の調として扱います。楽譜の途中で転調している場合は一部の音符の音高がずれることがあり、確認ダイアログでも注意が表示されます。移調先の調が現在の調と同じ場合は移調できません。

### 半音上げる / 半音下げる

楽譜全体を半音上げる、または下げます。クリックするとすぐに反映され、`Ctrl+Z` で元に戻せます。

## 2 つ目のボタングループ

| ボタン | 説明 |
| --- | --- |
| 標準モード | オン / オフの切り替えです。オンにすると、入力した音符が小節の拍子を超えた場合に次の小節へ移して選択し、現在の小節の残りは休符で埋めます。[編集モード](#score-edit) を参照 |
| クイック入力 | 数字譜のみ。テキストで数字譜をすばやく入力します。[数字譜のクイック入力](#edit-quick-number) を参照 |
| ピアノ入力 | 五線譜のみ。MIDI キーボードで演奏してピアノ譜として録音します。[五線譜の録音入力](#edit-piano-record) を参照 |
| 使用可能な音符一覧 | ドラムセット譜のみ。ドラムセット譜で使えるすべての音符と、対応する文字キーのショートカットを一覧表示します。[ドラムセット譜](#edit-drum) を参照 |
| 注意事項 | 「編集の注意事項」を開きます。選択と削除のルール、楽譜の種類ごとのショートカットなどをまとめています |
| 読み込む / 書き出す | [インポートとエクスポート](#edit-import-export) を参照 |
| 保存 | 楽譜を「マイ楽譜」に保存します |

## 下部ツールバー

| ボタン | 説明 |
| --- | --- |
| 戻る | 前のページに戻ります。前のページがない場合はホームに戻ります |
| 再生モード | 再生モードに切り替えて試聴します。まだ保存していない変更も反映されます |
| 譜面と音声の同期 | 譜面と音声の同期パネルを開きます。[譜面と音声の同期](#edit-sync) を参照 |

編集モード自体には再生ボタンはありません。試聴したいときは再生モードに切り替えてください。
