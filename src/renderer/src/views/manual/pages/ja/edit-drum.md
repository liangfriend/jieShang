ドラムセット譜は五線の上に書きますが、各線・各間が表すのは音高ではなく**1 つのドラムやシンバル**です。また、**符頭の形**（通常、バツ、三角形など）の違いも、異なる楽器や奏法を表します。

ドラムセット譜は上下 2 つの声部に分かれます。一般に、手で叩くドラムやシンバルは**第1声部**（符幹が上向き）に、足で踏むバスドラムやハイハットは**第2声部**（符幹が下向き）に書きます。

## 追加ツールバー

| 項目 | 選択肢 | デフォルト |
| --- | --- | --- |
| 声部 | 第1声部（上向き） / 第2声部（下向き） | 第1声部 |
| 追加 | 音符 / 休符 | 音符 |
| 符頭 | 通常、バツ、丸囲みバツ、丸囲みスラッシュ、三角形、ひし形 | 通常 |
| 音価 | 4分音符から128分音符まで（ドラムセット譜は最長でも4分音符） | 8分音符 |
| 付点 | なし / 付点 / 複付点 | なし |

一方の声部を選ぶと、もう一方の声部の音符はグレー表示になり、編集中の声部に集中できます。符頭を選ぶと、自動的に「音符」に戻ります。

## ショートカット

| キー | 動作 |
| --- | --- |
| `A`–`T`（`P` を除く） | 小節を選択した状態で、対応するドラムの音符を小節の末尾に追加します。声部・音価・付点はツールバーの設定を使います（下の表を参照） |
| `3`–`8` | 音価を切り替えます：3 が4分 …… 8 が128分。`1`、`2` は無効です |
| `0` | 「音符」と「休符」を切り替えます |

IME が中国語入力の状態でも、文字キーは同じように使えます。ドラムセット譜は MIDI キーボードでの入力に対応していません。共通のショートカットは [編集モード](#score-edit) を参照してください。

## ドラムセット譜の制限

- ドラムセット譜の小節には調号がありません。音部記号と拍子記号は設定できます。[小節](#edit-measure) を参照してください。
- ドラムセット譜の音色は打楽器に固定されており、変更できません。
- ドラムセット譜はほかの種類の楽譜に変換できません。
