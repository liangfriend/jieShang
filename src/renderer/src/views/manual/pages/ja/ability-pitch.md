音感テストでは、1 つの音が再生され、それがどの音名かをピアノの鍵盤で答えます。絶対音感を確かめるためのテストです。

## テスト設定

| 設定 | 選択肢 | 初期値 |
| --- | --- | --- |
| 音名の範囲 | 五音（宮・商・角・徴・羽、つまり C D E G A）/ 七音 / 十二音 | 十二音 |
| 音域 | 標準（中央 C を含むオクターブ）/ 全音域（ピアノの 88 鍵すべて） | 標準 |
| 鍵盤の表示 | 鍵盤に表示する文字：音名（C、C#……）/ 階名（do、di、re……）/ 数字（1、#1、2……） | 音名 |
| 出題数 | 1–12 | 6 |
| 制限時間（秒） | 3–20 | 8 |

## テストの流れ

1. 「テスト開始」をクリックすると、ランダムな音が 1 つ再生されます（2 ラウンド続けて同じ音になることはありません）。
2. もう一度聴きたいときは、リングの「クリックで再生」をクリックします。回数に制限はありません。
3. 下の 1 オクターブ分のピアノで、答えだと思う音をクリックします。
4. 正しい鍵盤は緑、間違えて選んだ鍵盤は赤になり、リングに「正解」「不正解」「時間切れ」のいずれかが表示されます。

- 判定するのは音名だけで、オクターブは問いません。例えば低音域の C が鳴った場合でも、中央の C をクリックすれば正解になります。
- カウントダウンが終わるまでに答えなかった場合は「時間切れ」になります。
- 「中止」でいつでも設定画面に戻れます。

## 結果

- 正答率（時間切れは不正解として扱います）。
- 正解・不正解・時間切れそれぞれのラウンド数。
- 平均回答時間（時間切れを除く）。
- 最大連続正解数。
