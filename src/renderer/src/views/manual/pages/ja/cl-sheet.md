コード弾き語り譜は「歌詞 + コード」の弾き語り用の譜面です。各文字の上に押さえるコードを表示するので、ギターやウクレレで弾きながら歌うのに向いています。五線譜や数字譜と違って拍や音価はなく、歌詞とコードの位置だけを記録します。

## 新規作成と開く

- 「マイ楽譜」で「新規楽譜」をクリックし、「コード弾き語り譜」グループの「空白」を選ぶと編集画面に入ります。
- 保存すると「マイ楽譜」の一覧に表示され、カードの左上に「弾き語り」マークが付きます。クリックすると開きます。
- 楽譜の名前は弾き語り譜の**曲名**です。曲名が空の場合は「無題の弾き語り譜」として保存されます。

## 表示と編集

画面右上で「表示」と「編集」を切り替えられます。

- **表示**：譜面だけを表示します。弾き語り中に見るのに向いています。保存済みの譜面を開くと最初は表示になります。
- **編集**：曲名・説明・作者・歌詞・コードを変更できます。右側にスタイルとコード付きテキストのパネルが表示されます。説明（「1=C 4/4」など）は曲名の下の左側、作者は右側に表示されます。

## 歌詞とコードを書く

| 操作 | 説明 |
| --- | --- |
| 行を追加 | 譜面の一番下の「＋ 添加一行」をクリックして歌詞を入力します。Enter で改行します |
| 行全体を編集 | 行をダブルクリック（または文字を選んで Enter）。Enter で分割、行頭の Backspace で前の行と結合、複数行をまとめて貼り付けることもできます |
| コードを設定 | 文字をクリックし、表示されるパネルでコードを選びます。文字の色と下線もここで設定できます |
| 選択の移動 | ← → ↑ ↓ で文字を移動、Delete でコードを削除、Esc で選択解除 |
| コードを移動 | コードを別の文字へドラッグします。Ctrl を押しながらドラッグするとコピーになります |
| 行の操作 | 行にマウスを重ねると、右側に編集・上へ・下へ・挿入・削除のボタンが表示されます |

> 行末に文字がないところへコードを置きたいときは、行末にスペースを入力し、そのスペースにコードを設定します。

## コード付きテキスト

右側の「コード付きテキスト」では、コードを角かっこで囲んで対応する文字の前に書きます。例：

```text
[C]Twinkle, twinkle, [F]little [C]star,
[F]How I [C]wonder [G7]what you [C]are.
```

- 譜面を変更するとテキストも自動で更新されます。「テキストをコピー」で共有できます。
- ネットで見つけたコード付き歌詞を貼り付けて「譜面に取り込む」をクリックすると譜面になります（現在の歌詞とコードはすべて置き換わります）。
- `{#e6553a}` を文字の前に書くと歌詞の色、`[コード]` の前に書くとコードの色、`{u}` は下線です。

## 上部の楽譜

弾き語りではリズムパターンを見たいことがよくあります。編集モードの右側「上部の楽譜」で「マイ楽譜」から作成済みの楽譜を 1 つ選ぶと、弾き語り譜の一番上に追加されます。

- 追加時に楽譜のコピーが弾き語り譜に保存されます。あとで「マイ楽譜」の元の楽譜を変更・削除しても、こちらのコピーには影響しません。変更を反映したいときは、もう一度選び直してください。
- 追加済みのときは、ドロップダウンで別の楽譜に差し替えられます。「削除」で上部の楽譜を外せます。
- 表示エリアは最初は低めです。編集中にエリアの下端をドラッグするか、「エリアの高さ」スライダーで高さを調整できます。収まらない内容はエリア内でスクロールできます。
- 「楽譜の拡大率」で楽譜の表示サイズを変えられます。
- 「コード名だけ表示」をオンにすると、楽譜内のコードダイアグラムがコード名だけになり、運指の枠を描かないので場所を取りません。

## スタイル

「スタイル」パネルで用紙の幅、歌詞サイズ、行間、フォント、歌詞の色、コードの色を調整できます。これらの設定は譜面と一緒に保存されます。「初期値に戻す」で元に戻せます。

「追加する歌詞」「追加するコード」は、これから追加する文字とコードに付ける色です。たとえばサビを別の色にしたいときは、先に色を選んでから書きます。既存の内容は変わりません。クリアすると、新しく追加する内容は上の歌詞の色・コードの色に従います。

## コード付きの歌詞

右側の「コード付きの歌詞」パネルでは、コードが付いている文字をまとめて変更できます。コードのない文字は変わりません。

- **下線を引く**：オンにするとコード付きの文字すべてに下線を引き、オフにするとすべて外します。すべてに下線があるときだけスイッチがオンになります。
- **色を変える**：色を選ぶと、コード付きの文字すべてがその色になります。色をクリアすると既定の歌詞の色に戻ります。色がそろっていないときはカラーピッカーが空になります。

行末にコードを置くためだけに入力したスペースは対象外です。

## 保存

右上の「保存」をクリックするか、Ctrl + S を押します。未保存の変更があると見出しの横に「未保存」と表示され、画面を離れる前に確認が表示されます。

## インポートとエクスポート

弾き語り譜は `.json` ファイルでインポート・エクスポートします（楽譜の `.sj` 形式ではありません）。バックアップや共有に便利です。

- **エクスポート**：右上の「エクスポート」をクリックすると、現在の弾き語り譜を `.json` ファイルに保存します。歌詞、コード、説明、スタイル、上部の楽譜が含まれます。未保存の変更もそのまま書き出されます。
- **インポート**：右上の「インポート」をクリックして `.json` ファイルを選ぶと、その内容で現在の弾き語り譜が置き換わります。インポート後は「未保存」と表示され、「保存」をクリックするまで反映されません。別の弾き語り譜として残したいときは、先に空の弾き語り譜を新規作成してからインポートしてください。
