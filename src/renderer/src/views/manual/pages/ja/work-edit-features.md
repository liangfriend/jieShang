## 上部ツールバー

| ボタン | 説明 |
| --- | --- |
| 元に戻す | 直前の操作を取り消します。ショートカットは `Ctrl+Z` |
| やり直す | 取り消した操作をやり直します。ショートカットは `Ctrl+Y` または `Ctrl+Shift+Z` |
| 設定 | 「作品設定」を開き、作品名、作者、ページサイズを変更します |
| プレゼン | [プレゼンモード](#work-show) に切り替えます |
| 保存 | 作品を保存します |
| インポート / エクスポート / 音量 | プレゼンモードと同じです。[プレゼンモードの機能](#work-show-features) を参照してください |

### 元に戻す・やり直す

- 最大 30 ステップまで保持されます。1 回のドラッグや 1 回の入力が 1 ステップです。
- 元に戻すと、変更があったページに自動で移動します。
- 作品を開いたりインポートしたりすると、操作履歴はクリアされます。
- 入力欄で文字を入力しているときは、ショートカットは入力欄そのものに対して働きます。

### 保存

- **新しい作品**：「作品を保存」が表示されます。「作品名」（必須）と「作者」（任意）を入力し、「保存する」をクリックします。
- **一度保存したことのある作品**：ダイアログは表示されず、そのまま保存されます。名前や作者を変更するには、先に「設定」で変更してください。下の「作品設定」を参照してください。

自動保存はなく、`Ctrl+S` のショートカットもありません。

## ページの管理

左側のサムネイルの下にあるボタン：

| ボタン | 説明 |
| --- | --- |
| ページ追加 | 最後に空白のページを追加します |
| 挿入 | 現在のページの後ろに空白のページを挿入します |
| ページ削除 | 現在のページを削除します（確認なし、元に戻せます）。ページが 1 枚しかない場合は削除できません |
| コピー | 現在のページを複製し、その後ろに置きます |

サムネイルを右クリックすると、「コピー」「貼り付け」「削除」もできます。「貼り付け」はコピーした内容で対象のページを**上書き**します。ページをドラッグして並べ替えることはできません。

## 作品設定

| 項目 | 説明 |
| --- | --- |
| 作品名 / 作者 | 変更後に「適用」をクリックし、さらに上部の「保存」をクリックすると作品ライブラリに書き込まれます。作品名は空にできません |
| デフォルトページ | これから作成するページのサイズです。「保存」でデフォルトに設定し、「全ページに適用」ですべてのページをこのサイズに変更します |
| 現在のページ | 現在のページの幅と高さを変更し、「適用」をクリックします |
| 標準サイズ | プリセットから選びます：A3、A4、A5、B4、B5、Letter の縦と横、および画面 16:9（1280×720）、4:3（1024×768） |

サイズの単位はピクセルで、範囲は 100〜10000 です。既定は 794 × 1123 で、A4 縦に相当します。

## ツールパネル

### 描画

- 「描画を開始」をクリックすると、「ペン」または「消しゴム」でページ上に描画できます。ペンの色は既定で黒、線の太さは 1〜80 です。
- ここで描いた線は**作品に保存されます**。プレゼンモードの一時注釈とは異なります。
- 描画中は要素を選択したりドラッグしたりできません。「描画を終了」をクリックすると元に戻ります。
- 「このページの描画をクリア」で、現在のページの線をすべて消去します。

### ページ背景

- 「背景を設定」：「マイ画像」から画像を 1 枚選び、「背景に設定」をクリックします。背景はページ全体に引き伸ばして表示されます。
- 「背景をクリア」：背景を取り除きます。

### 素材ライブラリ

「素材ライブラリを開く」をクリックし、「画像」「音声」「動画」から 1 つ選んで「ページに追加」をクリックします。素材は先に [マイ画像 / オーディオ / 動画](#media) にアップロードしておく必要があります。

- 画像と動画は元のサイズで追加されます（動画のサイズが読み取れない場合は 480×270）。
- オーディオは 320×64 の小さなプレーヤーです。

### テキストを追加

「テキスト内容」を入力し、「文字サイズ」（8〜200、既定は 16）と「色」を設定して、「ページに追加」をクリックします。

追加後にテキストを選択すると、右上のプロパティパネルで「文字サイズ」と「色」を変更できます。テキストをダブルクリックすると文字を編集できます。`Enter` で改行、`Ctrl+Enter` またはほかの場所をクリックで確定、`Esc` でキャンセルです。

### 楽譜を追加

1. 検索ボックスで「マイ楽譜」の楽譜を探し、クリックして選択します。
2. 「拡大縮小」（0.1〜2、既定は 0.5）と「楽譜スキン」を設定します。
3. 「追加」をクリックします。

楽譜に関連付けられた模範歌唱と伴奏は自動で引き継がれます。作品内の楽譜は**音符を変更できません**。変更したい場合は「マイ楽譜」で編集してから、追加し直してください。

## 要素の配置

- **選択**：要素をクリックします。ページの空白部分をクリックすると選択を解除します。
- **移動**：要素をドラッグします。動画とオーディオは、**縁**の部分をドラッグします（中央は再生ボタン用です）。
- **拡大縮小**：四隅をドラッグします。中心を基準に拡大縮小され、縦横比は保持されません。最小は 24 ピクセルです。
- **回転**：要素の上にある丸いハンドルをドラッグします。
- **削除**：選択して `Delete` または `Backspace` を押すか、右クリックして「削除」を選びます。確認はなく、元に戻せます。

楽譜は常にほかの要素の下に表示されます。グリッドへの吸着、複数選択、重なり順の変更はありません。

### 右クリックメニュー

| メニュー項目 | 対象の要素 | 説明 |
| --- | --- | --- |
| 傾きを戻す | すべて | 回転角度を 0 に戻します |
| 左右中央に配置 | すべて | ページの左右中央に移動します |
| 比率を戻す | 楽譜、画像、動画 | 幅はそのままで、元の縦横比から高さを計算し直します |
| トリミング / トリミング完了 | 楽譜、画像 | トリミングを開始または終了します |
| 削除 | すべて | |

## プロパティパネル

**楽譜、画像、テキスト**を選択すると、右上に「プロパティ」パネルが表示されます。オーディオと動画にはプロパティパネルはありません。

### 位置とサイズ

X、Y、幅、高さ、回転（-360〜360）。「比率を固定」は既定でオンになっており、パネルで幅または高さを変更すると、もう一方も比率に合わせて変わります。

### 文字スタイル

テキストのみ：「文字サイズ」は 8〜200、「色」はカラーピッカーで選べます。下の「情報」と「トリミング」は、楽譜と画像の場合にだけ表示されます。

### 情報

- 画像：名前、元のサイズ。
- 楽譜：模範歌唱、伴奏、楽譜サイズ。

### トリミング

楽譜や画像の一部だけを表示したいときに使います：

- **ドラッグでトリミング**：「ドラッグでトリミング」をクリックすると枠がオレンジ色になります。四隅をドラッグして残す範囲を調整し、外側へドラッグすると切り取った部分を元に戻せます。`Enter` または `Esc` を押すか、「トリミング完了」をクリックすると終了します。
- **大譜表でトリミング**（楽譜のみ）：「始点」「終点」で「タイトル」または「大譜表 n」を選び、「大譜表でトリミング」をクリックすると、その範囲の段だけが残ります。「左上を固定」をオンにすると、開始位置を固定できます。
- **数値でトリミング**：始点 X / Y と終点 X / Y を直接入力します。
- **枠サイズを維持（引き伸ばし）**：オンにすると、トリミングしても要素のサイズは変わらず、内容が引き伸ばされて枠いっぱいに表示されます。
- **トリミング解除**：元の内容全体に戻します。

トリミング中にほかの要素を選択したとき、ページを切り替えたとき、プレゼンモードに切り替えたとき、描画を始めたときは、トリミングが自動で終了します。
