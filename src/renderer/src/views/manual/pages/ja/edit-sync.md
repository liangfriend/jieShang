「譜面と音声の同期」は、実際の音声（模範歌唱や伴奏）と楽譜を合わせる機能です。各音符が音声の何秒目に現れるかをソフトに教えます。合わせ終わると、再生モードと歌唱モードで**この音声を再生しながら、楽譜のハイライトを音声に合わせて進める**ことができます。歌唱モードでは、このタイミングをもとに音程が正確かどうかも判定します。

開き方：編集モードの下部ツールバーにある「譜面と音声の同期」を押すと、下から譜面と音声の同期パネルが表示されます。

> 使う前に、音声ファイルを [マイオーディオ](#media) に追加しておく必要があります。

## 用語の説明

- **模範歌唱**：歌声入りの模範歌唱の音声です。
- **伴奏**：歌声の入っていない伴奏の音声です。
- 1 つの楽譜に模範歌唱と伴奏を 1 つずつ同時に関連付けられます。それぞれ別々に合わせ、別々のタイミングを持ちます。

## パネルのレイアウト

**1 行目の設定：**

| 設定 | 説明 |
| --- | --- |
| 時間プロパティ | 「模範歌唱」または「伴奏」。今どちらを合わせているかを表します。既定は「伴奏」です |
| px/s | 1 秒あたりのピクセル幅です。20〜400、既定は 80。値が大きいほど波形と音符の間隔が広がり、細かく調整しやすくなります |
| サンプルレート | 既定は 44100 で、通常は変更する必要はありません |
| 音声を選択 | 「マイオーディオ」から音声を選びます。波形の表示と再生に使います |

**2 行目：**「模範歌唱を関連付け」「伴奏を関連付け」で、この楽譜の模範歌唱の音声と伴奏の音声をそれぞれ指定します。どちらも「マイオーディオ」から選びます。「時間プロパティ」を切り替えると、「音声を選択」も対応する関連付け済みの音声に自動で切り替わります。

**メインエリア（上から順に）：**

1. **音声の波形**。
2. **展開譜**：楽譜の反復を展開し、複数の大譜表を単譜表の段ごとにつなげて 1 本の長い帯にしたものです。反復によって同じ音符が複数回演奏される場合は、ドラッグできる枠が複数表示されます。
3. **赤い再生ヘッド**：波形と展開譜を縦に貫き、上部に現在の秒数を表示します。停止中はヘッドをドラッグして再生位置を変更できます。再生中は画面が自動でスクロールし、ヘッドが中央に保たれます。

**下部のボタン：**

| ボタン | 機能 |
| --- | --- |
| 前奏時間 | 音声の始まりから最初の音符までの秒数を入力します |
| 位置揃えをリセット | 楽譜のテンポ、音価、反復、前奏時間から、すべての音符の理論上のタイミングを計算し直します |
| 再生 | ヘッドの位置から音声を再生します |
| 停止 | 再生を一時停止し、ヘッドはその位置に留まります |
| リセット | ヘッドを 0 秒に戻します。音符のタイミングは変わりません |

## 合わせ方の手順

1. 「模範歌唱を関連付け」または「伴奏を関連付け」で音声を選びます。
2. 「時間プロパティ」で、合わせたいほう（模範歌唱または伴奏）を選びます。
3. 音声を聴いて最初の音符が現れる秒数を測り、「前奏時間」に入力して「位置揃えをリセット」を押すと、おおまかに合った状態になります。
4. 「再生」を押し、聴きながらヘッドと音符の枠を確認します。ずれている箇所は、展開譜上で**音符の枠を左右にドラッグ**して、音声で実際に鳴っている位置に合わせます。
5. 合わせ終わったらパネルを閉じ、エディターに戻って「保存」を押します。

> パネルには**専用の保存ボタンはありません**。関連付けと合わせた結果は現在の楽譜に直接書き込まれますが、エディターに戻って「保存」を押さないと実際には保存されません。

## 制限

- 各大譜表の単譜表の段数が揃っている必要があります。揃っていないと展開できず、パネルにエラーが表示されます。
- 楽譜に空の大譜表がある場合も展開できません。
- タイムラインは最長 10 分です。

## 合わせた後

- **再生モード**：下部の「楽譜 / 模範歌唱 / 伴奏」ドロップダウンで「模範歌唱」または「伴奏」を選ぶと、音声の再生中に楽譜が合わせたタイミングでハイライトされます。[機能](#play-features) を参照してください。
- **歌唱モード**：模範歌唱または伴奏を音源として選べ、判定は合わせたタイミングで行われます。[歌唱モード](#play-singing) を参照してください。
- 音声を関連付けても合わせていない場合、再生時に「この楽譜には模範歌唱の譜面同期タイミングがまだありません」と表示されます（伴奏も同様です）。
