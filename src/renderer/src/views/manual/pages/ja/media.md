「マイオーディオ」「マイ画像」「マイ動画」は、あなたの素材ライブラリです。ホーム画面で対応する入口をクリックして開きます。3 つとも使い方は同じです。

## 素材の使い道

| 素材 | 用途 |
| --- | --- |
| オーディオ | [譜面と音声の同期](#edit-sync) で楽譜の模範歌唱または伴奏として関連付ける。[作品](#work-edit-features) でオーディオ要素として追加する |
| 画像 | 作品で画像要素として追加する、またはページの背景に設定する |
| 動画 | 作品で動画要素として追加する |

## 追加

右上の「オーディオを追加」「画像を追加」「動画を追加」をクリックし、表示されたウィンドウでファイルを選びます。一度に複数選択できます。ファイルのドラッグ＆ドロップには今のところ対応していません。

対応形式：

| 種類 | 形式 |
| --- | --- |
| オーディオ | mp3、wav、ogg、flac、m4a、aac、webm、aiff |
| 画像 | png、jpg、gif、webp、bmp、svg |
| 動画 | mp4、webm、mov、mkv、avi、m4v |

素材の名前はファイル名（拡張子を除く）から付けられます。現在、追加後に名前を変更することはできません。

## 検索とプレビュー

- 検索ボックスで名前から探せます。一覧は更新日時の新しい順に並びます。
- **オーディオ**：カード上で直接再生・停止・再生位置の変更ができます。同時に再生されるのは 1 つだけです。カードをクリックすると、長さ、サンプルレート、チャンネル、ファイルサイズ、形式、追加日時などの詳細を確認できます。
- **画像**：カードをクリックすると、サイズ、ファイルサイズ、形式、追加日時などの詳細を確認できます。
- **動画**：カードには最初のフレームと長さが表示されます。カードをクリックすると再生でき、長さ、解像度、ファイルサイズ、形式、追加日時を確認できます。

## 削除

カードの削除ボタンをクリックし、確認すると削除されます。削除するとファイルも同時に削除され、**元に戻せません**。

> 削除したオーディオがいずれかの楽譜の模範歌唱または伴奏として関連付けられていた場合、再生時に「関連付けられたオーディオが見つかりません」と表示されるので、関連付けし直す必要があります。

## バックアップ

素材ファイルはソフトのデータフォルダーに保存されます。Steam クラウドセーブで同期されるのはデータベースだけで、これらの素材ファイルは**含まれません**。パソコンを買い替えるときは、元のファイルを自分でバックアップしてください。
