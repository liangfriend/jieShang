編集モードで楽譜上を右クリックすると、メニューが表示されます。メニュー内の小節に関する操作は、右クリックした小節（または現在選択している小節）に対して行われます。メニューの外をクリックする、`Esc` を押す、またはページをスクロールするとメニューは閉じます。

## メニュー項目

| メニュー項目 | 機能 |
| --- | --- |
| 削除 | 選択中の内容を削除します。`Delete` キーを押したときと同じです |
| 長休符 / 長休符を解除 | ドラムセット譜のみ。小節全体を長休符にします。設定するとその小節には音符を追加できなくなります |
| コピー ▸ 小節 / 単譜表 / 大譜表 | 対応する範囲の内容をコピーします |
| 貼り付け ▸ 小節 / 単譜表 / 大譜表 | コピーした内容をここに貼り付け、元の内容を置き換えます |
| 音符をクリア | この小節の音符をすべて消去します。空の小節では使えません |
| 小節を追加 ▸ 左 / 右 | 左または右に空の小節を 1 列挿入します。大譜表内のすべての段に同時に挿入されます |
| すべての大譜表から同じ段の単譜表を削除 | **すべての大譜表**から、同じ段の単譜表を削除します（たとえばすべての大譜表の 2 段目）。いずれかの大譜表が空になってしまう場合は使えません |
| 音色を設定 | 単譜表の再生音色を設定します。TAB 譜とドラムセット譜は音色が固定されているため、この項目はありません |
| 音量を設定 | 単譜表の再生音量を設定します。既定値は 100 です |

## コピーと貼り付け

- コピーした内容は今回の使用中だけ保持され、ソフトを閉じると消去されます。
- **小節のコピー**では音符だけがコピーされ、歌詞は含まれません。貼り付けると貼り付け先の小節の音符が置き換えられ、元の音符に付いていたスラーなどの複数音符にまたがる記号は消去されます。
- **単譜表や大譜表のコピー**では、構造とその中の複数音符にまたがる記号も一緒にコピーされます。貼り付けると貼り付け先を置き換え、小節の数も自動的に揃えます。
- 貼り付けできるのは**同じ種類**の楽譜だけです。たとえば五線譜でコピーした内容は数字譜に貼り付けられません。クリップボードが空の場合や種類が一致しない場合、「貼り付け」はグレー表示になります。
- 編集モードには `Ctrl+C` / `Ctrl+V` のショートカットはありません。コピーと貼り付けは右クリックメニューを使ってください。

## 音色を設定

「音色を設定」を選ぶと、音色の選択ウィンドウが表示されます。

- この小節が属する単譜表の音色を設定します。**現在とそれ以降**の大譜表で同じ段にある単譜表にも同時に設定され、それより前の大譜表には影響しません。
- 音色を検索できます。音色は楽器のファミリーごとにグループ分けされ、所有している音色だけが表示されます。
- 「OK」で適用し、「音色をクリア」で未設定に戻します。

設定後は次のようになります。

- 再生モードの音色で「楽譜の設定」を選ぶと、ここで設定した音色が使われます。
- 上部の「音色を表示」をオンにすると、譜表の左側に音色名が表示されます。[上部の機能](#edit-top) を参照してください。

## 音量を設定

「音量を設定」を選ぶと、音量ウィンドウが表示されます。

- この小節が属する単譜表の再生音量をパーセントで設定します。範囲は 0〜200、既定値は 100 です。音色とは異なり、それより前のものも含め**すべて**の大譜表で同じ段にある単譜表に同時に設定されます。
- スライダーを動かすか数値を入力し、「OK」で適用します。「100 に戻す」で既定値に戻ります。
