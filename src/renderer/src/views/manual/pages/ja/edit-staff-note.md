このページでは、五線譜での音符と休符の追加・変更・削除について説明します。

## マウスで追加する

1. 小節をクリックして選択します。
2. マウスを小節の中に移動すると（加線上の音を追加しやすいよう、小節の上下 50 ピクセル以内でもかまいません）、半透明の**プレビュー音符**が表示されます。その高さが追加される音高です。
3. クリックすると追加されます。音価は左上のツールバーの設定を使います。

追加される位置は、クリックした場所によって変わります。

- **2 つの音符の間**をクリック：新しい音符を挿入します。
- **既存の音符の上**で高さが違う位置をクリック：その音符に音を重ねて**和音**にします。音価と連桁は元の音符を引き継ぎます。
- 既存の音符の上で高さが同じ位置をクリック：その音符を選択します。
- 休符は音符の間に挿入することしかできず、重ねることはできません。

新しく追加した音符には臨時記号は付きません。符幹の向きは自動で決まります（第 3 線より上なら下向き、それ以外は上向き）。

## キーボード / MIDI キーボードで追加する

- 小節を選択して MIDI キーボードの鍵盤を押すと、対応する音高の音符を小節の末尾に追加します。小節の音部記号と調号に合わせて自動で換算され、臨時記号が必要な場合はシャープで書かれます。
- 小節を選択してメインキーボードの `1`〜`7`、または 3 列の文字キー `Q`〜`U` / `A`〜`J` / `Z`〜`M` を押すと、階名どおりに小節の末尾へ音符を追加します。`0` / `~` で休符を追加し、テンキーの数字で音価を切り替えます。詳しくは [五線譜の編集](#edit-staff) のショートカットを参照してください。

## 音高を変える：ドラッグ

音符を選択してから、符頭を押したまま**上下にドラッグ**すると音高を変えられます。同じ和音の中で移動先の位置にすでに符頭がある場合、ドラッグは無効です。

## 音符のプロパティパネル

音符をクリックして選択すると、右側に「音符のプロパティ」が表示され、「基本」「記号」「ライン」の 3 つのタブに分かれています。最後に開いていたタブが記憶されます。

### 基本

**リズム**

- **音価**：全 / 2分 / 4分 / 8分 / 16分 / 32分 / 64分 / 128分。
- **付点**：なし / · / ·· / ···。
- **連桁**：両側連結 / 右側のみ連結 / なし。8 分音符以下の音符を隣の音符とどのように連桁でつなぐかを設定します。
- **符幹の向き**：上向き / 下向き。

**音高**

- **臨時記号**：なし / シャープ ♯ / フラット ♭ / ダブルシャープ 𝄪 / ダブルフラット 𝄫 / ナチュラル ♮。設定すると「横方向オフセット」スライダーが表示され、臨時記号の左右の位置を微調整できます。
- **音符前の音部記号**：なし / ト音記号 / ヘ音記号 / アルト記号 / テノール記号。この音符の前で一時的に音部記号を変更します。こちらも横方向オフセットを調整できます。

**横方向オフセット**：-40〜40 のスライダーで、音符全体の左右の位置を微調整します。

**装飾音**

- 「前打音を追加」または「後打音を追加」を押します。新しい装飾音は既定で 8 分音符になり、音高と符幹の向きは主音符に合わせます。
- 下の一覧に既存の装飾音が表示され、1 つずつ削除できます。
- 譜面上の装飾音をクリックすると単独で選択でき、プロパティパネルが「装飾音のプロパティ」に変わります。音価、連桁、符幹の向き、付点を変更できます。

### 記号

アクセント、スタッカート、トリル、強弱記号などの単一音符の記号を追加します。[その他の記号](#edit-symbols) を参照してください。

### ライン

アルペジオ、スラー、ペダル、8va / 8vb、トリル線、クレッシェンド・ディミヌエンドなど、複数音符にまたがる記号を追加します。[その他の記号](#edit-symbols) を参照してください。

## 休符のプロパティパネル

休符を選択すると「基本」と「記号」の 2 つのタブが表示され、音価、付点、横方向オフセットを変更したり、記号を追加したりできます。

## 削除

- 選択して `Delete` または `Backspace` を押します。
- 和音に複数の音がある場合は、選択した音だけが削除されます。最後の 1 つを削除すると、その音符の位置ごと削除されます。
- 削除した音符に付いていたスラーなどの記号もあわせて削除されます。

## 多声部

五線譜には現在、声部の切り替え機能はありません。同じ位置の複数の音は和音として重ねます。
